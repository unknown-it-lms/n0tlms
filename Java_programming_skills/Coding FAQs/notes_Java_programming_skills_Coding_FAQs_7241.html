Hello World without SOP
Problem:
Write a Java program that prints Hello World to the console without directly calling System.out.println().
Approach:
You can use System.out.print() with newline '\n',
use a PrintWriter wrapping System.out, use Logger, or use java.io.PrintStream's printf/format methods.
Code: 
import java.io.PrintWriter; 
public class HelloWithoutPrintln {
    public static void main(String[] args) {
        // Using print + newline escape
        System.out.print("Hello World\n");

        // Using printf
        System.out.printf("%s%n", "Hello World");

        // Using PrintWriter
        PrintWriter pw = new PrintWriter(System.out, true);
        pw.println("Hello World");
    }
}
Explanation:
Notes:
Time Complexity: O(1)
Space Complexity: O(1)
Demonstrates alternate output APIs; interviewer mainly checks familiarity with I/O.
Check if a number is prime
Problem:
Given an integer n, determine whether it is a prime number.
Approach1:
  1. If num <= 1, it’s not prime. 
  2. Loop from 2 to num / 2 and check if any number divides num.
  3. If divisible, it's not prime; otherwise, it's prime.
Code1:
public class PrimeCheck {
    public static void main(String[] args) {
        int num = 29; // example number
        boolean isPrime = true;

        if (num <= 1) {
            isPrime = false;
        } else {
            for (int i = 2; i <= num / 2; i++) {
                if (num % i == 0) {
                    isPrime = false;
                    break;
                }
            }
        }

        if (isPrime) {
            System.out.println(num + " is a prime number.");
        } else {
            System.out.println(num + " is not a prime number.");
        }
    }
}

Approach2:
  1. Handle numbers <= 1 as non-prime.
  2. Check divisibility from 2 up to sqrt(n).
  3. You can skip even numbers >2 for a mild optimization.
    Time Complexity: O(n) in worst case because we loop till num/2.
    Space Complexity: = O(1) (constant space)
Code2:
public class PrimeCheck {
    public static void main(String[] args) {
        int num = 29;
        System.out.println(num + (isPrime(num) ? " is prime" : " is not prime"));
    }

    static boolean isPrime(int n) {
        if (n <= 1) return false;     // Numbers <= 1 are NOT prime
        if (n <= 3) return true;    // 2 and 3 are prime
        if (n % 2 == 0 || n % 3 == 0) return false;  // Eliminate multiples of 2 or 3
       
        // check factors of form 6k ± 1
        for (int i = 5; i * i <= n; i += 6) {
            if (n % i == 0 || n % (i + 2) == 0) return false;
        }
        return true;
    }
}
/*
  1. Starts checking from i = 5.
  2. Only checks numbers of the form 6k ± 1 (because all primes > 3 lie in this form): Example: 5, 7, 11, 13, 17, 19...
  3. Condition: i * i <= n → check only up to √n.
  4. Checks i and i+2 in each iteration:
  5. Example: For i=5, check 5 and 7.
  6. Increments by 6 each time because numbers between (6k and 6k±1) are already checked.
*/
Explanation:
Notes:
Time Complexity: O(√n)
Space Complexity: O(1)
Using 6k ± 1 pattern reduces the number of trial divisions.
  Why is this optimized?
  1. Instead of checking all numbers up to n/2 or n-1, it checks only up to √n.
  2. Skips even numbers and multiples of 3.
  3. Uses the 6k ± 1 rule, which reduces iterations significantly.

 Time Complexity:
  1. O(√n / 3) approximately (due to skipping multiples of 2 and 3).
  2. Much faster than O(n) simple approach.
Swap numbers without third variable​​​​​​​
Problem:
Write a Java program to swap the values of two integer variables without using a temporary (third) variable.
Approach:
Use arithmetic (addition/subtraction) or bitwise XOR. Be careful about integer overflow with arithmetic approach for very large integers; XOR avoids overflow but works only with primitive numeric types.
Code:
public class SwapNumbers {
    public static void main(String[] args) {
        int a = 5;
        int b = 10;

        // Arithmetic approach
        a = a + b;  // a = 15
        b = a - b;  // b = 5
        a = a - b;  // a = 10

        System.out.println("After arithmetic swap: a=" + a + ", b=" + b);

        // Reset
        a = 5;
        b = 10;

        // XOR approach
        a = a ^ b;
        b = a ^ b; // b = (a ^ b) ^ b = a
        a = a ^ b; // a = (a ^ b) ^ a = b

        System.out.println("After XOR swap: a=" + a + ", b=" + b);
    }
}
Explanation:
Time Complexity: O(1)
Space Complexity: O(1)
Notes:
Arithmetic may overflow if a+b exceeds int range; XOR is safer for primitives.
Reverse a number
Problem:
Reverse the digits of an integer. Example: 1234 → 4321.
Approach:
  1. Repeatedly take last digit (n % 10)
  2. append to reversed number (rev = rev*10 + digit)
  3. and drop last digit (n /= 10)
  4. Consider sign handling and integer overflow.
Code:
public class ReverseNumber {
    public static void main(String[] args) {
        int num = 1234;
        System.out.println("Reversed: " + reverse(num));
    }

    static int reverse(int n) {
        int rev = 0,digit=0;
        while (n != 0) {
            digit = n % 10;
            n /= 10;
            rev = rev * 10 + digit;
        }
        return rev;
    }
}
Explanation:
Time Complexity: O(d)
Space Complexity: O(1)
Notes:


Reverse a string without built-in function
Problem:
Reverse a string manually, without using  StringBuilder.reverse()  or similar utilities.
Approach:
  1. Convert to char array
  2. swap characters from both ends moving inward.
  3. This avoids costly string concatenation in a loop.
Code:
public class ReverseString {
    public static void main(String[] args) {
        String str = "hello";
        System.out.println(reverse(str));
    }

    static String reverse(String s) {
        char[] arr = s.toCharArray();
        int i = 0, j = arr.length - 1;
        char tmp;
        while (i < j) {
            tmp = arr[i];
            arr[i] = arr[j];
            arr[j] = tmp;
            i++;
            j--;
        }
        return new String(arr);
    }
}
Explanation:
Time Complexity: O(n)
Space Complexity: O(n) for char array copy (or O(1) extra if allowed to modify in place).
Notes:
Avoid `rev +=` inside a loop; that creates many intermediate String objects.
Check if a string is palindrome
Problem:
Check whether a string reads the same backward as forward. Ignore case and optionally non-alphanumeric chars.
Approach:
  1. Convert the original string to lowercase.
  2. Use two pointers from both ends and compare characters after normalizing case. For a strict check, compare raw characters.
  3. Compare the original lowercase string with its reversed version.
Code: 
public class PalindromeString {
    public static void main(String[] args) {
        String s = "Madam";
        System.out.println(isPalindrome(s) ? "Palindrome" : "Not Palindrome");
    }

    static boolean isPalindrome(String s) {
        s = s.toLowerCase();  // Convert once instead of every comparison
        for (int i = 0, j = s.length() - 1; i < j; i++, j--) {
            if (s.charAt(i) != s.charAt(j)) {
                return false;
            }
        }
        return true;
    }
}
Explanation:

Time Complexity: O(n)
Space Complexity: O(n)
Notes:
  1. If you need to ignore non-alphanumeric characters, skip them in the loop.
  2. Avoid `rev +=` inside a loop; that creates many intermediate String objects.
Check if a number is palindrome
Problem:
Determine if an integer reads the same backward as forward. Example: 121 → true.
Approach:
  1. Make copy of original number.
  2. Reverse the new number and compare with original.
  3. Alternatively, compare digits by extracting front/back without full reverse to avoid overflow.
Code:
public class PalindromeNumber {
    public static void main(String[] args) {
        int n = 121;
        System.out.println(isPalindrome(n));
    }

    static boolean isPalindrome(int n) {
        if (n < 0) return false; // negative numbers not palindrome due to '-'
        return n == reverse(n);
    }

    static int reverse(int n) {
        int rev = 0,=digit 0;
        while (n != 0) {
            digit= n % 10;
            n /= 10;
            rev = rev * 10 + digit;
        }
        return rev;
    }
}
Explanation: 
Time Complexity: O(d)
Space Complexity: O(1)
Notes:
Interviewers may ask how you'd handle overflow or very large numbers (use String approach).
8. Factorial of a Number (Iterative and Recursive)
Problem:
Compute n! (n factorial) where n ≥ 0. Provide both iterative and recursive implementations.
Approach:
  1. Base: 0! = 1.
  2. Recursive: n! = n * (n-1)!.
  3. Iterative: loop from 1..n.
  4. Use long or BigInteger for large n.
Code:
import java.math.BigInteger;

public class Factorial {
    public static void main(String[] args) {
        int n = 10;
        System.out.println("Iterative factorial: " + factorialIterative(n));
        System.out.println("Recursive factorial: " + factorialRecursive(BigInteger.valueOf(n)));
    }

    static BigInteger factorialIterative(int n) {
        BigInteger res = BigInteger.ONE;
        for (int i = 2; i <= n; i++) {
            res = res.multiply(BigInteger.valueOf(i));
        }
        return res;
    }

    static BigInteger factorialRecursive(BigInteger n) {
        if (n.equals(BigInteger.ZERO) || n.equals(BigInteger.ONE)) return BigInteger.ONE;
        return n.multiply(factorialRecursive(n.subtract(BigInteger.ONE)));
    }
}
Time Complexity: O(n)
Space Complexity: O(1) iterative; O(n) call stack recursive.
Notes:
Prefer iterative for large n to avoid StackOverflowError.
You can use int instead of BigInteger if input no is not large.
9. Fibonacci Series up to n Terms (Iterative and Recursive)
Problem:
Generate the first n terms of the Fibonacci sequence (0, 1, 1, 2, 3, 5...).
Approach:
Naïve recursion (F(n)=F(n-1)+F(n-2)) is exponential; use memoization or iterative loop. Store results in array or print on the fly.
Code:
import java.util.*;

public class FibonacciSeries {
    public static void main(String[] args) {
        int n = 10;
        System.out.println("Iterative: " + fibonacciIterative(n));
        System.out.println("Memoized nth: " + fibMemo(n-1)); // 0-indexed
    }

    // Return list of first n fib numbers iteratively
    static List<Long> fibonacciIterative(int n) {
        List<Long> list = new ArrayList<>();
        if (n <= 0) return list;
        long a = 0, b = 1;
        list.add(a);
        if (n == 1) return list;
        list.add(b);
        for (int i = 2; i < n; i++) {
            long c = a + b;
            list.add(c);
            a = b;
            b = c;
        }
        return list;
    }

    // Memoized recursion for nth fib
    static long fibMemo(int n) {
        long[] dp = new long[n + 2]; // safe
        Arrays.fill(dp, -1);
        return fibHelper(n, dp);
    }

    static long fibHelper(int n, long[] dp) {
        if (n <= 1) return n;
        if (dp[n] != -1) return dp[n];
        dp[n] = fibHelper(n - 1, dp) + fibHelper(n - 2, dp);
        return dp[n];
    }
}

10. Sum of Digits of a Number
Problem:
Given an integer, compute the sum of its digits. Example: 987 → 9+8+7 = 24.
Approach:
Repeatedly take n % 10 and add to sum, then n /= 10 until zero. For negative numbers, take absolute value.
Code:
public class SumOfDigits {
    public static void main(String[] args) {
        int n = 987;
        System.out.println("Sum of digits = " + sumDigits(n));
    }

    static int sumDigits(int n) {
        //For negative numbers, take absolute value
        n = Math.abs(n); // n<0?n*-1:n;
        int sum = 0;
        while (n > 0) {
            sum += n % 10;
            n /= 10;
        }
        return sum;
    }
}
Time Complexity: O(d) where d is number of digits
Space Complexity: O(1)
Notes:
Use loops over string chars if number can be very large (beyond int).
11. Find the Largest Element in an Array
Problem:
Given an array of integers, find and return the maximum element.
Approach:
Initialize max to first element;
scan array updating max.
Handle empty array by throwing exception or returning sentinel.
Code:
public class LargestInArray {
    public static void main(String[] args) {
        int[] arr = {5, 2, 9, 1, 7};
        System.out.println("Max = " + max(arr));
    }

    static int max(int[] arr) {
        if (arr == null || arr.length == 0) {
            throw new IllegalArgumentException("Array empty");
        }
        int max = arr[0];
        for (int v : arr) {
            if (v > max) max = v;
        }
        return max;
    }
}
Time Complexity: O(n)
Space Complexity: O(1)
Notes:
Single pass linear scan.
12. Find the Second Largest Element in an Array
Problem:
Return the second largest distinct element in an integer array.
Approach:
Track two variables: largest and secondLargest.
Update as you scan. Be careful with duplicates; ensure second largest is distinct.
Code:
public class SecondLargest {
    public static void main(String[] args) {
        int[] arr = {5, 2, 9, 9, 1, 7};
        Integer second = secondLargest(arr);
        System.out.println("Second largest = " + second);
    }

    static Integer secondLargest(int[] arr) {
        if (arr == null || arr.length < 2) return null;
        Integer max = null, second = null;
        for (int v : arr) {
            if (max == null || v > max) {
                second = max;
                max = v;
            } else if (v != max && (second == null || v > second)) {
                second = v;
            }
​​​​        }
        return second;
    }
}
/*

This condition(else if part) is used to update the second largest value, but only when:

  1. The current value v is not equal to max (we want unique values).

  2. And v is greater than current second.
    */


Time Complexity: O(n)
Space Complexity: O(1)
Notes:
Returns null if no distinct second largest exists.
