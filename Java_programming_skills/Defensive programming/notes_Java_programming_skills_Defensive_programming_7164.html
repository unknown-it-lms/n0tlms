Defensive programming
​​​​​​​
Concept
Defensive programming is the practice of writing code that protects itself from incorrect input, unexpected behavior, or misuse by validating inputs, handling exceptions, and ensuring program stability even in edge cases.

​​​​​​​Key Principles of Defensive Programming:
PracticePurpose
Input validationCheck if inputs are within expected range/type.
Error handlingUse try-catch (or equivalent) to avoid crashes from runtime errors.
AssertionsEnsure assumptions are true during development.
Avoid hardcodingPrevent future maintenance issues.

Why Use Defensive Programming?

  • To prevent crashes from invalid inputs or conditions.

  • To make code easier to debug and maintain.

  • To protect against unexpected usage or security vulnerabilities.

  • To ensure software works in real-world and not just ideal conditions.


Examples
CodeDefensive Coding Elements in This Example:
import java.util.Scanner;

public class DefensiveProgrammingExample {
    
    public static double divide(int numerator, int denominator) {
        if (denominator == 0) {
            System.out.println("Error: Division by zero is not allowed.");
            return 0;  // Return default/fail-safe value
        }
        return (double) numerator / denominator;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        try {
            System.out.print("Enter numerator: ");
            int num = Integer.parseInt(scanner.nextLine());

            System.out.print("Enter denominator: ");
            int den = Integer.parseInt(scanner.nextLine());

            double result = divide(num, den);
            System.out.println("Result: " + result);

        } catch (NumberFormatException e) {
            System.out.println("Invalid input. Please enter valid integers.");
        } catch (Exception e) {
            System.out.println("Unexpected error occurred: " + e.getMessage());
        } finally {
            scanner.close();  // Always close resources
        }
    }
}

FeaturePurpose
Input validationUses Integer.parseInt() inside a try block.
Error handlingtry-catch to handle invalid input.
Division checkPrevents division by zero.
Resource managementCloses Scanner in finally block.
Safe defaultsReturns 0 in error cases.



Calculate Factorial of Number Program

public class Program {
   
    private static long findFact(int num) {
        if(num <0) 
            return -1;
        if(num == 0) 
            return 1;
        long ans=1;
        for(int i=1;i<=num;i++)
            ans=ans*i;
        return ans;
    }
   
 public static void main(String[] args) {
    try {
            if(args.length!=1) {
                System.out.println("Insufficient arguments.");
                return;
            }
            int num=Integer.parseInt(args[0]);
            long res=findFact(num);
            if(res==-1)
                System.out.println("This is a negative number.");
            else
                System.out.println("Number : "+num+"  Factorial  : "+res);               
    }
    catch(Exception e) {
            System.out.println(e.getMessage());
        }
    }
}

if(args.length != 1)Input argument count checkPrevents ArrayIndexOutOfBoundsException if user forgets to pass input.
Integer.parseInt(args[0]) inside try-catchException handlingPrevents crash from invalid input like "abc", handles NumberFormatException.
if(num < 0) return -1;Invalid input checkEnsures factorial is not calculated for negative numbers (which is undefined).
if(res == -1)Error signaling using return valueProvides meaningful feedback to the user when input is negative.
for(int i = 1; i <= num; i++) ans *= i;Controlled loopPrevents logical errors by using a well-defined loop range.
