Facts you should know for programming
​​​​​​​
  • Basic Arithmetic Operations:
    • Addition, subtraction, multiplication, and division of two or more numbers.
    • Finding the quotient and remainder of a division.
  • Number Properties:
    • Even or Odd: Checking if a number is even or odd using the modulo operator.
    • Prime Number: Determining if a number is prime (divisible only by 1 and itself).
    • Fibonacci Series: Generating the Fibonacci sequence up to a certain number of terms or a given limit.
    • Factorial: Calculating the factorial of a number (product of all positive integers up to that number). 
    • Armstrong Number: Checking if a number is an Armstrong number (sum of the cubes of its digits equals the number itself).
    • Palindrome Number: Determining if a number reads the same forwards and backward.
    • Perfect Number: Checking if a number is a perfect number (sum of its proper divisors equals the number itself).
  • Number Manipulation:
    • Swapping Two Numbers: Exchanging the values of two variables, potentially without using a third variable.
    • Reversing a Number: Reversing the order of digits in a number.
    • Sum of Digits: Calculating the sum of the digits of a given number.
  • Pattern Programs:
    • Printing various number patterns like pyramids, triangles, or diamond shapes using nested loops.
  • Conversions:
    • Converting between different number bases (e.g., decimal to binary, binary to decimal).
  • Finding Extremes:
    • Finding the largest or smallest among a set of numbers.
  • GCD and LCM:
    • Calculating the Greatest Common Divisor (GCD) and Least Common Multiple (LCM) of two numbers.
