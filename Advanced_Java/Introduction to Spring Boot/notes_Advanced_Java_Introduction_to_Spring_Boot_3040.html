Introduction to Spring Boot
​​​​​​​In this chapter we are going to lean about a extension of spring framework in the form of spring boot and we will highlight the difference the spring and spring boot to understand the advantages of spring boot over spring.
Introduction to Spring boot
​​​​​​​Spring is a very popular JavaEE framework for building web and enterprise applications. Spring is very popular for several reasons like
  • Spring’s dependency injection approach encourages writing testable code
  • Easy to use but powerful database transaction management capabilities
  • Spring simplifies integration with other Java frameworks like JPA/Hibernate ORM, Struts/JSF/etc. web frameworks. 
Basically, Spring-based applications have a lot of configurations. 
In Spring MVC we need to configure 
    - Component scan, 
    - Dispatcher Servlet
    - View resolver
    - Web jars(for delivering static content) among other things.
Spring MVC application which needs support of database we would need to configure  
    - Data source
    - Entity manager factory/session factory
    - Transaction manager
Means a lot of configuration is required which makes even XML file bulky. If Spring can automatically do it for me that would be great help. This is basic idea behind spring boot development.
Spring Boot is basically an extension of the Spring framework which eliminated the boilerplate configurations required for setting up a Spring application.
Spring Boot is an opinionated framework that helps developers build Spring-based applications quickly and easily. The main goal of Spring Boot is to quickly create Spring-based applications without requiring developers to write the same boilerplate configuration again and again.
Advantages over Spring framework
Spring Boot works well with several servlet containers
Spring Boot works well with some of the most popular embedded servlet containers. Spring Boot uses Tomcat as its default, but you can easily swap it for Jetty, Undertow, Resin, and Wildfly. 

Spring initializr helps is quick setup
Spring Initializr is a web based tool avaialble at http://start.spring.io/ .It is great tool to bootstrap your Spring Boot projects. It enables you to construct a wide range of Spring Boot-based applications using a very basic user interface. You may bootstrap the following applications:
Web Applications
Restful Applications
The term "bootstrapping" refers to the process of starting a system from scratch using minimal resources. In the context of Spring Boot, Spring Initializr acts as a bootstrapping tool because it provides a basic foundation for your application, including the core Spring Boot dependencies and a pre-configured project structure. 

Decreased boilerplate code
Spring Boot automatically configures common components based on your project's dependencies and properties, eliminating the need for manual configuration

Embedded HTTP servers like Tomcat
Any web application always needs a server runtime environment to run. Spring boot comes up with embedded HTTP servers like Tomcat, Jetty etc which allows to develop and test web applications easy. This eliminates deployment overhead for traditional servers.

No XML configuration required
Spring project developers can choose to use annotations or XML configurations. The option to avoid XML configurations is a speciality of spring boot which makes the overall development very easy and quick.

WAR files are not required
While Spring Boot can use WAR (web application resource) files, they are not necessary. Instead, Spring Boot can rely on JAR (Java resource). When you package your Spring Boot application as a JAR file, it includes all the necessary components, including your application code, dependencies, and the embedded Tomcat server.​​​​​​​

Spring boots starter parent
Spring Boot Starter Parent is a parent POM file that provides a convenient way to manage dependencies in your Spring Boot projects. The parent POM file ensures that all dependencies are using compatible versions, preventing version conflicts.

Opinionated Defaults Configuration approach to reduce Developer effort
Spring Boot's opinionated defaults configuration is a powerful feature that simplifies development by providing sensible default settings for various components and configurations. This approach eliminates the need for extensive manual configuration.
For example : If you add the spring-boot-starter-web dependency to your Spring Boot project, Spring Boot will automatically configure an embedded Tomcat server, a Spring MVC DispatcherServlet, and other components necessary for building web applications.

A large community of helpful users
Like many open-source tools, Spring Boot has a large community of users full of people who enjoy sharing their insights and creations. Another advantage of having such a large community of users is that you can often find existing code that closely resembles what you want to build.

Verify the beans that get created automatically
@SpringBootApplication
public class SimpleSpringBootApplication {
    public static void main(String[] args) {
        ApplicationContext ctx= SpringApplication.run(SimpleSpringBootApplication.class, args);
        Test obj = ctx.getBean(Test.class);
        System.out.println(obj);    
        String [] beanNames = ctx.getBeanDefinitionNames();
        for(String bean : beanNames)
            System.out.println(bean);        
    }
}
This will display the list of beans automatically created by spring boot application on the console.
Developing simple MVC application
Use either spring intializr or IDE plugin for creaing spring boot application. For creating MVC application, add the dependency for spring-boot-starter-web. 
SpringBootMvcApplication.java
@SpringBootApplication
/* If the controller class is in the same package as that of main class, there is no need of adding ComponentScan annotation */
@ComponentScan(basePackages = "com.example.demo.*")
public class SpringBootMvcApplication {
    public static void main(String[] args) {
        SpringApplication.run(SpringBootMvcApplication.class, args);
    }
}
