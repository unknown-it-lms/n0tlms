Supervised Learning: Regression Models

Supervised learning regression models are used when the target variable is continuous or numeric. These models aim to learn the relationship between the input features and the continuous target variable, enabling predictions of numeric values.
​​​​​​​Some popular regression models used in supervised learning:

  1. Linear Regression: Linear regression models assume a linear relationship between the input features and the target variable. They estimate the coefficients that define the linear equation to make predictions. Linear regression models include simple linear regression (with one input feature) and multiple linear regression (with multiple input features).

  2. Polynomial Regression: Polynomial regression extends linear regression by incorporating polynomial terms of the input features. It can capture nonlinear relationships by fitting a polynomial curve to the data.

  3. Decision Tree Regression: Decision tree regression models create a tree-like structure by recursively splitting the data based on feature values. The average value of the target variable in each leaf node is used for prediction.

  4. Random Forest Regression: Random forest regression is an ensemble method that combines multiple decision tree regressors. It reduces overfitting and improves prediction accuracy by averaging the predictions of individual trees.

  5. Support Vector Regression (SVR): SVR uses support vector machines to perform regression tasks. It aims to find a hyperplane that best fits the training data while controlling the margin or deviation from the data points.

  6. Gradient Boosting Regression: Gradient boosting regression models, such as Gradient Boosting Machines (GBM), XGBoost, and LightGBM, sequentially build a series of weak regression models and combine them to make final predictions. They iteratively minimize the loss function and optimize the overall prediction.

  7. Neural Networks: Neural network models can be used for regression tasks by adjusting the network architecture and training them with suitable loss functions. Deep learning models with multiple hidden layers can capture complex patterns and nonlinear relationships in the data.

These regression models differ in their underlying assumptions, complexity, and ability to capture different types of relationships in the data. The choice of model depends on factors such as the nature of the data, the complexity of the relationship, interpretability requirements, and the desired prediction accuracy. It is often beneficial to experiment with multiple models and evaluate their performance using appropriate metrics such as mean squared error (MSE) or R-squared to select the best model for a specific regression task.

Simple Linear Regression
Simple linear regression is a basic and commonly used regression model that assumes a linear relationship between a single input feature (also called the independent variable) and a continuous target variable (also called the dependent variable). It estimates the coefficients of a linear equation to make predictions.

Scikit-Learn Documentation: sklearn.linear_model.LinearRegression

Assumptions of Linear Regression:

  1. Linearity: Linear regression assumes a linear relationship between the independent variables and the dependent variable.
  2. Independence: The observations should be independent of each other.
  3. Normality: The errors or residuals should be normally distributed.
  4. Homoscedasticity: The variance of the errors should be constant across all levels of the independent variables.
  5. No multicollinearity: The independent variables should not be highly correlated with each other.

Principle of Linear Regression:
The principal idea of linear regression is to find the best-fitting line that minimizes the difference between the predicted values and the actual values. This is achieved by estimating the coefficients that define the line.

Mathematical Intuition:
The mathematical intuition of linear regression involves fitting a line to the data using the least squares method. The line is defined by the equation:

                                                                              Y = b0 + b1*X

where Y is the dependent variable, X is the independent variable, b0 is the y-intercept, and b1 is the slope of the line. The goal is to estimate the values of b0 and b1 that minimize the sum of the squared differences between the predicted Y values and the actual Y values.

Applications of Linear Regression:
Linear regression is widely used for prediction and forecasting tasks. It finds applications in various fields, including economics, finance, social sciences, marketing, and healthcare. It can be used to predict sales, housing prices, stock prices, customer behavior, and many other phenomena.

Advantages of Linear Regression:

  1. Simplicity: Linear regression is a simple and interpretable model.
  2. Efficiency: It can be computed quickly even with large datasets.
  3. Interpretability: The coefficients in linear regression provide insight into the relationships between variables.
  4. Wide Applicability: Linear regression can be applied to a wide range of problems.

Limitations of Linear Regression:

  1. Linearity Assumption: Linear regression assumes a linear relationship between the variables, which may not hold in complex scenarios.
  2. Sensitivity to Outliers: Linear regression is sensitive to outliers, which can impact the model's performance.
  3. Overfitting: If too many independent variables are included or if the model is too complex, overfitting may occur.
  4. Limited Expressiveness: Linear regression may not capture non-linear relationships between variables effectively.

It's important to note that there are variations and extensions of linear regression that address some of its limitations, such as polynomial regression, ridge regression, and lasso regression.

Multiple Linear Regression
Multiple linear regression is an extension of simple linear regression where there are multiple input features (independent variables) instead of just one. It is used to model the relationship between multiple input variables and a continuous target variable (dependent variable). In multiple linear regression, the goal is to estimate the coefficients for each input feature and the intercept term to make predictions.

The multiple linear regression model can be represented by the equation:

                                                      y = b0 + b1 * x1 + b2 * x2 + ... + bn * xn

where:

  • y is the target variable (dependent variable)
  • x1, x2, ..., xn are the input features (independent variables)
  • b0 is the intercept (the value of y when all input features are zero)
  • b1, b2, ..., bn are the coefficients (representing the relationship between each input feature and the target variable)
 
​


The multiple linear regression model estimates the values of the coefficients that best fit the given data. The most common method for estimating these coefficients is the ordinary least squares (OLS) method, which minimizes the sum of squared differences between the observed target values and the predicted values by the linear equation.

Stepwise Regression
Stepwise regression is a method used in statistical modeling to select the most significant predictors (input features) for a regression model. It is an iterative process that involves systematically adding or removing predictors based on their statistical significance.

The goal of stepwise regression is to find a subset of predictors that optimally predicts the target variable while maintaining model simplicity and avoiding overfitting. The process involves the following steps:

  1. Forward Selection: Starting with an empty model, each predictor is evaluated individually based on a statistical criterion (such as p-value or AIC) and the one with the lowest criterion value is added to the model. This process continues until no more predictors meet the predefined criteria.

  2. Backward Elimination: Starting with a model that includes all predictors, each predictor is evaluated individually and the one with the highest criterion value is removed from the model. This process continues until no more predictors can be removed without significantly affecting the model performance.

  3. Stepwise Selection: A combination of forward selection and backward elimination is performed. Predictors are added or removed based on the statistical criteria until the model reaches an optimal state.

The choice of the statistical criterion is important in stepwise regression, and common criteria include p-values, AIC (Akaike Information Criterion), BIC (Bayesian Information Criterion), or adjusted R-squared. These criteria help evaluate the significance and quality of the predictors in the model.

Stepwise regression can help identify a subset of predictors that provide the best predictive power while reducing the risk of overfitting. However, it is important to note that stepwise regression can be influenced by the order of variable inclusion or elimination, and the final model may not be the absolute best model for all scenarios.

def stepwise_regression(X, y):
    included = set() #set to store the features currently included in the model
    excluded = set(X.columns) #set containing all features initially
    best_model = None #to store the best model
    best_criteria = float('inf') #to store the best criterion value

    while len(excluded) > 0:
        best_criteria_round = float('inf')
        best_feature_round = None

        for feature in excluded:
            model = sm.OLS(y, sm.add_constant(X[list(included) + [feature]])).fit()
            criteria = model.aic  # Use AIC as the selection criterion

            if criteria < best_criteria_round:
                best_criteria_round = criteria
                best_feature_round = feature

        if best_criteria_round < best_criteria:
            included.add(best_feature_round)
            excluded.remove(best_feature_round)
            best_criteria = best_criteria_round
            best_model = model
        else:
            break

    return best_model #will return best model

  • best_criteria_round and best_feature_round track the best criterion and feature in each iteration.
  • The for loop iterates over each feature in the excluded set.
  • For each feature, it builds an OLS regression model using the features in included plus the current feature.
  • The model is fitted, and the AIC (Akaike Information Criterion) is calculated and stored in criteria.

k-NN Regressor

The k-Nearest Neighbors (k-NN) Regressor is a machine learning algorithm used for regression tasks. It is a non-parametric algorithm that predicts the value of a target variable based on the values of its k nearest neighbors in the feature space.

The k-NN Regressor works as follows:

  1. Training: During the training phase, the algorithm stores the feature vectors and corresponding target values from the training dataset.

  2. Prediction: Given a new input feature vector, the k-NN Regressor identifies the k nearest neighbors from the training dataset based on a distance metric (typically Euclidean distance). The target values of these neighbors are then used to predict the target value for the new input.

  3. Aggregation: For regression tasks, the predicted target value is usually calculated as the average (or weighted average) of the target values of the k nearest neighbors. The weights can be assigned based on the distance or other factors, such as the inverse of the distance.

Key considerations of the k-NN Regressor:

  • Choice of k: The value of k determines the number of neighbors considered for prediction. A smaller value of k can lead to more local patterns, while a larger value of k can smooth out the predictions. It is important to choose an appropriate value of k based on the dataset and problem at hand.

  • Distance metric: The choice of distance metric, such as Euclidean distance, Manhattan distance, or other measures, affects how the algorithm defines the neighbors. The distance metric should be selected based on the nature of the data and the problem being solved.

    ​

  • Feature scaling: Since k-NN Regressor relies on distance calculations, it is important to scale the input features if they are on different scales. Scaling the features to a similar range helps to prevent features with larger scales from dominating the distance calculations.

  • Computational efficiency: As a non-parametric algorithm, k-NN Regressor can be computationally expensive, especially for large datasets. Efficient data structures like KD-trees or ball trees can be used to speed up the search for nearest neighbors.

Applications of k-NN Regressor:
k-NN regression finds applications in various domains such as real estate, finance, healthcare, and recommendation systems. It can be used for tasks such as predicting house prices, estimating sales, and personalized recommendation.

Advantages of k-NN Regressor:

  1. Simplicity: k-NN regression is a simple and intuitive algorithm.
  2. Non-parametric: It makes no assumptions about the underlying data distribution, making it flexible.
  3. Interpretability: The predictions of k-NN regression can be easily interpreted as the average (or weighted average) of similar data points.

Limitations of k-NN Regressor:

  1. Curse of Dimensionality: k-NN regression suffers from the curse of dimensionality as the feature space becomes sparser in high-dimensional spaces.
  2. Sensitivity to Outliers: Outliers in the training data can significantly affect the predictions of k-NN regression.
  3. Scalability: The prediction time of k-NN regression can be slow for large datasets since it requires calculating distances for each data point.

It's important to choose an appropriate value for the number of neighbors (k) based on the dataset and problem at hand to achieve the best performance.

Performance Metrics for Regression Models
When evaluating the performance of regression models, several metrics can provide insights into how well the model is performing in predicting continuous numerical values. Here are some commonly used performance metrics for regression models:

Scikit-Learn Documentation:  Metrics and scoring: quantifying the quality of predictions

1. Mean Squared Error (MSE):

MSE measures the average squared difference between the predicted values and the actual values. It provides an overall measure of the model's accuracy, with a lower value indicating better performance.

Formula:                             MSE = (1/n) * Σ(y - y_pred)²

Where:

  • n: Number of data points
  • y: Actual values
  • y_pred: Predicted values

2. Root Mean Squared Error (RMSE):

RMSE is the square root of the MSE and represents the average magnitude of the prediction errors. Like MSE, a lower value indicates better model performance.

Formula:                              RMSE = √MSE

3. Mean Absolute Error (MAE):

MAE calculates the average absolute difference between the predicted values and the actual values. It provides a measure of the average magnitude of errors, without considering the direction of the errors.

Formula:                              MAE = (1/n) * Σ|y - y_pred|

4. R-squared (R²):

R-squared measures the proportion of the variance in the target variable that can be explained by the model. It ranges from 0 to 1, with a higher value indicating a better fit. However, R-squared should be interpreted with caution, as it can be biased by the number of predictors in the model.

Formula:                                 R² = 1 - (SSR/SST)

Where:

  • SSR: Sum of squared residuals (Σ(y - y_pred)²)
  • SST: Total sum of squares (Σ(y - y_mean)²)

5. Adjusted R-squared:

Adjusted R-squared adjusts for the number of predictors in the model, penalizing the addition of unnecessary predictors. It provides a more reliable measure of the model's goodness of fit compared to R-squared.

Formula:                      Adjusted R² = 1 - [(1 - R²) * (n - 1) / (n - p - 1)]

Where:

  • p: Number of predictors (independent variables)
