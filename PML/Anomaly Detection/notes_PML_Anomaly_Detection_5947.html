Anomaly Detection

Anomaly detection, also known as outlier detection, is the process of identifying patterns or instances in a dataset that significantly deviate from the norm or expected behavior. Anomalies are data points or observations that are different from the majority of the data, making them potentially interesting or suspicious.

Anomaly detection can be applied to various domains and datasets, including cybersecurity, fraud detection, network monitoring, system health monitoring, manufacturing quality control, and more. The goal is to automatically identify unusual or anomalous patterns that might indicate fraudulent activities, faults, errors, or other exceptional behavior.

There are several approaches and techniques for anomaly detection:

  1. Statistical Methods: Statistical techniques assume that normal data follows a certain statistical distribution. Anomalies are identified as data points that fall outside a defined range or have significantly different statistical properties compared to the majority of the data. Examples include z-score, percentile-based methods, Gaussian distribution models, and more.

  2. Machine Learning Methods: Machine learning approaches utilize algorithms to learn patterns and characteristics of normal data from labeled or unlabeled datasets. Any data point that does not conform to the learned patterns is considered an anomaly. Techniques like clustering, classification, density estimation, and autoencoders can be used for anomaly detection.

  3. Time-Series Analysis: Time-series data refers to data points collected over time. Anomalies in time-series data are detected by analyzing patterns, trends, and deviations from expected behavior over time. Techniques like moving averages, exponential smoothing, ARIMA models, and LSTM neural networks can be applied to time-series anomaly detection.

  4. Unsupervised Learning: Unsupervised learning techniques do not require labeled data and aim to discover anomalies solely based on the characteristics of the data. Clustering algorithms like k-means, DBSCAN, and isolation forests are commonly used for unsupervised anomaly detection.

  5. Ensemble Methods: Ensemble methods combine multiple anomaly detection techniques to improve accuracy and robustness. They aggregate the results from different models or algorithms to make a final decision on whether a data point is an anomaly or not.

It's important to note that anomaly detection is a challenging task, and the choice of technique depends on the nature of the data, the specific problem domain, and the available resources. It often requires careful feature engineering, parameter tuning, and domain expertise to achieve accurate and reliable results.

Point, Contextual and Collective Anomaly
​​​​​​​1. Point Anomaly:
Point anomalies, also known as global anomalies, are individual data points that significantly deviate from the normal behavior or pattern of the dataset. These anomalies are standalone instances that do not conform to the expected characteristics of the majority of the data.
Detecting point anomalies involves identifying data points that are statistically rare or significantly different from the rest of the data. Point anomaly detection focuses on finding these isolated anomalies that stand out from the overall distribution.
​
Various techniques can be used to detect point anomalies, including:
  1. Statistical Methods: Statistical techniques such as z-score, percentile-based methods, or Gaussian distribution models can be used to identify data points that fall outside a defined range or have significantly different statistical properties compared to the majority of the data.
  2. Distance-based Methods: Distance-based methods compute the distance or dissimilarity between data points and use a threshold to identify outliers. Examples include the Euclidean distance, Mahalanobis distance, or nearest neighbor-based approaches.
  3. Density-based Methods: Density-based anomaly detection methods identify anomalies based on the density or sparsity of data points in the dataset. Data points that have a much lower density than their neighboring points are considered anomalies. Techniques like Local Outlier Factor (LOF) or DBSCAN (Density-Based Spatial Clustering of Applications with Noise) can be used for density-based anomaly detection.
  4. Machine Learning Methods: Machine learning algorithms, such as isolation forests or one-class support vector machines (SVM), can be trained on normal data to learn the underlying patterns and then classify unseen data points as anomalies if they deviate significantly from the learned model.
  5. Ensemble Methods: Ensemble methods combine multiple anomaly detection techniques or models to improve accuracy and robustness. By aggregating the results from different models, ensemble methods can provide more reliable anomaly detection.
The choice of technique depends on the nature of the data, the available features, and the specific problem domain. It's essential to evaluate and fine-tune the anomaly detection method based on appropriate metrics and validation techniques to achieve accurate results.
2. Contextual Anomaly:
Contextual anomalies, also known as conditional anomalies, are data points that are considered anomalous based on a specific context or condition. These anomalies may appear normal in some contexts but become anomalous in others due to the presence of certain conditions or dependencies.

Contextual anomaly detection takes into account the contextual information or relationships among features to identify anomalies. It considers the dependencies between different variables or attributes in the dataset and detects deviations from the expected behavior given specific contextual conditions.

For example, consider a temperature sensor in a building. The temperature reading of 30°C might be normal during the summer months but would be considered anomalous during the winter season. In this case, the anomaly is contextual because it depends on the specific context of the season.

Contextual anomalies can be detected using various techniques, including:

  1. Contextual Modeling: This approach involves building models that capture the contextual dependencies and relationships between variables. The models can be based on statistical techniques, machine learning algorithms, or domain-specific knowledge. By considering the context, the models can identify data points that deviate from the expected behavior within that specific context.

  2. Bayesian Networks: Bayesian networks are graphical models that represent probabilistic dependencies among variables. They can capture contextual relationships and dependencies between variables and identify anomalies based on the deviations from the conditional probabilities given the context.

  3. Time-Series Analysis: Contextual anomalies can be detected in time-series data by considering the temporal context. Techniques like trend analysis, seasonality modeling, or forecasting methods can help identify anomalies based on the historical behavior of the time series.

  4. Rule-based Approaches: Rule-based anomaly detection methods define specific rules or conditions that determine whether a data point is anomalous or not in a given context. These rules can be derived based on domain knowledge or expert-defined thresholds.

The choice of technique depends on the specific context and the available data and features. It's important to carefully define and model the contextual dependencies and evaluate the performance of the anomaly detection method within different contexts.

3. Collective Anomaly:
Collective anomalies, also known as group anomalies or contextual outliers, refer to groups or subsets of data points that exhibit anomalous behavior collectively. These anomalies are characterized by the abnormal behavior or patterns that emerge when considering multiple data points together, rather than focusing on individual data points in isolation.

​

Detecting collective anomalies involves identifying groups or clusters of data points that deviate significantly from the expected behavior or the behavior of the majority of the data. These anomalies are often related to interactions, dependencies, or relationships among multiple data points.

Several techniques can be used to detect collective anomalies:

  1. Clustering Methods: Clustering algorithms, such as k-means, DBSCAN, or hierarchical clustering, can be used to group similar data points together. By identifying clusters that are significantly different from the majority of the clusters, collective anomalies can be detected.

  2. Graph-based Methods: Graph-based anomaly detection techniques model the relationships or interactions between data points as a graph. Anomalies can be identified as nodes or subgraphs that have different structural properties or connectivity patterns compared to the rest of the graph.

  3. Density-based Methods: Density-based algorithms, like LOF (Local Outlier Factor) or HBOS (Histogram-based Outlier Score), can be extended to identify collective anomalies. These methods consider the density or sparsity of data points in a neighborhood and identify groups of data points that have significantly different density profiles.

  4. Association Rule Mining: Association rule mining techniques, such as Apriori or FP-Growth, can identify frequent itemsets or itemsets that occur together more often than expected. Unusual or rare itemsets can be considered collective anomalies indicating unusual combinations of attributes.

  5. Collaborative Filtering: Collaborative filtering techniques, commonly used in recommender systems, can be adapted to detect collective anomalies. By analyzing the preferences or behaviors of users or entities collectively, anomalies can be identified when certain groups deviate from the normal behavior.

The choice of technique depends on the specific characteristics of the data and the problem domain. It is important to consider the interactions, dependencies, or relationships among data points to effectively detect collective anomalies.

Supervised and Unsupervised Anomaly Detection
1. Supervised Anomaly Detection:
Supervised anomaly detection involves training a machine learning model on labeled data that contains both normal and anomalous instances. The model learns from the labeled examples to classify unseen data points as normal or anomalous based on the learned patterns.
​

A step-by-step process for supervised anomaly detection:

  1. Data Preparation:

    • Collect and preprocess the data: Clean the data, handle missing values or outliers, and perform any necessary data transformations or feature engineering.

  2. Data Labeling:

    • Annotate the data: Label instances as normal or anomalous based on domain knowledge or expert judgment. Ensure a sufficient representation of both normal and anomalous instances.

  3. Feature Extraction:

    • Identify relevant features: Choose the features that are informative and discriminative for distinguishing normal and anomalous instances. This may involve domain knowledge or feature selection techniques.

  4. Model Training:

    • Split the labeled data: Divide the labeled data into training and validation/test sets. Ensure a balanced distribution of normal and anomalous instances in both sets.
    • Select a supervised learning algorithm: Choose a suitable algorithm such as decision trees, support vector machines (SVM), random forests, or neural networks.
    • Train the model: Use the training data to train the model to learn the patterns and characteristics of normal and anomalous instances.

  5. Model Evaluation:

    • Evaluate the model's performance: Use the validation/test set to assess the model's performance. Common evaluation metrics for anomaly detection include accuracy, precision, recall, F1-score, and area under the receiver operating characteristic (ROC) curve.
    • Fine-tune the model: Adjust the model's hyperparameters or feature selection techniques to optimize performance.

  6. Anomaly Detection:

    • Apply the trained model: Use the trained model to predict the anomaly scores or probabilities for new, unseen instances.
    • Set a classification threshold: Determine a threshold or cutoff point for classifying instances as normal or anomalous based on the anomaly scores.
    • Classify instances: Classify instances with anomaly scores above the threshold as anomalous and those below the threshold as normal.

  7. Validation and Interpretation:

    • Validate the detected anomalies: Examine and validate the detected anomalies using domain knowledge or additional verification steps.
    • Interpret the results: Understand the context and implications of the detected anomalies and take appropriate actions based on the findings.

It's important to note that supervised anomaly detection requires a reliable and representative set of labeled anomalies for training. The performance of the model heavily depends on the quality and diversity of the labeled data.

Supervised Anomaly Detection Example:

# Import Required Libraries
import numpy as np #for array manipulation
from scipy import stats #for statistical parameters
import matplotlib.pyplot as plt #for visualization 
import matplotlib.font_manager #visualization parameter
from pyod.models.knn import KNN #import the model
from pyod.utils.data import generate_data, get_outliers_inliers #to detect inlier & outlier
# generating a random dataset with two features
X_train, y_train = generate_data(n_train = 300, train_only = True,
                        n_features = 2)		For more info:
generate_data()
# Setting the percentage of outliers
outlier_fraction = 0.1
# Storing the outliers and inliners in different numpy arrays
X_outliers, X_inliers = get_outliers_inliers(X_train, y_train)
n_inliers = len(X_inliers)
n_outliers = len(X_outliers)
  • This code snippet calls a function (presumably get_outliers_inliers) to identify outliers and inliers in a training dataset (X_train, y_train).
  • It then counts and stores the number of outliers and inliers in the variables n_outliers and n_inliers, respectively.
# Separating the two features
f1 = X_train[:, [0]].reshape(-1, 1)
f2 = X_train[:, [1]].reshape(-1, 1)
  • These lines extract specific features from the training data X_train. f1 takes the first feature (column 0) and reshapes it into a column vector.
  • Similarly, f2 extracts the second feature (column 1) and reshapes it.
# create a meshgrid
xx, yy = np.meshgrid(np.linspace(-10, 10, 200),
          np.linspace(-10, 10, 200))
  • This line creates a meshgrid (xx, yy) using np.meshgrid. It generates a grid of points spanning from -10 to 10 in both x and y directions with a resolution of 200 points.
  • This is often used for visualizing functions or creating surface plots.
# scatter plot
plt.scatter(f1, f2)
plt.xlabel('Feature 1')
plt.ylabel('Feature 2')
# Training the classifier
clf = KNN(contamination = outlier_fraction)
clf.fit(X_train, y_train)
  • This line initializes a K-Nearest Neighbors (KNN) based outlier detection model.
  • The contamination parameter specifies the expected proportion of outliers in the dataset, which is set to the value stored in the variable outlier_fraction.
# You can print this to see all the prediction scores
scores_pred = clf.decision_function(X_train)*-1
y_pred = clf.predict(X_train)
n_errors = (y_pred != y_train).sum()
  • This code calculates outlier scores and predicts outlier labels using a pre-trained outlier detection model (clf) on the training data (X_train).
  • It then counts the number of prediction errors by comparing the predicted labels with the true labels (y_train).
# Counting the number of errors
print('The number of prediction errors are ' + str(n_errors))
# datapoint inlier or outlier
threshold = stats.scoreatpercentile(scores_pred, 100 * outlier_fraction)
  • This line calculates the threshold for outlier detection using the scoreatpercentile function from the stats module.
  • It determines the score value below which a given percentage of data points (specified by 100 * outlier_fraction) fall, effectively setting a boundary for identifying outliers.
# anomaly score for every point
Z = clf.decision_function(np.c_[xx.ravel(), yy.ravel()]) * -1
Z = Z.reshape(xx.shape)
  • The first line calculates outlier scores for a grid of points (xx, yy) using the decision_function of a pre-trained outlier detection model (clf).
  • The second line reshapes the resulting scores (Z) to match the shape of the grid, likely for visualization purposes.
# score to threshold value
subplot = plt.subplot(1, 2, 1)
subplot.contourf(xx, yy, Z, levels = np.linspace(Z.min(),
        threshold, 10), cmap = plt.cm.Blues_r)
  • This code creates a contour plot on a subplot.
  • It uses the grid data (xx, yy) and calculated outlier scores (Z) to visualize the decision boundary of the outlier detection model, with colors ranging from blue (inliers) to lighter shades (outliers).
# score is equal to threshold
a = subplot.contour(xx, yy, Z, levels =[threshold],
          linewidths = 2, colors ='red')
  • This line adds a red contour line to the existing subplot, representing the decision boundary (threshold) for outlier detection based on the outlier scores (Z).
  • The contour line is drawn with a linewidth of 2.
# score is from threshold to maximum anomaly score
subplot.contourf(xx, yy, Z, levels =[threshold, Z.max()], colors ='orange')
  • This line adds an orange filled contour to the subplot, highlighting the region above the outlier detection threshold (threshold).
  • This visually emphasizes the area where the model identifies potential outliers based on the calculated scores (Z).
# scatter plot of inliers with white dots
b = subplot.scatter(X_train[:-n_outliers, 0], X_train[:-n_outliers, 1],
                  c ='white', s = 20, edgecolor ='k')
  • This line plots the inlier data points from the training set (X_train) on the subplot as white circles.
  • The points are sized 20 and have black edges, making them visually distinct.
# scatter plot of outliers with black dots
c = subplot.scatter(X_train[-n_outliers:, 0], X_train[-n_outliers:, 1],
                  c ='black', s = 20, edgecolor ='k')
subplot.axis('tight')
subplot.legend(
  [a.collections[0], b, c],
  ['learned decision function', 'true inliers', 'true outliers'],
  prop = matplotlib.font_manager.FontProperties(size = 10),
  loc ='lower right')
subplot.set_title('K-Nearest Neighbours')
subplot.set_xlim((-10, 10))
subplot.set_ylim((-10, 10))
plt.show()
  • This code is creating a scatter plot of the training data, with the true inliers and outliers plotted in different colors.
  • The learned decision function is also plotted on the same plot.
  • The subplot.scatter function is used to create the scatter plot, and the c parameter is used to set the color of the outliers to black.
  • The subplot.axis('tight') function is used to adjust the axis limits to fit the data tightly.
  • The subplot.legend function is used to add a legend to the plot, which describes the different elements of the plot.
  • The subplot.set_title and subplot.set_xlim and subplot.set_ylim functions are used to set the title and the axis limits of the plot. 
  • plt.show() is used to display the plot.

2. Unsupervised Anomaly Detection:
Unsupervised anomaly detection involves detecting anomalies in data without the use of labeled examples. It focuses on identifying patterns, structures, or statistical deviations that are different from the normal behavior of the majority of the data.
​

A general process for unsupervised anomaly detection:

  1. Data Preparation:

    • Collect and preprocess the data: Clean the data, handle missing values or outliers, and perform any necessary data transformations or feature engineering.

  2. Feature Extraction:

    • Identify relevant features: Select the features that are informative and capture the characteristics of the data. This may involve domain knowledge or feature selection techniques.

  3. Unsupervised Anomaly Detection Techniques:

    • Statistical Methods: Utilize statistical techniques such as z-score, percentile-based methods, or Gaussian distribution models to identify data points that fall outside a defined range or have significantly different statistical properties compared to the majority of the data.
    • Clustering Algorithms: Apply clustering algorithms like k-means, DBSCAN, or density-based methods to group similar data points together. Instances that do not belong to any cluster or form small clusters can be considered anomalous.
    • Density-Based Approaches: Employ density estimation techniques like LOF (Local Outlier Factor) or HBOS (Histogram-based Outlier Score) to identify data points that have significantly different densities compared to their neighboring points.
    • Dimensionality Reduction Techniques: Use dimensionality reduction techniques like Principal Component Analysis (PCA) or t-SNE to reduce the data to a lower-dimensional space and identify anomalies based on their position or distance in the reduced space.
    • Autoencoders: Utilize autoencoders, a type of neural network, to learn a compressed representation of the data and reconstruct the input. Instances that are poorly reconstructed or have high reconstruction errors can be considered anomalous.

  4. Setting Anomaly Detection Threshold:

    • Determine an anomaly detection threshold or cutoff point based on the output of the unsupervised anomaly detection technique. This threshold separates normal instances from anomalies.

  5. Anomaly Classification and Validation:

    • Classify instances: Classify instances as normal or anomalous based on the anomaly scores or distance measures obtained from the unsupervised anomaly detection technique and the chosen threshold.
    • Validate and interpret anomalies: Examine and validate the detected anomalies using domain knowledge, expert input, or additional verification steps. Understand the context and implications of the anomalies and take appropriate actions based on the findings.

Unsupervised anomaly detection provides flexibility when labeled anomaly data is scarce or unavailable. However, the accuracy of anomaly detection depends on the chosen technique, feature representation, and the ability to set an appropriate threshold. It's essential to carefully evaluate and interpret the detected anomalies, considering the specific domain knowledge and context. Continuous monitoring and refinement of the unsupervised anomaly detection process may be necessary as the data evolves or new anomalies emerge.

# Import Required Libraries

from pycaret.anomaly import *
from sklearn.datasets import load_breast_cancer #import the dataset
This line imports all functions and classes from the pycaret.anomaly module for anomaly detection tasks.
# Load Dataset

df = load_breast_cancer(as_frame=True)['data']
df_train = df.iloc[:-10]
df_unseen = df.tail(10)
This code loads the breast cancer dataset as a DataFrame and splits it into a training set (df_train) containing most of the data and an unseen set (df_unseen) with the last 10 rows for model evaluation.
# Set up Pycaret

anom = setup(data = df_train)
Initializes the PyCaret anomaly detection environment using the training data df_train.
# Check available models

models()

# Train the anomaly detection model

anom_model = create_model(model = 'iforest', fraction = 0.05)
This line creates an Isolation Forest anomaly detection model with a contamination fraction of 0.05 using PyCaret.
# Score the dataset

results = assign_model(anom_model)
Assigns the trained anomaly detection model (anom_model) to the training data, generating a DataFrame (results) with anomaly labels and scores for each data point in the training set.
# Plot the model

plot_model(anom_model, plot = 'tsne')
This line generates a t-SNE (t-Distributed Stochastic Neighbor Embedding) plot to visualize the anomaly detection results from the trained model (anom_model).
This plot helps in understanding the distribution of data points and identifying potential outliers.
# Save the model

save_model(model = anom_model, model_name = 'iforest_model')
This line saves the trained Isolation Forest anomaly detection model (anom_model) to a file named 'iforest_model' for later use.
# Load the model

loaded_model = load_model('iforest_model')
type(loaded_model)
loaded_model.predict(df_unseen)
loaded_model.predict_proba(df_unseen)
loaded_model.decision_function(df_unseen)
  • This code loads a saved anomaly detection model ('iforest_model'), verifies its type, and then applies it to unseen data (df_unseen).
  • It generates anomaly predictions (labels), probabilities, and anomaly scores using the loaded model.
