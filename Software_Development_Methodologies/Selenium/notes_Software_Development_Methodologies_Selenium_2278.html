Selenium
Selenium is a widely adopted open-source automation testing framework that is designed to help users test web applications across various browsers and platforms. Selenium is a set of tools that helps testers to automate web-based applications more efficiently. The scripts in Selenium IDE are developed in Selenese which is a scripting language in Selenium.

The latest version of Selenium is on version 4. The basic difference between Selenium 3 and Selenium 4 is that, in Selenium 3 the communication between client and server is done by JSON Wire protocol, however, from Selenium 4, there is direct communication between the server and client, following the W3C guidelines.

Introduction to Selenium
Lets understand Selenium in following sub-topics:
Features of Selenium
  • Cross-browser Compatibility − Selenium can be used to execute tests on different browsers including Chrome, Firefox, Safari, and Internet Explorer. This ensures that your web application performs consistently across multiple platforms.
  • Platform Independence − Selenium can run on Windows, macOS and Linux. Due to this platform independence.
  • Support for Multiple Programming Languages − Selenium supports multiple programming languages including Java, Python, C#, Ruby, and JavaScript.
  • Extensibility − Selenium has features to enable users to incorporate additional functionalities through several plugins or extensions. One can easily customize Selenium to suit specific testing requirements.
Components of Selenium
Selenium Components are often referred to as a suite of Selenium tools. There are a total of four tools which are together called the Selenium Components.
​
No.Name of component
1Selenium IDE
Selenium Integrated Development Environment was first developed as a Firefox plugin, however now it is available in both Firefox and Chrome browsers. This is used for:
  • Recording, debugging, executing and editing of the functional tests can be done in Selenium IDE.
  • The scripts in Selenium IDE are developed in Selenese which is a scripting language in Selenium.
  • Selenium IDE commands help us to perform tasks like clicking a button or link, taking input in an edit box, obtaining a text from a web-element etc.
  • Selenium IDE tests can be converted to Java, C#, Python, TestNG, and so on.
  • Its default format is in .html.
  • Selenium IDE does not require technical or programming knowledge. Hence it can be used only testing simple scenarios and not used to cover any complex use cases.
2Selenium RC
  • Selenium Remote Control is a server implemented in Java.
  • It can accept commands for browsers using the HTTP.
  • Selenium RC has a Selenium RC server and a Selenium RC client.
  • Selenium RC is outdated and it has been deprecated by Selenium.
3Selenium Web-driver
  • Selenium WebDriver (began from Selenium version 2 onward) is the successor to Selenium RC which sends commands directly to the browser (with the help of the browser drivers) and retrieves results, hence it is faster than Selenium RC.
  • Selenium WebDriver does not require a server to initiate test execution and it communicates directly with the browser.
4Selenium Grid
  • Selenium Grid is mainly used for parallel testing.
  • It follows a hub (which is a central part and rest are considered as nodes) and node architecture.
Selenium Grid enables us to execute varied tests in multiple machines simultaneously.
Different types of tests
Selenium can be used to create different types of tests as follows:
Type of testPurpose
Functional Tests These tests help to check various new functionalities and features of the application or the product under test.
Regression TestsThese tests help to check if code changes have broken an existing functionality of the application.
Smoke TestsThese tests help to verify if a new build is stable enough to carry out testing activities on it.
Integration TestsThese tests help to validate if the integration of all the modules are working together as a unit.
Unit TestsThese tests are created by the developers to test their code.
Advantages of Selenium
  • Selenium is a free and open-source tool.
  • Can be extended for various technologies that expose DOM.
  • Supports multiple browsers.
  • Supports multiple operating systems, and platforms.
  • Supports mobile devices.
  • Supports parallel executions.
  • Has a big community support for help in case of issues.
Disadvantages of Selenium
  • Supports only web based applications.
  • No support for QR, captcha and barcode, scenario.
  • Programming and technical knowledge required.
  • It requires time to be more compatible and stable with new browsers.
  • Difficult to set up since no vendor support.
Selenium command
Selenese is a scripting language in Selenium. Every command used in Selenium IDE is known as the Selenese commands. Using the Selenese commands we perform all the testing activities on a web application.

Selenese commands are of three types:
  1. Actions Commands
  2. Accessors Commands
  3. Assertions Commands
Actions Commands:
The action commands are used to manipulate the state of the application under test. These are mainly for simulating user-actions with the application.

Some of these commands are listed below:
  • click(locator)
  • check(locator)
  • uncheck(locator)
  • close
  • debugger
  • double click(locator)
  • double click at(locator)
  • drag and drop to object(source locator, destination locator)
  • echo(message)
  • edit content(locator, value)
  • execute script(script, variable name)
  • execute async script(script, variable name)
  • mouse down(locator) + other commands related to mouse actions
  • open(url)
  • pause(wait time)
  • remove selection(locator, option)
  • run(test case)
  • select(locator, option)
Accessors Commands
Accessors commands are used to retrieve values or states from web elements or the browser.
Some of these commands are listed below:
  • store(text, variable)
  • store attribute(locator, variable)
  • store text(locator, variable)
  • store title(text, variable)
  • getText()
  • getAttribute(String attributeName)
  • getTitle()
Assertions Commands
Assertion commands are used to check the state of the application under test.
Some of these commands are listed below:
  • assert(variable, expected value)
  • assert alert(alert text)
  • assert checked(locator)
  • assert confirmation(text)
  • assert editable(locator)
  • verify(variable, expected value)
  • verify checked(locator)
  • verify editable(locator)
Interacting with web elements
Following are some of the code samples showing the way we can interact with the web-elements in Selenium.
ActionCode
Clicking an Element
driver.findElement(By.id("submit-button")).click();
Typing Text into a Text Field
driver.findElement(By.name("username")).sendKeys("testuser");
Clearing a Text Field
driver.findElement(By.id("search-box")).clear();
Getting Text from an Element
String text = driver.findElement(By.className("message")).getText();
Getting an Attribute Value
String value = driver.findElement(By.name("email")).getAttribute("value");
Checking if an Element is Displayed/Enabled/Selected
WebElement checkbox = driver.findElement(By.id("agree"));

boolean isDisplayed = checkbox.isDisplayed();
boolean isEnabled = checkbox.isEnabled();
boolean isSelected = checkbox.isSelected();
Handling Dropdowns (Using Select Class)
import org.openqa.selenium.support.ui.Select;
WebElement dropdown = driver.findElement(By.id("country"));
Select select = new Select(dropdown);
// By visible text
select.selectByVisibleText("India");
// By value attribute
select.selectByValue("IN");
// By index
select.selectByIndex(3);
Submitting a Form
driver.findElement(By.id("loginForm")).submit();
Mouse Hover (Using Actions Class)
import org.openqa.selenium.interactions.Actions;

WebElement menu = driver.findElement(By.id("menu"));
Actions actions = new Actions(driver);
actions.moveToElement(menu).perform();
Right-Click (Context Click)
Actions actions = new Actions(driver);
actions.contextClick(driver.findElement(By.id("right-click-area"))).perform();
Double Click
Actions actions = new Actions(driver);
actions.doubleClick(driver.findElement(By.id("double-click-button"))).perform();
Drag and Drop
WebElement source = driver.findElement(By.id("draggable"));
WebElement target = driver.findElement(By.id("droppable"));
Actions actions = new Actions(driver);
actions.dragAndDrop(source, target).perform();
