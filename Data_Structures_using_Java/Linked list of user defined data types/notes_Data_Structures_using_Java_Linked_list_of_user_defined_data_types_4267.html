Linked list of user-defined data types
​

This is structure of Linked List for  User-defined data type.
Suppose we want to create Linked list of Employees then apply following steps.
1. Create Employee class.
2. Create node class where data is of type Employee.
3. Create Linked List class.

Node class always has only data and the next part. data could be of type int,char,Employee, or Student.
 
Creating linked list with user defined data type
class Employee
{
       private int eid;
       private String ename;
      public Employee( )
       {
       }
      public Employee(int i,String nm)
        {
            eid=i;
           ename=nm;
        }
       // All getter and setter methods
       public String toString()
        {
                return eid+" "+ename;
        }
}

 class Node
{
        private Employee data
        private Node next;
        public Node()
        {
            data=new Employee();
            next=null;
        }
        public Node ( Employee data)
        {
                this.data=data;
                this.next=null;
        }
       //getter and setter methods
        public String toString()
        {    
                return " "+data;
        }
}     		class LinkedList
{
        private Node head;
       public LinkedList ( )
       {
              head=null;
        }
        public void addNode(Employee data)
        {
              Node record=new Node(data);
              if (  head = = null)
                        head=record;
           else
             {
                    Node move=head;
                   while(move.getNext()!=null )
                              move=move.getNext();
                  move.setNext(record);
              }
}
