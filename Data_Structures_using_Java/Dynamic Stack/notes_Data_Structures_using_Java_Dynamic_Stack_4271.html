Dynamic Stack
We know that stack could be implemented using array and such stack is known as static stack but since we are using array to implement it we cannot insert elements more than the size of array, it will show memory overflow because the size of array is fixed. To overcome this drawback i.e to make stack dynamic we implement stack using linkedlist and such stack is known as dynamic stack and in this section we are going to learn dynamic stack.

​
Concept of Dynamic Stack
Dynamic Stack, just like Dynamic Array, is a stack data structure whose the length or capacity (maximum number of elements that can be stored) increases or decreases in real time based on the operations (like insertion or deletion) performed on it.

Stack is one of the most popular used data structure which has multiple applications in real life. So we must be familiar with its structure and implementation, so that we can use stack in our program with ease.


Need of Dynamic Stack
Since we are using linkedlist to implement stack.
Linkedlist consists of consecutive linked nodes where each node consists of two parts data part and address part, data part stores the value and address part contains the address of next node. There is a pointer called head which stores the address of first node and the address part of last node is set to null since it does not point to any node.

    Stack has a container like structure with one open end known as top. Since stack is a ordered list so we can say it is a collection where insertion and deletion are performed at one end(top) only. It always follows the LIFO (Last in First Out) Principle for the insertion and deletion of elements.
Working on Dynamic Stack

Working on Dynamic Stack is nothing but implementing Linked list in restricted way. In Linked list we have created node class and linked list class.Same we have to create node class and linked list class only now instead of head it should call it top.
So top is null initially.
1. Push.
     Push operation is adding node at begging of the linked list.
  •    Step 1: Create node with given data.
  •    step 2: check if top is null make this node top.
  •    step 3: if top is not null add node at beginning. make newnode->next=top. and top=newnode
2. Pop.
    Pop operation is deleting first node from linked list.
  •     step 1: if top is null stack is empty.
  •     step 2: else mark first node ad del.
  •     step 3: move top to next element.
  •     step 4:display del data as deleted data.
   3. Display.
     Display stack is travel linked list from top to null.
  •    step 1: declare one pointer move and assign value of top to move;
  •    step 2: travel till move!=null and print data.

 public void push(int data){
        Node newnode=new Node(data);
        if(top==null)
            top=newnode;
        else        {
            newnode.setNext(top);
            top=newnode;
        }
     }
    public int pop()   {
        int data;
        Node del;
        del=top;
        top=top.getNext();
        data=del.getData();
        del=null;
        return data;
    }
    public String toString()   {
        String str=" ";
        Node move=top;
        while(move!=null)     {
            str=str+move.getData();
            move=move.getNext();
            str=str+' ';
       }
        return str;
    }
