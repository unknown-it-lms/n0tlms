Binary Search Tree
Binary Search Trees are special kinds of Binary Trees which have a few special properties. The idea is similar to the classical Binary Search algorithm. The only subtle difference is that it uses Binary Trees to represent the data set. 
Let’s talk check  the special properties of a Binary Search Tree.
  1. The value of all the nodes in the left subtree of the root node is less than the value of the root node.
  2. The value of all the nodes in the right subtree of the root node is greater than the value of the root node.
  3. Properties 1 and 2 are true for all the nodes of the tree.
Concept Of Binary Search Tree
A tree is a nonlinear hierarchical data structure that consists of nodes connected by edges.If we want to perform any operation in a linear data structure, it will take some extra time so ,the time complexity increases with the increase in the data size. But, it is not acceptable in today's computational world.
 There are diffrent types of tree data structures wich allow faster and easier access to the data as it is a non-linear data structure.
While implementing tree we should know following thing.
  • A tree can contain no nodes or it can contain one special node called the root with zero or more subtrees.
  • Every edge of the tree is directly or indirectly originated from the root.
  • Every child has only one parent, but one parent can have many children.
Advantages of Tree
  • Tree reflects structural relationships in the data.
  • It is used to represent hierarchies.
  • It provides an efficient insertion and searching operations.
  • Trees are flexible. It allows to move subtrees around with minimum effort.

Traversal Of Tree.
Traversing a tree means visiting every node in the tree. You might, for instance, want to add all the values in the tree or find the largest one. For all these operations, you will need to visit each node of the tree.

Linear data structures like arrays, stacks, queues, and linked list have only one way to read the data. But a hierarchical data structure like a tree can be traversed in different ways.
Types of Traversal
 Our main goal is to visit each node, so we need to visit all the nodes in the subtree, visit the root node and visit all the nodes in the right subtree as well.

Depending on the order in which we do this, there can be three types of traversal.
  1. Inorder Traversal.
  2. Preorder Traversal.
  3. Postorder Traversal.

Inorder traversal

  • First, visit all the nodes in the left subtree
  • Then the root node
  • Visit all the nodes in the right subtree

Preorder traversal

  • Visit root node
  • Visit all the nodes in the left subtree
  • Visit all the nodes in the right subtree

Postorder traversal

  • Visit all the nodes in the left subtree
  • Visit all the nodes in the right subtree
  • Visit the root node
