Tree
We all are familiar with trees in real life. It’s intersting  to know that with the observation of leaves and branches of a tree, one came up with a structure to store and organise data in the real world which now is widely being used in multiple application libraries and has really changed the world.

So by observing tree  we can conclude that a tree has leaves, branches, roots and stems. If observed more carefully, each leaf, following it’s stems and branches,when traced, can take us to its roots.

In real life, this fine observation can be used to structure a basic family history in the form of the hierarchy where leaves can be considered as children and tracing leaf with it’s stems and branches can lead to its earliest known roots i.e. parents to grandparents to earliest known grandparent.
Concept and need Of Tree
A tree is a nonlinear hierarchical data structure that consists of nodes connected by edges.If we want to perform any operation in a linear data structure, it will take some extra time so ,the time complexity increases with the increase in the data size. But, it is not acceptable in today's computational world.
 There are diffrent types of tree data structures wich allow faster and easier access to the data as it is a non-linear data structure.

While implementing tree we should know following thing.
  • A tree can contain no nodes or it can contain one special node called the root with zero or more subtrees.
  • Every edge of the tree is directly or indirectly originated from the root.
  • Every child has only one parent, but one parent can have many children.
Advantages of Tree
  • Tree reflects structural relationships in the data.
  • It is used to represent hierarchies.
  • It provides an efficient insertion and searching operations.
  • Trees are flexible. It allows to move subtrees around with minimum effort.

Types Of Tree

General Tree
The general tree is the type of tree where there are no constraints on the hierarchical structure.

Properties
The general tree follows all properties of the tree data structure.
A node can have any number of nodes.		​
Binary Tree
A binary tree has the following properties:

Properties
  • Follows all properties of the tree data structure.
  • Binary trees can have at most two child nodes.
  • These two children are called the left child and the right child.
​
Binary Search Tree 
A binary search tree is a type of tree that is a more constricted extension of a binary tree data structure.

Properties
  • Follows all properties of the tree data structure.
  • The binary search tree has a unique property known as the binary search property. This states that the value of a left child node of the tree should be less than or equal to the parent node value of the tree. And the value of the right child node should be greater than.
​
AVL Tree 
An AVL tree is a type of tree that is a self-balancing binary search tree.

Properties
  • Follows all properties of the tree data structure.
  • Self-balancing.
  • Each node stores a value called a balanced factor, which is the difference in the height of the left sub-tree and right sub-tree.
  • All the nodes in the AVL tree must have a balance factor of -1, 0, and 1.


​
Red-Black Tree
A red-black tree is a self-balancing binary search tree, where each node has either the color of red or black.
The colors of the nodes are used to make sure that the tree remains approximately balanced during insertion and deletion.
Properties
  • Follow all properties of binary tree data structure.
  • Self-balancing.
  • Each node is either red or black.
  • The root and leaves nodes are black.
  • If the node is red, then both children are black.
  • Every path from a given node to any of its nodes must go through the same number of black nodes.


​

Tree Terminologies
RootRoot is a special node in a tree. The entire tree is referenced through it. It does not have a parent.
Parent NodeParent node is an immediate predecessor of a node.

All immediate successors of a node are its children.

Nodes with the same parent are called Siblings.
Height of a nodeHeight of a node represents the number of edges on the longest path between that node and a leaf.
Hight Of Tree   Height of tree represents the height of its root node.
Depth Of Node Depth of a node represents the number of edges from the tree's root node to the node.
Edgeis a connection between one node to another. It is a line between two nodes or a node and a leaf.
Degree Of Node Degree of a node represents a number of children of a node.
Path   Path is a number of successive edges from source node to destination node.
Creating Tree
Tree can be implemented by two way.
1. Array Representation.
2. Dynamic Representation(using linked list).


1. Array Representation.
    The array representation of binary tree can be done using a technique called level order traversal. In level-order traversal, the elements of the binary tree are stored in the array in the order in which they are visited in a breadth-first search.
The array representation of binary tree allows for efficient access to the elements of the tree. For example, if a binary tree has n nodes, the array representation of the tree can be stored in an array of size n, allowing for constant-time access to each node in the tree.
    In this representation, the root node of the binary tree is stored at the first position of the array, and its left and right children are stored at the second and third positions, respectively. The remaining nodes are stored in the same way, with the children of each node stored in consecutive positions in the array.
​

The level order representation of this tree in an array would be [1, 2, 3, 4, 5].
Using this representation, it is possible to access the children of a node at position i by using the following formulas:

The left child of node i can be found at position 2i + 1
The right child of node i can be found at position 2i + 2
It is also possible to determine the parent of a node at position i using the formula:
The parent of node i can be found at position (i – 1) / 2

Operations on Binary Tree

Another frequently used tree operation is traversal. Tree traversal is the process of visiting each node present in a tree. There are three methods of tree traversal:

  1. In-order traversal.
  2. Post-order traversal.
  3. Pre-order traversal.
