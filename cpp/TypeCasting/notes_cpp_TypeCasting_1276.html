TypeCasting
  • We have already seen that, a base class pointer can point to any of its derived class objects. For example, Employee* pEmp can point to objects of SalesMangaer, Programmer as well as Admin classes. We call such pointer as generic pointer. 
  • However, using generic pointer, we can not access members of the derived class. For example, using pointer of Employee class, we can point to Admin object BUT we can not access the method getAllowance() which is present in the class Admin. To do this, we have to type cast the base class pointer to derived class type.
​​​​​​​
Following are the types of Type casting in C++:
  1. static_cast
  2. dynamic_cast
  3. reinterpret_cast
  4. const_cast
static_cast
This is the type casting done without cheking its validity. It should be done only when we are sure about its validity.
Employee* pEmp; // Base class pointer
Admin a1; 
pEmp= &a1; // Base class pointer can point to objects of its derived class
pEmp->GetName(); // Using such pointer, we can access methods of Employee class
pEmp->getAllowance(); // BUT we can't access methods of derived class
Admin* pAdmin= static_cast<Admin*>(pEmp); /* Here, base class pointer static type-casted to derived class pointer type (unsafe downcasting) */
pAdmin->getAllowance(); // Now using pAdmin, we can access methods of derived class Admin.

Note that:
Such type of downcasting works only when we are sure about its validity. For example, in the above case, WE KNOW that the object is of Admin class so it can be pointed by Admin pointer. So the typecasting works well.
However, there are many situations where we don't know the type of object pointed by the pointer, hence such blind downcasting may be un-safe. This is shown below:
Employee* pEmp; // Base class pointer
Programmer p1; 
pEmp= &p1; // Employee pointer can point to Programmer object
pEmp->GetName(); // Using such pointer, we can access methods of Employee class
pEmp->getAllowance(); // BUT we can't access methods of derived class
Admin* pAdmin= static_cast<Admin*>(pEmp); /* Here, base class pointer typecasted to derived class pointer type (downcasting). But this downcasting is wrong because we are creating a Admin pointer for Programmer object, which is wrong. */
pAdmin->getAllowance(); // Hence this line may give access violation error or some garbage value.
This situation can be handled by first checking whether our type casting is valid or not, before using the type casted pointer, as explained below. 
dynamic_cast
  • This is the type casting where we first ensure the validity of the type casting. Only if the type casting is valid, we use the type-casted pointer, else we dont use it. This is also called as safe-down casting.
  • This type-casting return null value, if the type-casting is valid, else for valid type casting, it return non-null value. By checking whether the pointer is null or not, we can decide whether to use it or not. 

This is shown below: 
Employee* pEmp; // Base class pointer
Admin a1; 
pEmp= &a1; // Base class pointer can point to objects of its derived class
pEmp->GetName(); // Using such pointer, we can access methods of Employee class
pEmp->getAllowance(); // BUT we can't access methods of derived class
Admin* pAdmin=dynamic_cast<Admin*>(pEmp); /* Here, base class pointer typecasted to derived class pointer type (downcasting) */
if(pAdmin!=null) /*Here, pAdmin will not be null because it is valid to have Admin pointer for Admin object a1.*/
{
    pAdmin->getAllowance(); // Now using pAdmin, we can access methods of derived class Admin.
}
Employee* pEmp; // Base class pointer
Programmer p1; 
pEmp= &p1; // Employee pointer can point to Programmer object
pEmp->GetName(); // Using such pointer, we can access methods of Employee class
pEmp->getAllowance(); // BUT we can't access methods of derived class
Admin* pAdmin= dynamic_cast<Admin*>(pEmp); /* Here, base class pointer typecasted to derived class pointer type (downcasting) */
if(pAdmin!=null) /*But, In this case, pAdmin will be null because it is invalid to have Admin pointer for Programmer object p1. Hence, this condition is false, so dont use this invalid Admin pointer on Programmer object.*/
{
    pAdmin->getAllowance(); // This code is not executed.
}
Such dynamic casting gives us safe-downcasting. 
const_cast
This is a special type casting which converts the constant pointer to non-constant pointer.
This is as explained in the code below. 
const int a = 10; 
//a = 20; Value of a can't be changed because it is const int
const int* p = &a;
//*p = 20; Using p we can't change value of int a because p is pointer to const int
int* q = const_cast<int*>(p); // Type of pointer p is changed from pointer to const int to pointer to int

*q = 30; // Using q, we can change value of int now
reinterpret_cast
​​​​​​​This casting is used for convering any type of pointer to any other type of pointer.
int x=20; 
int* p = &x;
​​​​​​​
char* q = reinterpret_cast<char*>(p); // int* is convereted to char* using reinterpret cast
