Class and Object basics
  • Class provide a template of state and behavior for creation of programming entities. It maps the real life entities that are relevant in solution. It binds the abstraction of state and behavior together.
  • Abstraction of state is mapped using data members, whereas abstraction of behavior is mapped using member functions. 
  • It also implements encapsulation because it binds state of an entity with its behavior. We can prevent direct manipulation of state by declaring the data members as private and then provide a controlled access to these data members through public member functions.
  • The default access specified is private for a class whereas it is public for a structure in C++.

Terminology:
Lets understand the technical terminology of a class using another class Person.
  • A class contains data as well as functions. Data present inside a class is called as data member, whereas the function present inside a class is called as member function.
  • Member function that is used to get value of a data member is called as accesser whereas a function that is used to change a data member’s value is called as mutator. A function that doesn’t either provide access to the data or mutate a data is called as an operation.

Constructor
Constructor is a member function of a class which is used to initialize an object at the time of creation itself.
class Date {
    int d, m, y;

public:
    // This is constructor
    Date() {
    d=m=y=0
    }
};
Rules for writing a constructor:
  1. It's name must be same as that of the class.
  2. It should not return anything. Don't write even void as its return type.
--------------------------------------------------------------------------------------------
Note that:
  • It is a function which we write in the class but called by compiler immediately after creating an object for its initialization.
  • Constructor is used to initialize an object. It doesn't create an object..
Destructor
It is a member function used for un-initialization of object just before it gets destroyed. It is called just before de-allocating memory of an object. It is written by programmer but called by Compiler.
class Date {
    int d, m, y;

public:
    // This is destructor
    Date() {
    d=m=y=0
    }
};
Rules for writing a destructor:
  • Name of a destructor is standard. It must be ~class name.
  • Destructors do not have parameters.
  • Destructors cannot return any value. Don’t even mention void.
--------------------------------------------------------------------------------------------
Note that:
  • It is a function which we write in the class but called by compiler just before deleting the object from the memory. It is the last chance given to the object to perform necessary clean-up operations.
  • As destructor doesn't have parameter, it can NOT be overloaded. Hence, there can be only one destructor in a class
Copy constructor
It is a constructor, which is used to create copy of existing objects. These objects have same initial state but may mutate independently. 
class Date {
    int d, m, y;

public:
    // This is a copy constructor
    Date(Date& arg) {
     d=arg.d;
    ​​​ m=arg.m;
      y=arg.y;
    }
};
Rules for writing a constructor:
  1. It's name must be same as that of the class.
  2. It should not return anything. Don't write even void as its return type.
  3. Argument object for a copy constructor MUST be passed by reference
--------------------------------------------------------------------------------------------
Note that:
  • For every class, compiler provides a default copy constructor, which performs bit-wise copy.
Scope resolution operator
Scope resolution operator is used for the following purposes in C++ program.
  1. To define member functions outside the class
  2. To access static data or static functions from a specific class
  3. To explicitly access global variable or global functions 

Lets see each of them now.

1. To define member functions outside the class:

  • Till now, we have defined all the member functions inside the class itself. This might be acceptable for classes with only few functions which are small in size.
  • However, this may make the class code unreadable if it has many big functions. To handle this situation, we simply declare such functions inside the class and define them outside the class in other files. At the point of definition of such functions, we use scope resolution operator to mention clearly that the function is not a global function but its the member of specified class. 
  • Here, we create a header file with .h extension in which we simply declare the class. We then create other definition files with .cpp extensions which define all the member functions of that class. This is as shown below.
date.h (Header file)date.cpp (Definition file)
#pragma once /* This is used to avoid multiple inclusion of header file */

#include<iostream>
using namespace std;
class Date
{
    int d, m, y;
public:
    Date(); // Declaration of default constructor
    Date(int, int, int); // Declaration of parameterized constructor
    void Display(); // Declaration of member function
};
/*
Note that this class now contains only declarations of member functions. They can be defined in one or more definitions files. Each definition file must include this header file first.
*/		#include"date.h" // include the .h file

// Definition of default constructor

3. To explicitly access global variable or global functions 
​​​​​​​
If a function has a local variable whose name is same as that of another global variable, we can access the global variable using scope resolution operator, as shown below.
int amount = 185;
void SomeFunction()
{
    int amount = 0;
    cout << amount; // Prints 0
    cout << ::amount; // Prints 185
}		Note that:
The function has a local variable (amount) whose name is same as other global variable. If we simple use amount in our code, it will give access to local variable. In such scenario, if we want to access global variable (amount), we have use scope resolution operator ::amount
