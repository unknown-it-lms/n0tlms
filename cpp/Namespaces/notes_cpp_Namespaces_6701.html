Namespaces
Names are used in a software system for identifying various programming elements like variables, functions, classes etc. In a large system, it is quite possible that a name used by one programmer may be accidentally used by another programmer for some other entity. This creates a problem called as “name collision” when the entire system is build together.
​​​​​​​Namespaces are used to avoid this problem. Understanding of namespaces is essential for developing large size projects comprising of code contribution from different in-house teams and third-party vendors.
Need of Namespace
Consider following scenario. In file1.cpp we have created a global variable, iTotal. In file2.cpp also we have created a global variable with same name iTotal. When we compile file1.cpp, it compiles succesfully. When we compile file2.cpp, it compiles succesfully. But when we compile the entire source code, it gives a redefinition error saying that the variable iTotal is already defined. This is because, the compiles finds the variable iTotal in both the files, which is not allowed. Such errors are called as name collisions.

Such cases can be handled in programming by creating namespaces.

Using namespaces
Namespaces are created as follows:
Creating namespace
Accounts.cpp
namespace Accounts
{
    int iAmount=1200;
    void PrintDetails()
    {
        //. . . 
    }
    // Other variables and functions
}		Here we have created a namespace with name "Accounts". Inside this namespace, we have defined a variable with name iAmount as well as a function with name PrintDetails();

Note that, now: 
  • The full name of variable iAmount is Accounts::iAmount
  • The full name of function PrintDetails is Accounts::PrintDetails
  • Such full names of variables, functions and classes are called as "Fully decorated/qualified names".

So fully decorated name of various entities are 
<Name of namespace>::<Name of entity> 
Finance.cpp
namespace Finance
{
    int iAmount=1200;
    void PrintDetails()
    {
        //. . . 
    }
    // Other variables and functions
}		Here we have created a namespace with name "Finance". Inside this namespace, we have defined a variable with name same name iAmount as well as a function with same name PrintDetails();

Note that, now: 
The full name of variable iAmount is Finance::iAmount
The full name of function PrintDetails is Finance::PrintDetails

Now, even if we compile both these files together, it won't give any error. This is because the full names of both variables as well as functions in NOT same. Now the names of variables are Accounts::iAmount and Finance::iAmount. And the names of functions are Accounts::PrintDetails and Finance::PrintDetails

Accessing names from namespaces
We can access various names from a namespace in following two ways:
  1. Using fully qualified names
  2. Use of "using" keyword

Lets now see each of them:
1. Using fully qualified names
Accounts.cppFinance.cpp
namespace Accounts
{
    int iAmount=1200;
    void PrintDetails()
    {
        //. . . 
    }
    // Other variables and functions
}		namespace Finance
{
    int iAmount=1200;
    void PrintDetails()
    {
        //. . . 
    }
    // Other variables and functions
}
void main()
{
    Accounts::iAmount=2500; // This will assign value 2500 to iAmount from Accounts namespace
    Accounts::PrintDetails(); // This will call PrintDetails() from Accounts namespace

    Finance::iAmount=3800; // This will assign value 3800 to iAmount from Finance namespace
    Finance::PrintDetails();  // This will call PrintDetails() from Finance namespace
}
2. Use of "using" keyword
In this method, instead of specifying the name of namespace everytime, we simply open the namespace once, so that all names will be accessed from that namespace only. This is done with the help of "using" keyowrd, as given below:
using namespace Accounts;
void main()
{
    iAmount=2500; // This will assign value 2500 to iAmount from Accounts namespace
    PrintDetails(); // This will call PrintDetails() from Accounts namespace
}
using namespace Finance;
void main()
{
    iAmount=2500; // This will assign value 2500 to iAmount from Finance namespace
    PrintDetails(); // This will call PrintDetails() from Finance namespace
}
using namespace Accounts;
using namespace Finance;
void main()
{
    iAmount=2500; // This will give error as iAmount is present in both namespaces which are used
    Finance::PrintDetails(); // This will call PrintDetails() from Finance namespace
}
Nested namespaces
We can have a namespace created inside other namespace. Such namespaces are called as nested namespaces. They are created and used as shown below:
namespace Accounts
{
    int iRecordNo=20;
    namespace Reports
    {
        int iReportNo=45;
        void Print()
        {
            cout<<"Print 123";
        }
    }
}		Here, namespace Reports is created inside namepsace Accounts.

Following are different ways in which we can access different names inside such namespaces:
  • cout<< Accounts::iRecordNo; /* Shows 20. Accesses iRecordNo variable inside Accounts namespace */
  • cout<< Accounts::Reports::iReportNo; /* Shows 45. Accesses iReportNovariable inside Reports namespace which is inside Accounts namespace */
  • ​​​​​​​Accounts::Reports::Print(); // Shows Print 123
  • We can also use the "using" keyword as follows:
    using namespace Accounts::Reports;
    void main()
    {
        cout<< iReportNo; /* Shows 45. Because we are using Accounts::Reports */
        cout<< Accounts::iRecordNo; /* Shows 20. Accesses iRecordNo variable         inside Accounts namespace */
    }
Namespaces can be nested at any level. In the example given below, we have 4-level nesting of namespaces:
namespace A
{
    namespace B
    {
        namespace C
        {
            namespace D
            {
                int Value=123;
            }
        }
    }
}		Here, we can access variable Value in following ways:
----------------------------------------------
A::B::C::D::Value=45;
----------------------------------------------
using A::B::C::D;
void main()
{
    Value=45;
}
----------------------------------------------
using A::B::C;
void main()
{
    D::Value=45;
}
----------------------------------------------
using A::B;

{
    C::D::Value=45;
}
Global namespace
Variables and functions which are defined globally are in the global namespace. This is the default namespace. But in some cases, we need to explicitly specify it. This is as shown below:
int total=45;
void main()
{
    int total=20;
    cout<< total; // output is 20
    cout<< ::total; // output is 45
​​​​​​​}		Here, we have variable with same name in local scope as well as in global scope. Inside the function, by default local variable is accessed. But if we want to access the variable from global scope (instead of local scope), we have to explicity mention the global namespace with the given syntax:
::<Variable Name> 
This can be used in following cases also:
void Display()
{
    cout<<"Display from global namespace called";
}
namespace X
{
    void Display()
    {
        cout<<"Display from namespace X called";
    }
}		using namespace X;

void main()
{
    Display(); /* X's Dsiplay called because we are using namespace X  */

    ::Display(); // Global Display function called.  
}
