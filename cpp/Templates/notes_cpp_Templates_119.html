Templates
  • Many times in programming, we write some code for implementing some algorithm which is same for parameters of all data types. For example, the algorithm for adding two numbers is same for adding two int as well as for two floats and two doubles etc. In such cases, we can write many add functions with same name but different signatures (due to function overloading), but in each function the programming logic is exactly same. To avoid such repetition of programming logic, we write the logic without mentioning data type of the parameters. We just write the logic for a data type, say T and mention the value of T at the time of actual use of that function.
  • Such type of programming where algorithms are implemented without mentioning a specific data type of parameters, is called as generic programming. 
  • Templates are used in C++ for writing such generic code which can work for different data types. The data type is mentioned directly or indirectly at the time of use of that code.
Need of template
Many times, we write code whose algorithm (logic) is same for all types of data on which it works. For example, the logic of addition of two number is same but we have to write it separately for each data type as follows: 
int Add(int a, int b)
{
    return a+b;
}		float Add(float a, float b)
{
    return a+b;
}		double Add(double a, double b)
{
    return a+b;
}
Note that:
  • Function overloading allows us to just keep same name for different functions as above but we have to write separate functions for supporting different data types for additions.
  • Templates solve this problem. Using templates we just write the business logic without mentioning the type of data. The type of data is specified when we actually use that template for some data type.
  • Based on this actual data type, compiler creates separate versions of the template function, if not already created or present, for each data type as and when needed. So note here that, the compiler creates (instantiates) actual function with types from the function template, as and when needed.
  • This instance of function created from function template is then called by the compiler.
Difference between function overloading and function templates
Function overloadingFunction template
It allows us to write multiple functions with same name, provided the function signature is different. It allows us to write the programming logic without mentioning the data type.
As, we are writing separate function for different data types, the programming logic for different data types can be different. Programming logic should be same for different data types.
We have to write all the functions explicitly. Compiler simply calls the most suitable function from all available options.We have to just write one function template. Compiler generate different functions for different data types from the function template. These functions, generated by compiler are then called by compiler.

The concept of generic programming using templates, is applicable at function level as well as class level. Hence, we will see it in use for both.

Function template
  • Function template is a function in which the programming logic is written without mentioning the specific data type for that logic. It is written for an unknown data type say, T. 
  • When the function is called, compiler check the actual type of data passed as parameter and create a new function with that data type and then calls that function.
template <typename T>
T Add(T a, T b)
{
    return a + b;
}		Here, the logic for addition of two numbers is written without specifying any data type. It is written for an unknown data type T.
int main()
{
    int a = 12;
    int b = 23;
    cout<<Add(a, b); /* Here compiler uses the template function and creates a new function with T=int and calls it with a=12 and b=23 */

    double d1 = 12.3;
    double d2 = 0.85;
    cout << Add(d1, d1); /* Here compiler uses the template function and creates a new function with T=double and calls it with a=12.3 and b=0.85 */

    int x = 34;
    int y = 65;
    cout<<Add(x, y); /* Here compiler knows that it has already created a function for T=int in earlier step and hence simply uses that function with a=34 and b=65 */
        
    cout << Add(45.2, 81.6); /* Here compiler knows that it has already created a function for T=double in earlier step and hence simply uses that function with a=45.2 and b=81.6 */
}    
Class template
Sometimes the entities we model by creating a class are independent of the type of data of its data members. For example, the abstraction as well as behavior of Stack is same for stack of int as well as stack of float and doubles etc.
In such situation, if we write the class itself in the form of a template, without mentioning the data type on which it is working. Such classes are called as template classes. Such type of programming is called as generic programming. 
​​​​​​​
Class declaration in stack.hClass definition in stack.cpp
template <typename T>
class Stack
{
    T arr[5];
    int top;
public: 
    Stack();
    void Push(T);
    T Pop();
    void Display();
};		template <typename T> Stack<T>::Stack()
{
    top = 0;
}
template <typename T> T Stack<T>::Pop()
{
    if (top == 0) return -1;
    else return arr[--top];
}
template <typename T> void Stack<T>::Push(T a)
{
    if (top == 5) return;
    arr[top++] = a;
}
template <typename T> void  Stack<T>::Display()
{
    for (int i = 0; i < top; i++)
        cout << arr[i] << endl;
}
Using the template class in main.cpp
void main()
{
    Stack<int>  s1; /* Here template class stack is created with T=int by the compiler and then its object s1 is created*/

Overloading function template
In the previous example, we have created a function template for addition of two variables of type T. This template will be used by template for generating functions for adding two int, float etc. But what if we have to add 3 variables? The template of two Ts can't be used here. We have to create another template with 3 Ts as follows:
Template for addition of two numbers    Template for addition of 3 numbers
template <typename T>
T Add(T a, T b)
{
    return a + b;
}		template <typename T>
T Add(T a, T b, T c)
{
    return a + b + c;
}
int main()
{
    int a = 12;
    int b = 23;
    cout<<Add(a, b); /* The first template is instantiated with T=int and called with a=12, b=23 */

    int c = 45;
    cout << Add(a, b, c); /* The second template is instantiated with T=int and called with a=12, b=23 and c=45*/
}
Here we have overloaded the template function itself. First having two Ts and second having 3 ts. This is called as overloading of function template.
Template with multiple parameters
Till now, we have seen templates with only one unknown data type T. In such cases, it is compulsory that all parameters MUST have same data type at the time of using that template. For example, both parameters must be int or both must be float etc. If we want that the user should have freedom to mention different paramters, we should create template with multiple parameters. 
​​​​​​​This can be applicable for function template as well as class template. Lets see each of them now.
Function template with multiple template parameters
Consider the function template Add with T as the template parameter. While using this function template, we have to pass both paramters of same data type, either both int or both float and so on. What if we want to add two number where the first might be int and second might be float. The template with one parameter can't be used in these situations. We need to create a template function with 2 unknown parameters to handle such scenarios, as follows:
template <typename X, typename Y>
void Add(X a, Y b)
{
    cout<<( a + b );
}		Here, X and Y are two templates parameters. Now add function can be called with any two different parameters in any order.

However, the return type must be specified either as X or Y. This can put limitations on the usage of such templates. Hence we have simply added the two numbers and displayed them in the function itself.
int main()
{
    Add(23.4, 12); /* Here template is instantiated with X=double and Y=int and then called with a=23.4 and b=12*/

    Add(23.4f, 0.3); /* Here template is instantiated with X=float and Y=double, and then called with a=23.4f and b=0.3*/
}

Default values for template parameters
We can even assign default values for template parameters of a class as follows. In such case, the default value of data type will be considered if not mentioned explicitly.
template <typename T=int>
class Stack
{
    T arr[5];
    int top;
public: 
    Stack();
    void Push(T);
    T Pop();
    void Display();
};		Here T will be considered as int, if not mentioned explicitly
void main()
{
    Stack<>  s1; /* s1 will be stack of int because value for T is not mentioned, so default will be considered*/
    s1.Push(1);
    s1.Push(2);
    s1.Push(3); 

    Stack<float>  s2; /* s2 will be stack of float because value for T is mentioned, so default will be ignored*/
    s2.Push(1.2f);
    s2.Push(34.2f);
    s2.Push(35.7f); 
}
Template specialization
  • There are situations where we have exactly same algorithm for all data types except few of them. For example, the algorithm for adding two int, float, long, double etc is exactly same. (We just add the first parameter with the second parameter). But addition of two strings is done differently. In that case, we use strcat function to appends the second string to the first one.
  • In such case, we cases, we write a template function for addition BUT for adding two strings, we write a special function that accepts two char*. 
  • Here when the function is called with other data types, the template function is called but when two char* are passed, the special function is called. 
  • At the time of calling the function, the compiler first checks if a specialized function is available. If yes, that function is called. If no, it uses the function template.
  • This is called as template specialization. 
  • In the above case, we say that the addition function template is specialized for char* 

This is as shown below:
template <typename T> T Add(T a, T b)
{
    return a + b;
}		This is a generic function template written for data type T. Values of T is decided by the compiler during the function call.
BUT
Only for char* type of data, we create a separate function, because algorithm of addition of numbers is not suitable for addition of two char*
char ans[200];
char* Add(char* a, char* b)
{
    memset(ans, 0, 200);
    strcpy(ans, a);
    strcat(ans, b);
    return ans;
}		This is how two strings are added in C++. We have created a separate function only for adding two char*.

void main()
{
    char str1[100]; 
    char str2[10];

    cout<< Add(12, 13)<<endl; // Here function template is used with T=int 
    cout << Add(12.3, 13.5) << endl; // Here function template is used with T=double 
    cout << Add(str1, str2) << endl; // Here specialized function char* Add(char*, char*) is used
}
