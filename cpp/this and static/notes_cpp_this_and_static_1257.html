this and static
Here we will see following important concepts in C++. These concepts are appliable for all object oriented languages with little difference in syntax.

this
​​​​​​​"this" is an hidden local variable created by the compiler in every non-static member function of a class. It is actually a pointer that points to the object that has called the function (invoking object).
  • It is automatically created by the compiler, in every non-static member function of a class.
  • It is a local variable of that member function. It gets created automatically on the stack when the function is called and gets removed from the stack when the function returns.
Consider class Date
class Date {
    int d, m, y;
    public:
    void getDay() {
        //  this pointer refers to invoking object.
        // Here, its data type is Date*
    }
};		#include"date.h"

void main() {
    Date d1;
    Date d2;
    d1.getDay(); // In this function call, this points to d1
    d2.getDay(); // In this function call, this points to d2
}
Now consider class Person
class Person {
    char name[30];
    int age;
    public:
    void getName() {
        //  this pointer points to invoking object.
        // Here, its data type is Person*
    }
};		#include"person.h"
​​​​​​​
void main() {
    Person p1;
    Person p2;
    p1.getName(); // In this function call, this points to p1
    p2.getName(); // In this function call, this points to p2
}
Note that:
  • this pointer is created only for non-static member functions of a class
  • Global functions don't have this pointer.
  • Static member functions don't have this pointer
Use of this pointer
"this" pointer is used for following purposes in C++ program.
1To void masking of data member by a local variable.

class Date {
    int d, m, y;

public:
    // Note that here parameter names are same as names of data members
    Date(int d, int m, int y) {

        d=d; /*Wrong: Parameter being a local variable, it gets assigned to itself. This is called as self-assignment. Our intention is to assign value of parameter d to data member d, which fails due to same name. This is called as variable masking or variable shadowing. */

    /* To avoid this, we specify explicitly that local variable d should be assigned to data member d, as follows */
    this->d=d; /* Now data member d gets initialized with parameter. Also note that this is a pointer, so -> operator is used to access the data member */
    }
};
2To return invoking object from a member function

class Date {
    int d, m, y;
public:    
    Date someFunction() {
        return *this; /* Invoking object is returned here. Note that this is a pointer to invoking object, so *this is the invoking object itself */
    }
};
3To delete the invoking object (if it is created dynamically)

delete this; // Note that "this" is a pointer to invoking object, so delete this will delete the invoking object itself*/
/* delete this should be used only for dynamically created object using new. For other objects such code will result into access violation error */
static
Static keyword is used in C++ to create static data and static functions. Lets understand them in detail.

Static data
  • Static keyword is used to create a data member that is common for all objects of that class. 
  • Non-static data is created separately for all each instance. Hence, they are also called as instance variables.
  • This is used to stored some information that is guaranteed to have same value for all instance of that class. However, note that the value of static data member CAN be changed. Just one copy of that variable will be shared by all instances of that class.
  • Static data doesn't get created when objects are created. They must be created through explicit declaration outside the class (as shown below)
class Date {
    int d, m, y; /* Non-static data members of the class. Created separately for each instance of date */

    static int count; /* Static data member of class. Created only once and shared by all instances of date */
}		int Date::count=0; /* Static data member must be created explicitly */

void main()
{
        Date d1;
        Date d2;
        /* Note that data members d, m and y are created for d1 and d2 separately. However, count, being static, gets created only once and is shared by d1 as well as d2. */
    }
Example of static data member:
  • Count of objects for various classes
  • Rate of interest for bank account.
  • Registration fees for all bikes
  • Exam schedule for all students of a class 
 
Static functions
  • Static functions are the member functions of a class that can be called without using object of that class. They are called using just the name of that class and scope resolution operator.
  • As static functions don't have invoking object, they don't have "this" pointer.
  • Static functions can access ONLY static data members. However, non-static functions can access static as well as non-static data members.

class Date {
    int d, m, y; /* Non-static data members.*/
    static int count; /* Static data member */

public:
    // constructor is a non-static member function
     Date() {
        d=m=y=0; // Can access non-static data 
        count++; // Can access static data also
        this.d=10; // Can use this reference
    }

     // This is a static member function.
    static int getCount() {
        d=0; // ERROR. Can't access non-static data member
        return this->count; // ERROR. Don't have this pointer
        return count; // Can access static data member
    }
}		void main()
​​​​​​​{
        Date d1;
        Date d2;
        /* static functions can be called using class name and scope resolution operator */
        int iCountOfObjects= Date::getCount();
}
