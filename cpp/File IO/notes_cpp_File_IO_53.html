File IO
State of an application must be maintained permanently so that in the next session of the application this state can be regained. Maintaining this state on the hard-disk is a common, simple and less costly option. C++ simplifies this task of reading and writing data in files by encapsulating these operations in some in-built classes. This can be done either in text mode or binary mode. We can also customize the output on console using various manipulators. 

Following are the points we will see in this topic:
  1. IO class hierarchy
  2. Basic file operations
  3. Text Input Output
  4. Binary Input Output
  5. Console Input Output

Basic file operations
Following are some basic operations we do in every file input/output operation.
  • Open a file
  • Close a file
  • Check status of file.
  • Position the file stream pointer

Lets understand these operation in detail.
Open a file
For opening a file, we need to call a member function "open" in the stream object. This function accepts two parameters, first is the file path and second is mode of opening the file.
Syntax:open (filename, mode);
  • "filename" is a string representing the name of the file to be opened.
  • "mode" is an optional parameter with a combination of the following flags.
ios::inOpen for input operations.
ios::outOpen for output operations.
ios::binaryOpen in binary mode.
ios::ateSet the initial position at the end of the file. If this flag is not set, the initial position is the beginning of the file.
ios::appAll output operations are performed at the end of the file, appending the content to the current content of the file.
ios::truncIf the file is opened for output operations and it already existed, its previous content is deleted and replaced by the new one.
The mode parameter has default values for following classes.
classDefault value of mode
ifstreamios::in
ofstreamios::out
fstreamios::in | ios::out
Lets understand this through some examples:
ofstream myfile; 
myfile.open ("mydata.txt");


File is opened for writing in text mode. If the file is already present, its content is automatically deleted. As the default value for mode is ios::out, this line is same as 
myfile.open ("mydata.txt",ios::out);
ofstream myfile; 
myfile.open ("mydata.txt", ios::app);		File is opened for writing in text mode. If the file is already present, its content is NOT deleted. The new content is written at the end because the file is opened in append mode.
ofstream myfile;
myfile.open ("mydata.bin", ios::binary);		File is opened for writing in binary mode. If the file is already present, its content is deleted. 
ofstream myfile;
myfile.open ("mydata.bin", ios::out | ios::app | ios::binary);		File is opened for writing in binary mode. If the file is already present, its content is NOT deleted. The new content is written at the end because the file is opened in append mode.
Also note that here ios::out is not compulsory, because its the default value for ofstream.
Close a file
When we are finished with our input and output operations on a file we must close it so that the operating system is notified and its resources become available again. For that, we call the stream's member function "close". This member function takes flushes the associated buffers and closes the file:
ofstream myfile; 
myfile.open ("mydata.txt", ios::app);
...
myfile.close();
  • Once this member function is called, the stream object can be re-used to open another file, and the file is available again to be opened by other processes.
  • If the ofstream object gets destroyed while without closing the file explicitly, the destructor automatically calls the member function "close".
Check status of file
The following member functions can be used to check for specific states of a stream (all of them return a bool value)
bad()Returns true if a reading or writing operation fails. For example, in the case that we try to write to a file that is not open for writing or if the device where we try to write has no space left.
fail()Returns true in the same cases as bad(), but also in the case that a format error happens, like when an alphabetical character is extracted when we are trying to read an integer number.
eof()Returns true if a file open for reading has reached the end.
good()It is the most generic state flag: it returns false in the same cases in which calling any of the previous functions would return true. Note that good and bad are not exact opposites (good checks more state flags at once).
clear()The member function can be used to reset the state flags.
File stream positioning operations
The current position the file will read data from, is maintained by a file pointer called as get pointer. Similarly, the current position the file will write data to, is maintained by a file pointer called as put pointer.
The pointer positions are counted from following reference positions: 
ios::begFile pointer offset counted from the beginning of the stream
ios::curFile pointer offset counted from the current position
ios::endFile pointer offset counted from the end of the stream
We can get information about these pointer position as well as set their positions with the help of following functions.
tellg()Returns the current position of get pointer
tellp()Returns the current position of put pointer
seekg (n); The stream get pointer is changed to the absolute position "n" (counting from the beginning of the file)
seekp (n); The stream put pointer is changed to the absolute position "n" (counting from the beginning of the file)
seekg (n,ios::cur); The stream get pointer is changed to the position "n" from the current position.
seekp (n,ios::cur); The stream put pointer is changed to the position "n" from the current position.
Using file seek operations
// Finding file size
#include <iostream>
#include <fstream>
using namespace std;

int main () {
  streampos begin,end; // begin and end are of type streampos
  ifstream myfile ("myimage.jpg", ios::binary); // Open a file (in this case a binary file is opened)
  begin = myfile.tellg(); // This will return current position from beginning
  myfile.seekg (0, ios::end); // Move the get pointer to the end position
  end = myfile.tellg(); // Now get the position
  myfile.close(); 
  cout << "size is: " << (end-begin) << " bytes.\n"; // Size of file is diff between the end and begin positions
  return 0;
}


Text Input Output
Text files, as the name indicates, store text data. Text file streams are created without setting the ios::binary flag in their opening mode. These files are designed to store text data.

Reading text from file can be done in following 3 ways:
  1. Reading character-by-character
  2. Reading word-by-word
  3. Reading line-by-line

Binary Input Output
For reading the binary file, first we need to open the file in binary mode. Once the file is opened, we have to ready the data as a memory block, having starting position and size.
File streams include two member functions specifically designed to read and write binary data sequentially:
  1. write: is a member function of ostream (inherited by ofstream)
    write ( memory_block, size );
  2. read: is a member function of istream (inherited by ifstream)
    read ( memory_block, size );
​​​​​​​
Here, memory_block is of type char* (pointer to char), and represents the address of an array of bytes where the read data elements are stored or from where the data elements to be written are taken. The size parameter is an integer value that specifies the number of characters to be read or written from/to the memory block.

This is as shown below:
// reading an entire binary file
#include <iostream>
#include <fstream>
using namespace std;

int main () {
  streampos size;
  char * memblock;

  ifstream file ("example.bin", ios::in|ios::binary|ios::ate); /* Note that the file is opened in ate mode. Hence the put and get pointers are already at the end position */
  if (file.is_open())
  {
    size = file.tellg(); // Here, tellg directly gives the end position from the beginning. Hence, this is data size
    memblock = new char [size]; // Allocated a block of memory 
    file.seekg (0, ios::beg); // Now move the get pointer at start
    file.read (memblock, size); // And read entire block of file-size
    file.close();

    cout << "the entire file content is in memory";

    delete[] memblock; // Delete the block of memory allocated by new. Else this is memory leakage.
  }
  else cout << "Unable to open file";
  return 0;
}
Console Input Output
In C++ Programming, the console IO operations are performed using the header file iostream.h. This header file provides two objects cin and cout to perform input and output operations respectively.

There are mainly two types of console IO operations.
1. Un-formatted console IO 
2. Formatted console IO
Un-formatted console IO
Here, we read/write the data from the standard input/output devices in following three ways:
  1. Char by char
  2. Word by word
  3. Line by line

1. Read/write character by character
The get() is a method of cin object used to input a single character from the standard input device (keyboard). Its main property is that it allows wide spaces and newline character. The get() function does not have any return value (void get()).
The put() is a method of cout object and it is used to print the specified character on standard output device (monitor).
This is shown in the example given below:
#include <iostream>
using namespace std;
int main()
{
    char ch;

    cout<<"Press any key: ";
    ch = cin.get(); /*This will wait for the user to press a key on keyboard. Once pressed, it returns that char value */

    cout << "You have pressed: ";
    cout.put(ch); /* This function will put one char at a time on the std output device */

    return 0;
}

2. Read/write word by word
We have already used cin and cout for reading and writing character arrays delimited by white space characters. This is as shown below:
#include <iostream>
using namespace std;
int main()
{
    char Name[60];
    cout<<"Enter your name: ";
    cin>> Name;  // This reads only one word at a time, delimited by white spaces

    cout << "Your name is: "<< Name; 
    return 0;
}

3. Read/write line by line
The getline(char *buffer,int size) is a method of cin object and it is used to input a string with multiple spaces.
The write(char * buffer, int n) is a method of cout object and it is used to read n character from buffer variable.
#include <iostream>
using namespace std;
int main()
{
     char ch[128];
    memset(ch, 0,128);

    cout << "Enter your full name: ";
    cin.getline(ch, 128); // This will read entire string till you hit enter, including spaces.
    cout.write(ch, 128);
    return 0;
}
Formatted console IO
The C++ programming language provides the following built-in functions to display the output in formatted form.
These built-in functions are available in the header file iomanip.h
  1. setw(int): This is a method used to set width of the output.
  2. setfill(char): This is a method used to fill specified character at unused space.
#include <iostream>
#include <iomanip>
using namespace std;

int main()
{
    int x = 10;

    cout << setw(10); /* We set min width of 10 characters and then display int x */
    cout << x << endl; /* First 8 positions will be empty and then 10 will be displayed */

    cout << setw(10) << setfill('*') << x << endl; /* Here, using setfill, we specify the character to be used at empty positions, instead of space (by default) */

    return 0;
