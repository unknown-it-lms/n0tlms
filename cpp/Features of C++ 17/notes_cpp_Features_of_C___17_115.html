Notes: cpp- Features of C++ 17

C++ 17
C++17 introduced several new features and improvements to the language and the Standard Template Library (STL). These changes aim to make C++ code more concise, readable, and efficient.

Following are some of the important features introduced in C++ 17 version:
  1. Nested Namespaces
  2. Variable declaration in if and switch
  3. if constexpr statement
  4. Structured bindings
  5. Fold Expressions
  6. Direct list initialization of enums
Nested Namespaces
Namespaces are used to group together similar codes like classes and functions that are correlated. C++17 allows more easy syntax of using nested namespaces. Earlier the syntax was quite complicated when the number of nested namespaces increases. This is simplified in C++ 17 as follows:
Old version of C++In C++ 17 version
namespace Documents {
    namespace Reports {
        namespace Accounts {
            
            class AuditReport {
            }
        }
    }
}		namespace Documents :: Reports ::  Accounts {
            class AuditReport {
            }
}
Lot of opening and closing brackets are needed for nested namespaces as shown above. This can make the code difficult to read and maintain.Nesting of namespaces is indicated by :: instead of opening and closing brackets. The code is more readable and easy to maintain.
Benefits
  1. Improves the code readability by eliminating the need of unnecessary brackets.

Variable declaration in if and switch
C++17 introduced a feature allowing variable declaration and initialization directly within if and switch statements, enhancing code conciseness and scope management. This is known as "selection statements with initializers."
If Statement with Initializer:
SyntaxExample
if (init-statement; condition) {
    // Code to execute if condition is true
} else {
    // Code to execute if condition is false
}		if (double marks = getMarks(); marks > 40) {
    std::cout << "You scored "<< marks <<". Result is Pass";
} else {
    std::cout << "You scored "<< marks <<". Result is Fail"
}
// marks is not accessible here
Note that the variable initialized inside the if condition, is accessible only in the if block and the else block. It is NOT accessible else where. Note that the variable marks is accessible in if block as well as else block. It is not accessible elsewhere
Switch Statement with Initializer:
SyntaxExample
switch (init-statement; controlling-expression) {
    case value1:
        // Code for value1
        break;
    case value2:
        // Code for value2
        break;
    default:
        // Default code
        break;
}		switch (int val = getUserInput(); val) {
    case 1:
        std::cout << "Option 1 selected.\n";
        break;
    case 2:
        std::cout << "Option 2 selected.\n";
        break;
    default:
        std::cout << "Invalid option.\n";
        break;
}
// val is not accessible here
Note that the variable initialized inside the switch condition, is accessible only in the switch block. It is NOT accessible else where. Note that the variable val is accessible in switch block. It is not accessible elsewhere
Benefits
This offers following benefits to the programmer:
  1. Promotes cleaner code by keeping related variable declarations close to their usage.
  2. Automatically managing their scope
  3. Reduces the chance of name collisions
  4. Improves code readability.

if constexpr statement
In C++17, constexpr indicates that an entity (variable, function, or object) can be evaluated at compile time, allowing for compile-time constant expressions. This enables optimizations and compile-time checks, particularly in generic programming and template meta programming.

Regular if statement evaluates its condition at run-time, but if constexpr evaluates its condition at compile time, and only the chosen branch is compiled, while the other branches are discarded. 
Syntax
template <typename T>
auto process(T value) {
  if constexpr (std::is_integral<T>) {
      return value * 2; // Only compiled if T is an integral type
      } else {
           return value; // Only compiled otherwise    
        }
    }
Benefits
  1. Code is highly optimized.
  2. Compile-time checking is done

Structured bindings
These are used to declare multiple variables to be initialized with values in a pair, tuple etc. All these binding of variables with initializers done in a single statement. It basically allows you to declare multiple variables that are initialized with values from pairs, generic tuples or from custom structures and these multiples variable declarations happens in single statements.

Binding to Array
int arry[3] = { 3,4,5 };
auto [a,b,c] = arry;
// here array is created and a refers to 3, b refers to 4 and c refers to 5.
Binding to Tuple
float fnum{};
char ch1{};
int number{};
std::tuple < float&, char&&, int > tplex( fnum, std::move(ch1) , number);
const auto& [ p, q, r] = tplex;
// p is name of structured binding referring to fnum
// q is name of structured binding referring to ch1
// r is name of structured binding referring to number
Binding to structure

struct structVar {
mutable int num1 : 2;
volatile double num2;
};

structVar func();
const auto [ a, b] = func();
// a is an int lvalue for the 2-bit bit field
// b is a const volatile double lvalue

Benefits
  • Improves code readability where lot of variables need to be initialized to default values or from some other sources like array or structure.

Fold Expressions
Fold expressions, provide a concise and elegant way to apply a binary operator (like + - * / << >> etc) over a parameter pack in variadic templates. They are used to write shorter codes for a variable number of arguments that can be passed to a function or can be returned from the function. It enables the use of any number of variables as arguments and in return statements of a function.


SyntaxExplanation
#include <iostream>

template<typename... Args>
auto sum(Args... args) {
    return (args + ...);
    // Unary right fold for addition operator
}

int main() {
    std::cout << "Sum: " << sum(1, 2, 3, 4, 5);    return 0;
}
Output: 
Sum : 15		Here, the function sum accepts variable number of arguments args (Also called as 'pack'). 

The statement args + ... applies the binary addition operator (+) on the pack args. As the fold operator is on the right hand side, it is called as unary right fold for addition
#include <iostream>

template<typename... Args>
void print_all(Args... args) {
    (std::cout << ... << args) << std::endl;
    // Unary left fold for insertion operator
}

int main() {
    print_all("Hello", ", ", "world", "!");
    return 0;
}
Output:
Hello, world!		Here, the function print_all accepts variable number of arguments args (Also called as 'pack'). 

The statement ... << args applies the insertion operator (<<) on the pack args. As the fold operator is on the left hand side, it is called as unary left fold for insertion
Important:
​​​​​​​
Unary right fold - ( pack op1 ... ) // One operator op1 on the right hand side of pack
Unary left fold - ( … op1 pack ) // One operator op1 on the left hand side of pack
Binary left fold - ( init op1 … op1 pack ) // Two operators op1 and op2 on the left hand side of pack
Binary right fold - ( pack op1 … op1 init ) // Two operators op1 and op2 on the right hand side of pack
Benefits
  • Provide a concise and expressive way to work with parameter packs in C++
  • Reduces the need for complex recursive code.
  • ​​​​​​​More readable and maintainable code.

Direct list initialization of enums
Direct-list initialization of enumerations allows for the initialization of enum variables using brace-enclosed initializer lists. 

Syntax
enum class Color : uint8_t {
    Red,
    Green,
    Blue
};
int main() {
    Color myColor{Color::Red}; // Initializes with an enumerator
    Color anotherColor{1}; // Initializes with an integer value 
}


enum Shape : int {
Circle,
Square
};
int main() {
    Shape myShape{Shape::Circle}; // Initializes with an enumerator
    Shape anotherShape{0}; // Initializes with an integer value 
}
Benefits
  • Direct-list initialization provides a more explicit and type-safe way to initialize enums
