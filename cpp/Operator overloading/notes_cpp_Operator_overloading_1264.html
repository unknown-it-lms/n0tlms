Notes: cpp- Operator overloading

Operator overloading
Every programming language provides various operators for performing various mathematical as well as logical tasks. Such operators are broadly classified into following categories:

  • Binary operators (Like + - * / % = == != <= >= += etc, which operate on two operands)
  • Unary operators (Like ++ -- - etc, which operate on only single operand)

However, these operators work only on the built-in data types like int, float, double, char etc. The feature of operator overloading in C++ extends the use of such operators on user-defined data types (like objects of various classes created in our program). 
Need of overloading operator 
  • If necessary operators are overloaded, use of user-defined objects in mathematical as well as logical operations becomes very easy and exactly similar to built-in data types.
  • For example, it is easier to add two complex numbers c1 and c2 using an expression c1+c2, instead of calling member function like c1.Add(c2)

Now we will see, overloading of:
​​​​​​​
  1. Binary operators
  2. Unary operators
  3. Pre and Post operators
  4. cin and cout operators
  5. Special operators
Overloading Binary operators
Here, we will see how we can extend the functionality of binary operators, so that they can be used with user-defined data types like class Complex, class Date, class Person etc.
Steps for overloading binary operators:
  • For overloading a binary operator, say +, for a class, say Complex, we have to define a function with name operator+ that accepts object of Complex type as parameter. It should return object of type Complex, because addition of two complex numbers is also a complex number. 
  • Now, when we use this operator with objects of class Complex (like c1 + c2), the compiler uses the left side operator to invoke the function "operator+" and passes the right side object as parameter.
  • Inside the function "operator+", we can access the state of left side object using "this" pointer (because the left side object is the invoking object) and that of right side object using the function parameter.
complex.hcomplex.cpp
#include<iostream>
using namespace std;
class Complex
{
    int real;
    int imag;
public:
    /* Constructors and other member function written here... */
    Complex operator+(Complex); /* Declaration of overloaded + operator */
    void Display();
};		#include"complex.h"
// Definition of overloaded + operator
Complex Complex::operator +( Complex arg)
{
    Complex temp;
    temp.real = this->real + arg.real;
    temp.imag = this->imag + arg.imag;

    return temp;
}
main.cpp
#include "complex.h"
void main()
{
    Complex c1(12, 13);
    Complex c2(2, 3);
    Complex c3 = c1 + c2; /* Replaced by compiler as c1.operator+(c2) */
    c3.Display();
}		Output:
14+16i /* Note that real of c3 is sum of real of c1 and real of c2. imag of c3 is sum of imag of c1 and imag of c2. */

In similar manner, we can overload:
  • binary - operator by defining function operator-
  • binary * operator by defining function operator*
  • binary / operator by defining function operator/
  • binary % operator by defining function operator%
Overloading Unary operators
Here, we will see how we can extend the functionality of unary operators, so that they can be used with user-defined data types like class Complex, class Date, class Person etc.
Steps for overloading unary operators:
  • For overloading a unary operator, say -, for a class, say Complex, we have to define a function with name operator-. It should return object of type Complex, because - of complex numbers is also a complex number whose real and imag values are negative of original values. 
  • Now, when we use this operator with objects of class Complex (like -c1), the compiler uses the object to invoke the function "operator-" ( like c1.operator-() ).
  • Inside the function "operator-", we can access the state of left side object using "this" pointer (because the object is the invoking object).

Lets understand this by overloading unary operator -
complex.hcomplex.cpp
#include<iostream>
using namespace std;
class Complex
{
    int real;
    int imag;
public:
    /* Constructors and other member function written here... */
    Complex operator-(); /* Declaration of overloaded unary - operator */
    void Display();
};		#include"complex.h"
// Definition of overloaded unary - operator
Complex Complex::operator-()
{
    Complex temp( -this->real, -this->imag);
    return temp;
}
main.cpp
#include "complex.h"
void main()
{
    Complex c1(12, 13);
    Complex c2 = -c1; // Compiler calls c1.operator-()
    c1.Display();
    c2.Display();
}		Output:
12+13i
-12+ -13i
/* Note that real and imag of c2 have negative values, as per the definition of operator- */
Overloading pre and post operators
There are pre-increment and post-increment operators in C++ which behavior differently when used on a variable. The pre-increment operator first increments the value and then uses the incremented value in the expression. On the other hand, the post increment operator, first uses the current value in the expression and then increments the value. 

Lets first understand this on built-in data type like an int.
int a=10;
cout<< ++a; /* This is pre-increment, so a is first changed to 11 and then used in the expression. So output is 11. */
int a=10;
cout<< a++; /* This is post-increment, so a is first used in the expression, so output is 10, and then changed to 11 */
Steps for overloading unary increment/ decrement operators:
  • Overloading unary increment operator comes in two version, pre and post. Both versions need to be defined in a function with name operator++(), which is function overloading. However, this overloading is not possible, because there is no parameter to this function and hence both functions will have same signature.
  • To solve this problem, compiler passes a dummy int parameter to the post definition. This dummy parameter is passed ONLY to somehow create different signatures for the two versions of operator++. The dummy parameter should simply be ignored in our function definition. 

Lets understand this by overloading unary operator++
complex.hcomplex.cpp
#include<iostream>
using namespace std;
class Complex
{
    int real;
    int imag;
public:
    /* Constructors and other member function written here... */
 Complex operator++(); /* Declaration of overloaded pre-increment operator */
    Complex operator++(int); /* Declaration of overloaded post-increment operator */
  
    void Display();
};		#include"complex.h"
// Declaration of overloaded pre-increment operator
Complex Complex::operator ++()
{
    real++;
    imag++;
    return *this;
}
// Declaration of overloaded post-increment operator
Complex Complex::operator ++(int d)
{
    /* d is the dummy int passed by compiler just to somehow differentiate post from pre. Simply ignore it in function definition */
    Complex temp(*this);
    real++;
    imag++;
    return temp;
}
main.cpp
#include "complex.h"
void main()
{
    Complex c1(12, 54);
    Complex  c2= c1++; // Post increment
    c1.Display(); // 13+i55
    c2.Display(); // 12+i54

    Complex c3(12, 54);
    Complex  c4 = c3++; // Pre increment
    c3.Display(); // 13+i55
    c3.Display(); // 13+i55

}		Output:
13+i55
12+i54
13+i55
13+i55

In same way, we can overload unary operator-- as follows:
Complex operator(); // Pre-decrement 
Complex operator--(int); // post-decrement 
Overloading cin and cout
  • Overloading the insertion operator (<<) and extraction operator (>>) is different than overloading other operators. This is because, in all other operators, the user-defined object is on the left hand side, hence it is used for invoking the operator function. In case of cin and cout, we don't have object of our class on left hand side, it is on the right hand side.
  • To solve this case, compiler calls a global function with the name operator<< (or operator>>) and both the operands, LHS and RHS are passed as parameters to it.
  • So we should define the functions operator>> and operator<< accordingly.

Complex c1;
c1 +c2 // c1 is used as invoking object for calling the function operator+, because it is on LHS
c1++; // c1 is used as invoking object for calling the function operator++, because it is on LHS
cout << c1; /* c1 is on RHS. The object on LHS is not of our user defined class. So compiler calls operator<< (count, c1); */
Steps for overloading unary increment/ decrement operators:
  1. Define a global function with name operator<< having ostream as first parameter and Complex as second parameter. Read the private data members of complex object and show them on standard output device using ostream object
  2. Define a global function with name operator>> having istream as first parameter and Complex as second parameter. Read the values from standard input device using the istream object and assign them to the private data members of complex object.
  3. Note that we need access to the private data of complex class in both these overloaded functions. Hence, these functions should be declared as friend in the class Complex, as shown below. 

complex.hcomplex.cpp
#include<iostream>
using namespace std;
class Complex
{
    int real;
    int imag;
public:
    /* Constructors and other member function written here... */

    friend ostream& operator<<(ostream& out, Complex& c);

    friend istream& operator>>(istream& in, Complex& c);
};		#include"complex.h"
/* Note that operator<< and operator>> are global functions. They are not members of class Complex. But they are friend of class Complex */
ostream& operator<<(ostream& out, Complex& c)
{
    // Can access private data because it is a friend function
    out << c.real << "i" << c.imag<<endl;
    return out;
}
istream& operator>>(istream& in, Complex& c)
{
    // Can access private data because it is a friend function
    in>> c.real >>c.imag;
    return in;
}
main.cpp
#include "complex.h"
void main()
{
    Complex c1;
    cin>> c1; /* operator>>(cin,c1) gets called here */
    cout <<c1; /* operator<<(cout,c1) gets called here */
}
Overloading other operators
We can overload many other operators in the same way as follows:
class Complex
{
    int real;
    int imag;
public:
    operator[](int);
};		/* We can define the operator[] such that if the parameter is 0, we get real value of invoking complex object else if it 1 we get imag part of the complex number */
int Complex::operator[](int index)
{
    return index == 0 ? this->real : this->imag;
}
main.cpp
void main()
{
    Complex c1(12, 54);
    cout << c1[0] <<endl;
    cout << c1[1];
}		Output:
12
54

In the same way, we can overload other operators be defining member function with the name "operator followed by symbol of that operator".
For example,
  • for function call operator -> define function operator()()
  • for ! operator -> define function operator!()
  • and so on...
Operators that CAN NOT be overloaded:
Following operators cannot be overloaded in C++.
  • sizeof
  • typeid
  • Scope resolution (::)
  • Ternary or conditional (?:)
  • Class member access operators (. and .*)
