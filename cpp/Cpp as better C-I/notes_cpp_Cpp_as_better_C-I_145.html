History
C++ was originally invented in 1979 by the Danish developer Bjarne Stroustrup. However, it was only in 1983, that the first version of C++ was released to the public. It quickly gained popularity among programmers worldwide and was adopted by many companies as well. 
cin & cout
  • In C++, we can perform input and output functionality by using iostream. This stands for input and output, and this uses the stream to perform this functionality. In c++, stream stands or represents a sequence of character or byte which is used to perform input/output operations.
  • We must include iostream header file to input and output from a C++ program.

1. cout
  • cout is an object that represent standard output stream. It produces output on the standard output device, i.e., the display screen.
  • It is an instance of the ostream class.
  • We need to use the stream insertion operator << to insert data into the standard output stream cout, which has to be displayed on the screen.
  • This operator can be used in cascaded mode to display multiple variable in single statement.
 
Syntax:
   cout<<variable_name; // Used to display single variable
   cout<<variable_name1<<variable_name2; // Cascaded to display multiple variables
   cout<<"Any string literal"<<variable_name<<"String2";

2. cin
  • cin is an object that represents standard input stream. It reads input from the standard input device, i.e., the keyboard.
  • We need to use the stream extraction operator >> to extract data entered using the keyboard.

Syntax:
cin>>variable_name;
cin>>variable_name>>variable_name;
Code
#include<iostream> //Must include this header and use namespace std, for cin and cout
using namespace std;
int main()
{
    int a=12;
    float b=23.4;
    char ch='S';
    double d=34.56;

    /* String literal displayed on output device. endl adds a new line character */
    cout<<"Initial values:"<<endl;
    
    // cout shows value of variable a on screen
    cout<<a<<endl;

    // Cascaded output of many variables on screen
    cout<<b<<", "<<ch<<", "<<d<<endl;

    // cin accepts value for variable a from user
    cin>>a;

    /* cin accepts values for many variables (a, b, ch and d) in cascaded manner from user */
    cin>>a>>b>>ch>>d;

    // Now lets show the values entered by user
    cout<<"Values entered by user:"<<endl;
    cout<<a<<", "<<b<<", "<<ch<<", "<<d<<endl;
}
Default parameters
A default parameter is a value in the function declaration automatically assigned by the compiler if the calling function does not pass any value to that argument. This can be quite helpful if some parameters have same values in most of the function calls. Such values can be set as default so that we need not pass them in each function call.

For Example:
Suppose we want to write a function getDistance that accepts x and y coordinates of two points and returns the distance between them.
Code
double getDistance(int x1,int y1, int x2,int y2) 
{
    return sqrt(pow((x2-x1),2)+pow((y2-y1),2));
}		While calling this function, we have to pass all values x1, y1, x2, y2 as follows:
getDistance(12,2,54,23);
getDistance(2,5,34,85);
If want to calculate the distance of a point from origin, then in all such cases, values of x2 and y2 will always be 0 ,0. In such case instead of asking the user to pass these values, we can assign 0 and default value for parameter x2 and y2 as follows. In such case, if the user passes values for x2 and y2 explicitly, those values are considered but if the user doesn't pass these values, the default values will be considered.
double getDistance(int x1,int y1, int x2=0,int y2=0)
{
    return sqrt(pow((x2-x1),2)+pow((y2-y1),2));
}		Here default values 0 and 0 are assigned to parameters x2 and y2. These values will be used if not passed explicitly, as follows:

// This is same as getDistance(12,2,0,0);
getDistance(12,2);

// This is same as getDistance(12,2,34,0);
getDistance(12,2,34);

// This is same as getDistance(12,2,34,56);
getDistance(12,2,34,56);
Note that:
  • You can assign any values as default as long as its data type matches that of the parameter
  • Default values can be assigned only to the trailing parameters. For ex:

double getDistance(int x1,int y1, int x2=0,int y2=0); // Correct
double getDistance(int x1,int y1=25, int x2=0,int y2=0); // Correct
double getDistance(int x1=45,int y1=34, int x2=0,int y2=0); // Correct

double getDistance(int x1,int y1=34, int x2,int y2=0); // Wrong
double getDistance(int x1,int y1=34, int x2=0,int y2); // Wrong

Reference Variables
Reference variable is an alias created for existing variable. It is like nickname of a person.
CodeOutput
int main()
{
    int a=12;
    int &b=a; // Here b is a reference of existing variable 'a'
    cout<<"Value of a: "<< a <<endl; // Both a and b will show same values i.e. 12
    cout<<"Value of b: "<< b <<endl;
    cout<<"Address of a: "<< &a <<endl; // &a and &b will show same address
    cout<<"Address of b: "<< &b <<endl;
    b=25; // Assign value to b. It will get reflected in 'a' as well
    cout<< a <<endl; // 25
}		Value of a: 12
Value of b: 12
Address of a: 0x28fec8
Address of b: 0x28fec8
25
Note that:
  • A reference variable must be initialized else it will give error during compilation.
     int &c;         // Error. Reference variable MUST be initialized.
     int &c=b;    // Correct

  • Once initialized, a reference variable can't be set as alias of another variable.
    int a=12;
    int &b=a;    // b is another name of a
    int c=20;
    int &b=c;     // Error. Redefinition of variable b. It is already defined.
    b=c;          // Ok but Here b won't be set as alias of c. Just value of c will be assigned to b (which is alias of a)
  • Memory is NOT allocated for a reference variable. Just a name is created to existing variable. 
New Delete
​​​​​​​The "new" operator in C++ is used to allocate memory dynamically for a variable or an object at runtime. This means that the memory is allocated during the execution of the program, as opposed to being allocated at compile time.
new used to create one integer:Output
int main()
{
    int *p; // Pointer is created on stack but not initialized
    p= new int; // One int is created on heap. Its address stored in p
    *p=12; // Using pointer, value 12 is assigned to integer on heap
    cout<<*p; // Value of int pointed by p is accessed and displayed
    delete p; // int on heap which is pointed by p gets deleted.
    //Note that here p is NOT deleted
}		12
new for creating array of integers:Output
int main()
{
    int *p; // Pointer is created on stack but not initialized
    p= new int[5]; // Array of 5 int created on heap. Base address of array stored in p
    p[0]=10; // 10 assigned to element at 0 posltion
    p[1]=20; // 10 assigned to element at 1 posltion
    p[2]=30; // 10 assigned to element at 2 posltion
    p[3]=40; // 10 assigned to element at 3 posltion
    p[4]=50; // 10 assigned to element at 4 posltion
    for(int i=0;i<5;i++)
    {
        cout<<p[i]<<endl;
    }
    delete [ ] p; // Note that [ ] is used before p for deleting entire array of int on heap.
    // delete p; Wrong. This will delete only the first int from the array. 
}		10

new for creating string (array of char) 
#include<iostream>
#include<cstring> // Needed for memset and strcpy functions
using namespace std;
int main()
{
    char *p; // Pointer is created on stack but not initialized
    p= new char[50]; // Array of 50 char created on heap.
                                   // Base address of array stored in p
    memset(p,0,50); // Set all 50 char to 0 (which is null)
    strcpy(p,"Welcome to KNOW-IT, Pune"); // Copy string to p    
    cout<< p <<endl; // Show the value of p    
    delete [] p; // Entire array of char on heap which is pointed by p gets deleted.
}		Welcome to KNOW-IT, Pune
Note that:
  • new and delete are operators. 
  • Both these operators can be overloaded, if needed.
