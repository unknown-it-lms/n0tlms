React routing
​​​​​​​This is not core feture in React JS library. This needs to be installed so that all the components can be rendered as per the requirement of the user by selecting appropriate menu. Routing helps in maintaining single page application. It is even possible to dynamically render some component based on the outcome of business logic.
Need and installation
​​​​​​​In React, routers help create and navigate between the different URLs that make up your web application. They allow your user to move between the components of your app while preserving user state, and can provide unique URLs for these components to make them more shareable. With routers, user experience can be imprived by simplifying site navigation.
React Routing library
  • React Router is one of the most popular routing frameworks for React. 
  • It provides a declarative way to manage navigation and routing within your components.
  • By using React Router, it is possible to create dynamic routes(programmatic routes), nested routes, access data sent on URL while navigation
A Single-Page Application (SPA)
It is a web application where all the necessary code, HTML, CSS, and JavaScript, is loaded on a single page initially. Instead of reloading the entire page when the user interacts with different parts of the application, the SPA updates the content dynamically using JavaScript.
In single page apps, there is only single html page. We are reusing the same html page to render the different components based on the navigation.

Different components of routing
There are three primary categories of components in React Router:
  1. Routers, like <BrowserRouter> and <HashRouter>
  2. Route matchers, like <Route> and <Switch>
  3. Navigation, like <Link>, <NavLink>, and <Redirect>
Routers
At the core of every React Router application should be a router component. For web projects, react-router-dom provides <BrowserRouter> and <HashRouter> routers. The main difference between the two is the way they store the URL and communicate with your web server.
A <BrowserRouter> uses regular URL paths.
A <HashRouter> stores the current location in the hash portion of the URL, so the URL looks something like http://example.com/#/your/page. Since the hash is never sent to the server, this means that no special server configuration is needed.
Route Matchers
There are two route matching components: Routes and Route. Whenever the location changes, <Routes> looks through all its child routes to find the best match and renders that branch of the UI. This means that you should put <Route>s with more specific (typically longer) paths before less-specific ones. If no <Route> matches, it renders nothing (null).
One important thing to note is that a <Route path> matches the beginning of the URL, not the whole thing. So a <Route path='/'> will always match the URL. Because of this, we typically put this <Route> last in our <Switch>. Another possible solution is to use <Route exact path='/'> which does match the entire URL.
<Routes location>
  <Route />
</Routes>;
<Route> elements may be nested to indicate nested UI, which also correspond to nested URL paths. Parent routes render their child routes by rendering an <Outlet>.
<Routes>
  <Route path="/" element={<Dashboard />}>
    <Route path="messages" element={<DashboardMessages />}  />
    <Route path="tasks" element={<DashboardTasks />} />
  </Route>
  <Route path="about" element={<AboutPage />} />
</Routes>​​​​​​​
Navigation (or Route Changers)
React Router provides a <Link> component to create links in your application. Wherever you render a <Link>, an anchor (<a>) will be rendered in your HTML document.
<Link to='/'>Home</Link>
// <a href='/'>Home</a>
The <NavLink> is a special type of <Link> that can style itself as 'active' when its to prop matches the current location.
Adding routes
Using BrowserRouter
Entire application needs to be under the control of <BrowserRouter>. So in index.js, wrap <App> element in <BrowserRouter> like following:
const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(
    <BrowserRouter>
       <App />
    </BrowserRouter>
 );
Creating Links and matching Routes​​​​​​​
The App component will be used as a tab menu. The other three components (Home), (About) and (Contact) are rendered once the route has changed. Create very simple Home, About and Contact component.
export default function App() {

        </ul>

These different components can be thought of as different pages in the application. App component can be considered as the component which displays all the routing options available by displaying a kind of menu.

Dynamic routing
Programmatic Routing
in React refers to the ability to navigate between routes within your application using JavaScript code, rather than relying solely on user interactions like clicking links. This provides more flexibility and control over the navigation process. This is generally required when we want to redirect users to a different route based on certain conditions or when we want to share a URL of specific resource directly to the user.
useNavigate Hook returns a function that can be used to navigate to a specific route.
import { useNavigate } from 'react-router-dom';
  function MyComponent() {
      const navigate = useNavigate();
      const handleButtonClick = () => {
      navigate('/about');
  };
  return (
    <button onClick={handleButtonClick}>Go to About</button>
  );
}
For successful navigation, corrsponding <Route> should be defind for the path '/about'
Sending data on routes
In React Router, there are two primary methods to send data along with routes.
Using Path Parameters:
Path parameters are a way to dynamically pass data into a route in React Router. They're used to create more flexible and dynamic URLs.
Basic Syntax:
<Route path="/users/:userId" element={<UserProfile />} />
In this example, :userId is a path parameter. When a user navigates to a URL like /users/123, the userId variable in the UserProfile component will be set to 123.
Accessing Path Parameters:
To access path parameters within a component, useParams hook can be used
import { useParams } from 'react-router-dom';
function UserProfile() {
   const { userId } = useParams();
  // Use userId to fetch data or render content
   return (
     <div>
       <h2>User Profile: {userId}</h2>
       {/* ... */}
    </div>
  );
}
Using Query Parameters:
Query parameters are key-value pairs appended to the end of a URL, separated by question marks and ampersands. They're often used to pass additional data 
Basic Syntax:
<Route path="/search" element={<SearchPage />} />
To navigate to /serach with query parameters
navigate('/serach', { search: `name=${query}` }) 
Accessing query Parameters:
To access path parameters within a component, useLocation hook can be used
import { useLocation } from 'react-router-dom';
function SearchPage() {
  const { search } = useLocation();
  const queryParams = new URLSearchParams(search);
  const nm = queryParams.get('name');
  // Use the nm value for your search logic
  return (
    <div>
       <h2>Search Results for: {nm}</h2>
       {/* ... */}
    </div>
  );
}
