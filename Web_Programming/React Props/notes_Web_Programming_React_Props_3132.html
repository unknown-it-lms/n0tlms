React Props
In this topic we will look into how data can be passed to the component from external environment in the form of props and how it can be accessed in the class and functional components.
What are props
  • Props stand for "Properties".
  • Props are arguments passed into React components. Props are used to supply the data to the component from external environment. Props are used as read only fashion by the component.
  • Props are passed to components via HTML attributes.
  • React Props are similar to attributes in HTML.
  • To send props into a component, use the same syntax as HTML attributes.
  • It is an object which stores the value of attributes of a tag and work similar to the HTML attributes. It gives a way to pass data from one component to other components.
  • Props can be considered similar to function arguments. Props are passed to the component in the same way as arguments passed in a function.
  • If props are not passed then component can define some default value for that component.
Using props
To send props into a component, use the same syntax as HTML attributes. One component can be passed with multiple props while rendering. 
Using props with class componentRendering the component
class Welcome extends React.Component {  
   render() {     
      return (  
          <h1> Welcome {this.props.name} </h1>
      );  
   }  
}  
export default Welcome;
 <Welcome name="Monika" /> 

If data is in the form of variable, use curly braces for sending data as prop.
<Welcome name={nm}  /> 
where nm is variable having data.
Using props with functional componentRendering the component
function PropsFunComp(ps) {
    return (
        <div>
            <h1> Welcome { ps.nm}</h1>
            <p>Age:{ps.age}</p>
        </div>
    )
}
export default PropsFunComp;
<PropsFunComp name="Sagar" age="30" />

If data is in the form of variable, use curly braces for sending data as prop.
<PropsFunComp name={nm} age={age}  /> 
where nm and age are variables having data.



Default props
If the required props for the component are not passed, we can make use of either conditional rendering or default props. Because value of props if not supplied while rendering, will be undefined,  we will see undefined display in place of the props. We can not even process that value using some function which will generate error.
Fallback value
We can use the logical operator || to set a fallback value, so when a prop is missing it displays the fallback value in place of the missing prop.​​​​​​
Using conditional operatorRendering the component
class Welcome extends React.Component {  
   render() {     
      return (  
          <h1> Welcome {this.props.name || 'GUEST' } </h1>
      );  
   }  
}  
export default Welcome;		<Welcome name="Shilpa" />
// outcome will be <h1> Welcome Shilpa </h1>

<Welcome  />
// outcome will be <h1> Welcome GUEST </h1>
Using default props
React offers a better way in the form of  defaultProps. defaultProps is a property in React component used to set default values for the props argument. It will be changed if the prop property is passed.
Using ES6 class, we will define a static property named defaultProps.
class ReactComp extends React.Component {}       //component definition
ReactComp.defaultProps = {}          //defaultProps object will be supplied with key-value pairs
Using default props with class componentRendering the component
class Welcome extends React.Component {  
 constructor(props){}
   render() {     
     return (  
            <h1> Welcome {this.props.name} </h1>
      );  
   }  
}
Welcome.defaultProps = {
    name: "Guest"
}		<Welcome name="Shilpa" />
// outcome will be <h1> Welcome Shilpa </h1>

<Welcome  />
// outcome will be <h1> Welcome GUEST </h1>

Validating props
React comes with an internal mechanism for validating props values with respect to its data type to make sure that values passed through props are valid. React components uses a special property called propTypes to setup data type validation. We are allowed to define components without PropTypes, but, with PropTypes we can avoid unexpected errors. The PropTypes is provided with props and their respective PropTypes for type-checking. When a prop is passed in with an invalid type or fails the prop type, a warning is passed into the JavaScript console.
Specifying validations in component
Using PropTypes in component
class Component extends React.Component {
  render() {}
}
Component.propTypes = {
    propArray: PropTypes.array.isRequired,
    propBool: PropTypes.bool.isRequired,
    propNumber: PropTypes.number,
    propString: PropTypes.string
}
Component.defaultProps = {
    propArray: [1,2,3,4,5],
    propBool: true,
    propNumber: 1,
    propString: "Hello, World!"
}
Validators of basic data types
The React.PropTypes object contains a list of validators for basic data types.
ValidatorsMeaning
PropTypes.any 
the prop can be of any data type
PropTypes.boolthe prop should be a boolean
PropTypes.numberthe prop should be a number
PropTypes.stringthe prop should be a string
PropTypes.functhe prop should be a function
PropTypes.arraythe prop should be an array
PropTypes.objectthe prop should be an object
PropTypes.symbolthe prop should be a symbol
PropTypes.instanceOfthe prop should be an instance of a particular JavaScript class
PropTypes.isRequiredthe prop should be provided
Custom validation
In React, we are allowed to create a custom validation function to perform custom validation as per our requirement. In order to create a custom validation function, we are required to create a function with following arguments :
props :- The props passed to the component
propName :- The propName being validated
componentName :- The componentName we are validating against
Installation
Proptypes is not a built-in feature of React but a third-party library that provides a mechanism for validating the types. 
To use Proptypes in your React component, it needs to be installed using npm.
npm install prop-types
Import PropTypes from the prop-types library and use it to define the expected prop types within your component.
