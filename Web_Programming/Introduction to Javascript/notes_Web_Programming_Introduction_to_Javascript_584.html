Introduction to Javascript
So far we have seen about displaying static HTML but in today's scenario, more interactive and dynamic web sites are very common. Javascript is the client side scripting language which helps in making web page dynamic. In this chapter we will learn about very basics of Javascript language
Client Side Scripting
Client side scripting basics
Client-side scripting generally refers to the computer programs that are executed on the client-side, by the user's web browser. Client-side scripting adds interactivity in a Web application. Achieving interactivity using client side script is having performance advantage than achieving same interactivity using server side script.
Client-side script does not involve the delay of a round trip between the client and the server, making the Web application more responsive. In addition, client-side scripting offers the benefit of sharing the load of the server wherever processing is needed.
In general client side scripting gives the benefit of utilizing computational power of client and avoids unnecessary request - response cycles between client and server which unnecessary occupy network bandwidth.
Client side scripting languages
Javascript, Jscript, VB script were different client side scripting languages used in early days of dynamic HTML. 
VB Script
Visual Basic Script is a lightweight active scripting language developed on Visual basic. It is developed and maintained by Microsoft for the purpose of developing dynamic web applications.
JavaScript
JavaScript is a language based on ECMAScript. A standard for scripting languages like JavaScript, JScript is ECMAScript. JavaScript is considered as one of the most popular implementations of ECMAScript.
JScript
JScript released in 1996 by Microsoft, as Microsoft’s dialect of ECMAScript. JScript and JavaScript are different names for the same language. They have different names to avoid trademark issues.
Typescript
It is a typed superset to javascript. It compiles into the regular javascript code. It is purely object-oriented and statically typed like Java. It is developed and maintained by Microsoft. It is a relatively new into the market and is regularly getting updated
Now-a-days the language that has dominated the client side scripting is javascript.
ECMAScript
The full form of ECMA is European Computer Manufacturer's Association. ECMAScript is a Standard for scripting languages such as JavaScript, JScript, etc. It ensures the interoperability of web pages across different browsers.
Basics of Javascript
  • JavaScript was initially developed as a scripting language specifically for Netscape Navigator, a popular web browser in the 1990s.
  • JavaScript is a lightweight interpreted programming language with object-oriented capabilities.
  • The general purpose core of the language has been embedded in Netscape Navigator, IE and other web browsers.
  • One of the most common misconceptions about JavaScript is that it is a simplified version of Java. The fact that both Java and JavaScript can provide executable content in web browsers, the two languages are entirely unrelated. The name JavaScript is owned by Netscape.
  • The original version of the language, now almost obsolete, is JavaScript 1.0. The current version of the JavaScript is ES14.
  • Client-side JavaScript extends the core language by supplying objects to control a browser (Navigator or another web browser) and its Document Object Model (DOM).
JS Features
  1. Lightweight scripting language :
    Since it is not a general-purpose language so it has a limited set of libraries. Also as it is only meant for client-side execution and that too for web applications, hence the lightweight nature of JavaScript is a great feature.
  2. Dynamic typing :
    In JavaScript we do not have to provide the data type while declaring a variable. Any type of value can be stored in the variable.
  3. Object based language : 
    Starting from ES6, the concept of class and object oriented concepts has been more refined. JavaScript is often described as an object-based language because of its focus on objects as the primary mechanism for structuring code and data.
  4. Easy syntax :
    Most of the javascript control statements syntax is same as syntax of control statements in C language.
  5. Interpreted Language :
    JavaScript is an interpreted language which means the script written inside javascript is processed line by line. These Scripts are interpreted by JavaScript interpreter which is a built-in component of the Web browser.
  6. Can be easily embedded in web page :
    Javascript code can be written in the existing HTML page using script tag which makes HTML page dynamic.
  7. Can catch events :
    Javascript is designed to react to user actions like button click, checking the checkbox, keeping moues pointer over certain element, loading of HTML page. Different functions can be called on occurrence of such events.
  8. JavaScript is a case-sensitive language :
    It follows the camel casing notation. JavaScript ignores spaces, tabs, and new lines that appear between tokens in programs. A token is a variable name, keyword, function name, number, or any other entity. JavaScript supports both C and C++ style comments.
First Javascript program
Let us see now very first javascript program which displays "Hello World" on the web page. For embedding javascript code in the HTML page <script> tag is used. This tag can be written anywhere in the web page and can be repeated as many number of times as required.
First program 
<!DOCTYPE html>
<html>
<head>
    <title>My First JavaScript Program</title>
</head>
<body>
<script>
    // JavaScript code
    document.write("Hello, World!"); // Print "Hello, World!" on the web page
</script>
</body>
</html>
Note : document is the default object available to javascript code. It's write method writes the given content in the web page. We can specify the content wrapped in HTML tags.
External javascript
Using external JavaScript files is a common practice in web development as it helps to keep your HTML code and javascript code separated (separating structure and behavior). Use these steps for creating and linking external javascript.
  1. Create a JavaScript File: 
    Create a new file with a .js extension, for example, script.js. This file will contain the JavaScript code. 
    // script.js
    document.write("Hello from external javascript!"); // Displays msg in web page
  2. Link the External JavaScript File to Your HTML Document:
    In the HTML document, use the <script> tag to link the external JavaScript file. Place this tag inside the <head> or <body> section of your HTML document.
    <!DOCTYPE html>
    <html>
    <head>
        <title>External JavaScript Example</title>
        <script src="script.js"></script>   <!-- Link to the external JavaScript file -->
    </head>
    <body>
      <!-- Your HTML content -->
    </body>
    </html>
    When HTML document is opened in a web browser, it will execute the JavaScript code from the external file.
​​​​​​​Advantages of external javascript
  • It improves code organization and maintainability by separating HTML and JavaScript code.
  • It allows for code reuse across multiple HTML pages.
  • It facilitates caching, as browsers can cache external JavaScript files, resulting in faster page loading times for subsequent visits.

Use of var, let and const
var, let and const all the keywords are used for declaring variables. But they differ in their scope and behavior. 
  1. var 
    Variables declared using var keyword are function scoped. If variable is declared outside the function, it becomes global variable. These variables can be re-declared and reassigned.
    function example() {
        var x = 10;
        if (true) {
           var y = 20;
          console.log(x); // Output: 10
       }
       console.log(y); // Output: 20
    }
  2. let 
    Variable declared with let is only accessible within the block (enclosed by {}) in which it is declared. It can not be re-declared in the same block.
    function example() {
        var x = 10;
        if (true) {
           var y = 20;
          console.log(x); // Output: 10
       }
       console.log(y); // Error: y is not defined
    }
  3. const
    const is even block scoped like let. But it can not be re-assigned or re-declared in the same block.
    function example() {
        const x = 10;
        x = 20; // Error: Assignment to constant variable
        const obj = { name: "John" };
        obj.name = "Jane"; // Allowed, but cannot reassign obj
    }

=== operator: 
It is known as the strict equality operator. It compares values without type conversions. It works like :
  • If the operands are of the same type (for example, both are numbers, strings, or booleans), JavaScript compares their values and returns true if they are equal.
  • If the operands are of different types, JavaScript immediately returns false without attempting any type conversion.
  • For objects (including arrays and functions), === checks whether the two operands reference the same object in memory. It does not compare the contents of the objects.
  • Examples 
    Javascript codeOutput
    5 === 5         true (both operands are the same value and type)
    5 === "5" false (one operand is a number, the other is a string)
    true === truetrue (both operands are the same value and type)
    true === 1false (one operand is a boolean, the other is a number)
    "hello" === "hello"true (both operands are the same value and type)
    var obj1 = {};
    var obj2 = {};
    obj1 === obj2    		false (objects are compared by reference, not content)
!== operator:
It is the strict inequality operator. It returns true if the operands are not equal or of different types. Otherwise, it returns false. 
typeof operator:
  • typeof is important because JavaScript is a dynamically typed language.
  • The typeof operator returns a string that represents the current type of a variable. It is used like typeof(variable) or typeof variable.
  • Example:
    var x = 12345;    
    console.log(typeof x) // number      
    x = 'string';      
    console.log(typeof x) // string      
    x = { key: 'value' };      
    console.log(typeof x) // object

Defining functions
A JavaScript function is defined with the function keyword, followed by a name, followed by parentheses (). Function names can contain letters, digits, underscores, and dollar signs (same rules as variables). The parentheses may include parameter names separated by commas: (parameter1, parameter2, ...) The code to be executed, by the function, is placed inside curly brackets:
function functionName([arg1, arg2, ...argN]){      
     //code to be executed  
}  
The code inside the function will execute when the function is called.
