Third Party Middleware
In this chapter we will learn about the middlewares which are available in npm repository and can be installed as per need of the application. In this chapter we will learn about body-parser, cookie-parser and express-session, cors middlewares.
Need and Advantages
Third-party middleware in ExpressJS refers to functions developed and maintained by third-party developers, which can be used to add additional functionality to an ExpressJS application. For example, third-party middleware packages can handle authentication, logging, compression, and more. These middleware packages can be installed using package managers like npm, and then included in the application using the app.use() method.
Third-party middlewares are a good alternative when there is a package available out there offering functionality that our API will need such as allowing client access from different origins and parsing the incoming request body data. 
Overall, third-party middleware can be a powerful tool to enhance and extend the functionality of an ExpressJS application.
To use the middleware in express application
  1. Theses middleware are expected to install it separately from npm repository. You can install it by using the following command :
    npm install MODULE_NAME
  2. Import the middleware using require() function
    const <name> = require('<middleware-name>');
  3. Use the middleware in the app.use method
    app.use(name([options]))

Body Parser
​​​​​​​Body-parser is a third-party middleware for processing incoming HTTP requests in Node.js. It is used to extract the request body and expose it on the request object for easier handling.
When a client makes an HTTP request to a server, the request may contain data in the request body, such as form data or JSON data. Body-parser helps to extract this data and make it available in a format that can be easily used by JavaScript code running on the server.
Body-parser supports various types of request bodies including JSON, URL-encoded data, raw text, and even multi-part data. It parses the request body and populates the request object with a body object containing the parsed data.
Body-parser is an important tool for building web applications with Node.js because it simplifies the process of handling incoming data from client requests.
Steps for using body-parser
  1. Install body-parser using npm utility
    npm install body-parser
  2. Import the module in the express application
    const bodyParser = require("body-parser");
  3. Use the middleware in the express application
    app.use(bodyParser.json()); // for application/json parsing
    app.use(bodyParser.urlencoded({ extended: true })); // for application/x-www-form-urlencoded parsing
  4. Use the middleware in route handler
    app.post('/logincheck', function(req,res){
        if(req.body.uid == "knowit" && req.body.pwd == "knowit123")
            res.send("Login success");
        else
            res.send("Login failed"); 
    });
Note : req.body object is populated with data received from the request only when all the steps are precisely followed.




Cookie Parser
​​​​​​​Cookie-parser is a middleware for handling HTTP cookies in Node.js with Express. It simplifies the process of parsing and setting cookies, which are small pieces of data that are stored on the client side and sent back to the server with each subsequent request.
Cookie-parser provides methods for parsing and setting cookies in a standardized way and also provides additional security features like signing and encrypting cookies to prevent tampering and protect sensitive data.
Steps for using cookie-parser
  1. Install body-parser using npm utility
    npm install cookie-parser
  2. Import the module in the express application
    const cookieParser = require("cookie-parser");
  3. Use the middleware in the express application
    app.use(cookieParser()); 
  4. Use the middleware in route handler to set a cookie
    // set a cookie
    app.get("/set-cookie", (req, res) => {
       res.cookie("username", "john");
       res.send("Cookie has been set!");
    });
  5. Use the middleware in route handler to get a cookie
    // get a cookie
    app.get("/get-cookie", (req, res) => {
       const username = req.cookies.username;
       res.send(`The username is: ${username}`);
    });
  6. Use the middleware in route handler to delete a cookie
    // delete a cookie
    app.get("/delete-cookie", (req, res) => {
       res.clearCookie("username");
       res.send("Cookie has been deleted!");
    });
    Note : req.cookies object is populated only after following all these steps
cors
CORS stands for Cross-Origin Resource Sharing. Without prior consent, it prevents other websites or domains from accessing your web resources directly from the browser. There is a high chance your API needs to be accessible from different client origins, for example, from a mobile device, or from a web browser while your API is running in a different server. Unless you allow access to clients to the API, the clients will face CORS errors. CORS is a mechanism that allows web applications to access resources from other domains.
That’s why we are going to install the package cors.
Features of CORS
  • Supports GET, POST, or HEAD HTTP methods.
  • Allows web programmers to use regular XMLHttpRequest, which handles errors better.
  • Allows websites to parse responses to increase security.
Usage of CORS
You can use either enable CORs for all the routes using
app.use(cors())  
Or it can be used only for single route
app.get('/', cors(), (req, res) => {     
       res.json({         
             message: 'Happy Coding'    
       }); 
});​​​​​​​
Steps for using cors
  1. Install cors using npm utility
    npm install cors
  2. Import the module in the express application
    const cookieParser = require("cors");
  3. Use the middleware in the express application
    app.use(cors());
