React redux
​​​​​​​This chapter will reveal very important aspect of react application i.e. application state management. For this we will use react redux library. It covers about the need and usgae of latest redux library.
What is redux
​​​​​​​Redux itself is a standalone library that can be used with any UI layer or framework, including React, Angular, Vue, Ember, and vanilla JS. Although Redux and React are commonly used together, they are independent of each other.
React Redux is the official Redux UI binding library for React.
Redux is used to maintain and update data across your applications for multiple components to share, while remaining independent of the components.
Redux is a predictable state container designed to help you write JavaScript apps that behave consistently across client, server, and native environments, and are easy to test. With Redux, the state of your application is kept in a store, and each component can access any state that it needs from this store.
Without Redux, you would have to make data dependent on the components and pass it through different components to where it’s needed. we only need some data in the parent and inner child components, but we’re forced to pass it to all the components (including the child component that doesn’t need it) to get it to where it’s needed.
​
With Redux, we can make state data independent of the components, and when needed, a component can access or update through the Redux store.
​
Advantages of redux
​​​​​​​Redux can help simplify the state management process, especially when dealing with complex and interconnected components.
  • Centralized state management: With Redux, you can maintain the state of your entire application in a single store, making it easier to manage and access data across components.
  • Predictable state updates: Redux has a clear flow of data, which means changes to the state can only happen when you create an action and send it through Redux. This makes it easy to understand how your application's data will change in response to user actions.
  • Easier debugging: With Redux DevTools, you have a clear record of all the changes to your application's state. This makes locating and fixing issues in your code easier, saving you time and effort in the debugging process.
  • Better performance: By centralizing state management, Redux can minimize unnecessary re-renders of components that are not directly affected by state changes..
How redux works?
​​​​​​​Redux enables you to maintain a single centralized store that manages the state of your entire application. All components in your application can access this store and update or retrieve data from it as needed.
The key components that enable this centralized approach to state management are:
  1. Store
  2. Actions
  3. Dispatch
  4. Reducers

The Store
The Redux store is like a giant container that holds all the data for your application. It can hold various kinds of data, such as strings, numbers, arrays, objects, and even functions.
Also, the store is the single source of truth for your application's state. This means that any component in your application can access it to retrieve and update data.
Actions
An action is an object that describes what changes need to be made to the state of your application. It sends data from your application to the Redux store and serves as the only way to update the store.
An action must have a "type" property describing the action being performed. This "type" property is typically defined as a string constant to ensure consistency and avoid typos. In addition to the "type" property, an action can have a "payload" property. The "payload" property represents the data that provides additional information about the action being performed. For example, if an action type is ADD_TASK, the payload might be an object containing a new task item's "id", "text", and "completed status".
example of an action:
{
  type: 'ADD_TASK',
  payload: {
    id: 1,
    text: 'Buy groceries',
    completed: false
  }
}

Dispatch
In Redux, dispatch is a function provided by the store that allows you to send an action to update the state of your application. When you call dispatch, the store runs an action through all of the available reducers, which in turn update the state accordingly. dispatch delivers actions to various reducers in your Redux store.
Reducers
In Redux, a reducer is a function that takes in the current state of an application and an action as arguments, and returns a new state based on the action.

  1. Install latest redux library using following command
    npm install --save react-redux @reduxjs/toolkit
    Note it installs react-redux as well as @reduxjs/toolkit module
  2. Create store
    Use configureStore() function for creating store
       it needs object as argument
       export deafult configureStore({
            reducer : {
                  ------  will be created by slice
           }

  3. Import this in index.js and wrap <App /> component in <Provider />  element
       <Provider store={store}>
            <App />
       </Provider>  
     Store to be imported as  import store from './store'. This makes the store available for entire application.
  4. Create slice in slice.js using createSlice() function
    It needs object as argument which has keys - name, initialState(Object), reducers(object). From this slice export actions as object destructuring, export reducers as default.
    import { createSlice } from "@reduxjs/toolkit"
    export const loggedSlice = createSlice({
        name: 'logged',
        initialState: {
            loggedIn: false
        },
        reducers: {
            login: (state) => {return {loggedIn: true}} ,       
            logout: (state) =>{ return {loggedIn: false}
            }
        }
    })
    export const {login} = loggedSlice.actions;
    export const {logout} = loggedSlice.actions;
    export default loggedSlice.reducer;
  5. Once the slice is ready, make the entry in store of exported reducer from slice
    export default configureStore({
        reducer: {
            logged : loggedReducer
        }
    });
  6. Access state in the component
    It can be done using useSelector() hook. This hook needs atleast 1 argument which is a callback function which reads state of respective reducer
    const mystate = useSelector((state)=>state.logged)         //fetching data from store
    Above statement actually fetches the state of logged reducer
  7. Use useDispatch for modifying the state
    let dispatch = useDispatch();
    dispatch(login())  //login is action exported from the reducer
