Using JSON
JSON can be used as data exchange format between cleint and server. In this topic let us see how JSON can be generated on server side and when client receives the JSON data, how it can make use of jquery functionality for parsing reveived data.
Generating JSON on Server Side
Express module has a method res.json() that takes an object or a value, converts it into JSON and sends it as a response. This method will automatically set the Content-Type header, as “application/json”.  This method is super useful and easy.  send() method is used to send data which is plain text and interpreted as html. This method will  sets the Content-Type as “text/html” automatically. 
Express application which sends JSON data
Scenario : Client sends deptno as key in the request body. Server reads request body using body-parser middleware to get the value of deptno sent by the client. Accordingly it executes query in the database and whatever result(set of employee) it returns, will be sent to the client as json.
//import require modules
var exp = require('express');
var bp = require('body-parser');
var mysql = require('mysql2');
//create connection object holding database connection information
var con = mysql.createConnection({
    host: "localhost",
    user: "root",
    password: "root",
    database: "sakila"
})
var app = exp();
//using body-parser as middleware
app.use(bp.urlencoded({extended: false}));
//actually establishing connection to database
con.connect(function(err){
    if(!err)
        console.log("con established");
    else
        console.log("con rejected : "+err.toString());
})
//exp server listens on port 9000
app.listen(9000,function(){
    console.log("JSON exp server - 9000");
})
//route handler for request url '/deptform' and request method get
//this sends the static html file as a response
app.get('/deptform',function(req,res){
    res.sendFile(__dirname+"/deptform.html");
})
//route handler for request url '/getEmps' and request method post
app.post('/getEmps',function(req,res){
    //req.body is available to parse data from the request body
    var dno = req.body.deptno;
   //write a query as a string for querying the database table
    var query = "select * from emp where deptno = "+dno;
   //execute the query in the database to get required set of records
    con.query(query,function(err,result){
        if(!err) {
            //converting JS array to JSON string as a response
            res.json(result);
        }
    })
})

AJAX using jQuery
Regular AJAX code may be difficult to create because different browsers use different syntaxes for AJAX implementation. So this code needs to be tested for different browsers.jQuery includes many functions which allow client to make a request asynchronouly.
jQuery AJAX methodParametersDescription
load()$(selector).load (URL, data, callback)Used for loading server's response in the selected element
get()$.get(url, callback)Used for making HTTP get request
post()$.post(url, data, callback)Used for making HTTP post request
ajax()$.ajax({ key: value, key1:value1 })Performs an asynchronous request with the given settings. 
load method
This method helps to load the contents received from the web server in a selected element of the webpage. Basic syntax is $(selector).load (URL, data, callback) where
URL : This parameter refers to the URL to which request needs to be sent
data : This optional parameter indicates the set of query string key/value pairs that is sent in the request
callback : This optional parameter represents the name of the function that will be executed after the load() method has been completed
Javascript code
<script>
         $(document).ready(function () {
                //event is click of button
                $("button").click(function () {
                     $("#div1").load("demo.txt", function (responseTxt, statusTxt, xhr) {
                         if (statusTxt == "success") alert("The content was successfully loaded!");
                         if (statusTxt == "error") alert("Error: " + xhr.status + ": " + xhr.statusText);
                     });
                });
         });
</script>
​​​​​​​get mehod
The jQuery get() method is used to request data from a server via an HTTP Get request. The syntax for jQuery Get is: $.get(URL, callback) where
URL : This parameter refers to the URL you want to request
callback : This parameter refers to the name of the function to be executed if the request is successful.
Javascript code
<script>
       $(document).ready(function(){
            //event is click of button
            $("#b1").click(function(){
                var url = "http://localhost:9000/getEmpDetails?empid="+$("#empid").val();

                $.get(url,function(data,status) {
                     //when request-response cycle completed successfully
                     if(status == "success") {
                        //display received response as inner HTML of selected element
                        $("#info").html(data);
                     }
                });
            });
       });
</script>

ajax method
$.ajax() method is a powerful and straightforward way of creating Ajax requests. It takes a configuration object as a argument that contains all the instructions and data that jQuery requires to complete the request. The $.ajax({settings}) method is particularly important because it offers the ability to specify both success and failure callbacks.
Javascript code
//all data needed for asynchronous request can be supplied as key-value pairs
$.ajax({
  url: "target url",
  type: "GET",
  dataType: "html",
  success: function (data, status, jqXHR) {
    $("#container").html(data);
  },
  error: function (jqXHR, status, err) {
    console.log(err.toString());
  },
  complete: function (jqXHR, status) {
    console.log("AJAX completed");
  }
})
Note : The $.ajax() function underlies all ajax requests sent by jQuery. It is often not required to directly call this function, as simpler alternatives like $.get(), $.post() and .load() are available and are easier to use. Only when more flexibility is required for making asynchronous request, $.ajax() method can be preferred.
