Handling Forms and Events
In this chapter we will go in the details of very important aspect for client view i.e. the form. We will go in the details of how form can be created, how data accepted from user can be kept in the state of the component by handling change event, how data can be validated and how it can be submitted to the server.
Creating form
Web applications often need to send data from browser to the backend server. The most used way of doing so is through a HTML form, by using text inputs, radio buttons, checkboxes, select boxes and so on.
Just like in HTML, React uses forms to allow users to interact with the web page. You add a form with React like any other element. Handling forms is about how you handle the data when it changes value or gets submitted.
Controlled vs Uncontrolled components
In React, when a component renders a form with elements such as text inputs, select boxes or checkboxes, there are two ways of keeping and updating their state.
  1. Uncontrolled components : The state is kept and updated by the input itself. This is the way forms work in pure HTML.  React has no control over the input's state. Therefore, these form inputs are called uncontrolled components. In HTML, form data is usually handled by the DOM.
    useRef hook is used to access and read the current value of an input field without binding it to state. useRef is a React hook that gives a mutable reference to a DOM element. As form's data is not bound to the state, components will not be re-rendered.
    Example of useRef hook
    import React, { useRef } from 'react';
    function UncontrolledForm() {
      //creates a reference to the input element.
      const inputRef = useRef(null);
      const handleSubmit = (e) => {
        e.preventDefault();
       // accesses the current value without needing React state.
        console.log(`Input value: ${inputRef.current.value}`);
      };
      return (
        <form onSubmit={handleSubmit}>
          {/*  attaches the ref to the DOM node.  */}
          <input type="text" ref={inputRef} />
          <button type="submit">Submit</button>
        </form>
      );
    }

  2. Controlled components : The state is handled by the component that renders the form. It uses the component's state for such purpose and gives responsibility to event handlers to detect changes and keep the state up-to-date. This is the recommended way of handling forms in React. React controls the input's state. For this reason, such inputs are called controlled components. In React, form data is usually handled by the components. When the data is handled by the components, all the data is stored in the component state. You can control changes by adding event handlers in the onChange attribute:
Example of form in class component

Handling input change
Every time when a change occurs in the input, some event handler needs to be called. This event handler will catch the modified value from the form's field and update in the component's state.
Handling input change in class component
In the below component, every time a change occurs in the input, the handleNameChange event handler is called. This handler receives an event object that holds, among other things, the up-to-date value of the input. After getting it, this same value is assigned to its matching entry in the component's state by using the setState method. After the change is performed, the value attribute of the input is automatically updated, since the this.state.name state entry is bound to it.
To verify this, we can display the value in the text field below the form.
Handling form in class component
export default class App extends Component {
  constructor(props) {
       super(props);
       this.state = { name: "" };
  }
   handleNameChange = (e) => {
       const name = e.target.value;
       this.setState({ name });
  };
   render() {
    return (
      <div>
        <form>
          <label>Name:</label>
          {/* displaying the state in the form field and modifying state when change event occurs  */}
          <input value={this.state.name} onChange={this.handleNameChange} type="text" />
        </form>
          {/* to verify whether state is updated */}
         <strong>The typed name is: </strong><span>{this.state.name}</span>
      </div>
    );
  }
}

Handling multiple input
useReducer is one of the additional hooks is avaialble with React v16.8. An alternative to the useState Hook, useReducer helps you manage complex state logic in React applications.
Steps to follow
  1. It accepts a reducer function as its first parameter and the initial state as the second. 
    const [emp,dispatch]  = useReducer(reducer, init);
    useReducer returns an array that holds the current state value and a dispatch function to which you can pass an action. Initialstate can be defined like :
    const init = {
        empid: 0,
        ename: "",
        salary: 0.0,
        dept:0
    }
    The reducer is a pure function that accepts 2 parameters: the current state and an action object. Depending on the action object, the reducer function must update the state in an immutable manner, and return the new state.
    const reducer=(state,action) => {
        switch(action.type)
        {
            case 'update':
                return {...state,[action.fld]:action.val}
            case 'clear':
                return init;
        }
    }
  2. An action object is an object that describes how to update the state. The action object has a property type — a string describing what kind of state update the reducer must do.
    const action = {
      type: 'increase'
    };
    If the action object must carry some useful information (aka payload) to be used by the reducer, then you can add additional properties to the action object.
    const action = {
      type: 'add',
      user: { 
        name: 'John Smith',
        email: 'jsmith@mail.com'
      }
    };
  3. This action object can be passed to dispatch function when an event occurs.
    <input type="text" name="ename" value={emp.ename}
         onChange={(e)=>{dispatch({type:'update',fld:'ename',val:e.target.value})}}  />
    Note : An object is passed to dispatch which has type attribute and other required data as fld and val attributes.
Complete example
import { useReducer, useState } from "react";
//needed by useReducer - data
const init ={
    empid: 0,
    ename: "",
    salary: 0.0,
    dept:0
}
//needed by useReducer - modify function
const reducer=(state,action) => {
    switch(action.type)
    {
        case 'update':
            return {...state,[action.fld]:action.val}
        case 'clear':
            return init;
    }
}
function EmpForm ()
{
    //maintaining complex state(object)
    const [emp,dispatch]  = useReducer(reducer, init);
    let sendData = (e) => {
        e.preventDefault();
        console.log(JSON.stringify(emp))
    }
    return (
        <div>
            <h1>Emp Form</h1>
            <form>
                Enter empid :
                <input type="number" name="empid" value={emp.empid} 
                onChange={(e)=>{dispatch({type:'update',fld:'empid',val:e.target.value})} }  />
                <br/>
                Enter ename : 
                <input type="text" name="ename" value={emp.ename}
                onChange={(e)=>{dispatch({type:'update',fld:'ename',val:e.target.value})}}  /> 
                <br/>
                Enter salary : 
                <input type="number" name="salary" value={emp.salary}
                onChange={(e)=>{dispatch({type:'update',fld:'salary',val:e.target.value})}}   /> 
                <br/>
                Enter dept : 
                <input type="text" name="dept" value={emp.dept}
                onChange={(e)=>{dispatch({type:'update',fld:'dept',val:e.target.value})}}   /> 
                <br/>
                <input type="submit" value="Submit"  onClick={ (e)=> {sendData(e) } }  />
                <input type="button" value="Clear"  onClick={()=>{dispatch({type:'clear'})}} />
                <br/>
                {/* Showing the current state */}
                {JSON.stringify(emp)}                                
            </form>
        </div>
    )
}
export default EmpForm;
Submitting form
To handle the form submission, you just need to define a handler for the onSubmit event.
handleFormSubmit = (event) => {
   console.log(this.state.name)
   event.preventDefault();
};
In this event handler, you could submit the values of your form to the REST endpoint by using the fetch API. You also need to call the event.preventDefault method to prevent a traditional form submission, which reloads the entire page.
If it is a functional component, state may be a set of different varibales or it may be complex in the form of object. State maintained in the component may be sent to REST API or may be used for component modification.
 let sendData = (e) => {

Data validation
User input in terms of different kinds of input controls can be validated when the user is typing or wait until the form gets submitted. The message related to the validation may be displayed in alert box or it can be displayed within the form itself with some different formatting so that it can be highlighted (more preferred than alert messages).
Example for displaying error messages within the form
render() {
    return (
      <form>
      <h1>Hello {this.state.username} {this.state.age}</h1>
      <p>Enter your name:</p>
      <input
        type='text'
        name='username'
        onChange={this.myChangeHandler}
      />
      <p>Enter your age:</p>
      <input
        type='text'
        name='age'
        onChange={this.myChangeHandler}
      />
      {this.state.errormessage}
      </form>
    );
  }
myChangeHandler will validate the value for the data. If found invalid, errormessage can be set by the handler which will get displayed within the form by some highlighting.
Validation function
myChangeHandler = (event) => {
    //get the field name and its updated value
    let nam = event.target.name;
    let val = event.target.value;
    let err = '';
    if (nam === "age") {
      if (val !="" && val < 18) {
        err = <strong>Your age must be a number greater than 18</strong>;
      }
    }
    this.setState({errormessage: err});
    //partial updation of the state
    this.setState({[nam]: val});
  }
