Component State
​​​​​​​In this chapter we will discuss about how react component can maintain the state(data) internally and how to modify the state of the component that will trigger the re-rendering of the component
What is state
  • Class components has a built-in state object.
  • The state object is where you store property values that belongs to the component.
  • When the state object changes, the component automatically re-renders.
  • State is the place where the data is maintained required by a component.
  • The state in a component can change over time. The change in state over time can happen as a response to user action or system event.
  • A component with the state is known as stateful components. It is the heart of the react component which determines the behavior of the component and how it will render. They are also responsible for making a component dynamic and interactive.
  • The state object can contain as many properties as required.
  • Class components can have state but functional components can not have state.
  • But from version 16.8 onwards, react allows to use react hook functionality for maintaining state in functional components.
Defining state
Defining state in class component
To define a state,  declare a default set of values for defining the component's initial state. For this, add a class constructor which assigns an initial state using this.state. The 'this.state' property can be used to display state information inside render() method.
Class component definition 
class StatefulComp extends React.Component {
   constructor(props){    
       super(props);
       //state initialization in the constructor
       this.state = {
            name: "Amit"    
      }
   }
   render() {     
      return (  
          //using state data in compoenent rendering 
          <p> Paragraph with style {this.state.name} </p>
      );  
   }  
}  
export default StatefulComp;
Defining state in functional component
To define a state in the functional components, useState hook can be used.  It returns an array with two values: the current state and a function to update (setter function) it. The Hook takes an initial state value as an argument and returns an updated state value whenever the setter function is called. It can be used like this:
const [state, setState] = useState(initialValue);
Here, the initialValue is the value you want to start with, and state is the current state value that can be used in your component. The setState function can be used to update the state, which triggers a re-render of the component.
In React, useState can store any type of value, whereas the state in a class component is limited to being an object. This includes primitive data types like string, number, and Boolean, as well as complex data types such as array, object, and function. It can even cover custom data types like class instances.
Basically, anything that can be stored in a JavaScript variable can be stored in a state managed by useState.
Functional component definition 
import { useState } from "react"
const StateFunComp = () => {
    //initializing component state
    const [nm,setNm] = useState("Vishal")
    return (<div>
                {/*    using state data in component rendering */}
                <h1> Welcome {nm} </h1>
                <input type="text" name="nm" value={nm}
                 onChange={(e)=>{setNm(e.target.value)}} />
                <button onClick={()=>{setNm("Bakul")}}>
                    Change Name
                </button>
            </div>)
}
export default StateFunComp;
For maintaining state as objects or array :
// Objects
const [state, setState] = useState({ name: 'John', age: 30 });
// Arrays
const [array, setArray] = useState([1, 2, 3, 4, 5]);
Using state
State maintained in the component can be used in rendering of the component.
Using state in class component
Refer to the state object anywhere in the class component by using the this.state.propertyname syntax
Eaxmple :
 render() {     
      return (  
          <p> Paragraph with style color as {this.state.color} and size as {this.state.size} </p>
      );  
   } 
Using state in functional component
In the functional component, state can be used as a simple variable which can be rendered in JSX using curly braces syntax i.e. in the form of javascript expression.
import { useState } from "react"
const StateFunComp = () => {
    const [nm,setNm] = useState("Vishakha")
    return (<div>
                <h1> Welcome {nm} </h1>
                 </div>)
}
export default StateFunComp;

Modifying state
Modifying state in class component
In the class component to change a value in the state object, use the this.setState() method.
When a value in the state object changes, the component will re-render, meaning that the output will change according to the new value(s).
Class component definition
class StatefulComp extends React.Component {
   constructor(props){    
       super(props);
       //state initialization in the constructor
       this.state = {
            name: "Amit"    
      }
   }
   handleClick = () => {
       //modifying state using this.setState() method
       this.setState({
           name: "Rahul"
      })
   }
   render() {     
      return (  
          //using state data in compoenent rendering 
          <p onClick="handleClick"> Paragraph with style {this.state.name} </p>
      );  
   } 
}  
export default StatefulComp;
Modifying state in functional compoenent
In the functional components, when any event occurs state can be modified by calling it's setter method created in useState declaration. New value can be passed to this setter method for modification.
Functional component definition
import { useState } from "react"
const StateFunComp = () => {
    const [nm,setNm] = useState("Vishakha")
    return (<div>
                <h1> Welcome {nm} </h1>
                <input type="text" name="nm" value={nm}  />
                {/*   Modifying state after button click     */} 
                <button onClick={()=>{setNm("Sachin")}}>
                    Change Name
                </button>
            </div>)
}
export default StateFunComp;
When the state is modified, component will get re-rendered displaying the latest state.
Comparison of state and props
Props                                            State
Props are read-only.   State changes can be asynchronous.
Props are immutable.   State is mutable.
Props allow you to pass data from one component
to other components as an argument.    		State holds information about the components.
Props can be accessed by the child component.States can be used for rendering dynamic changes with the component.
Stateless component can have Props.Stateless components cannot have State.
Props make components reusable.State cannot make components reusable.
Props are external and controlled by whatever renders the component.The State is internal and controlled by the
React Component itself.
