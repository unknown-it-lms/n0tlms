Regular Expressions
Regular expressions are patterns used to match character combinations in strings.It helps the programmers to validate text string. It offers a powerful tool to analyze and search a pattern as well as to modify the text string. In this lesson we will learn about different symbols used for constructing the RegExp pattern and examples of the RegExp patterns that are frequently required.
Introduction to Regular Expressions
Regular expressions form a small, separate language that is part of JavaScript and many other languages and systems with some differences between each implementation
Regular expressions are patterns used to match character combinations in strings. A regular expression is an object that describes a pattern of characters. By formulating a regular expression with a given set of symbols and characters, you can :
  • search text a string
  • replace substrings in a string
  • extract information from a string
These patterns are used with the exec and test methods of RegExp. 
These patterns are used with the match, replace, search, and split methods of String
Creating regular expression
A regular expression can be created in one of two ways:
  1. Using a regular expression literal, which consists of a pattern enclosed between slashes, as follows:
    var re = /ab+c/;
    General syntax is 
    var pattern = /pattern/attributes
  2. By calling the constructor function of the RegExp object, as follows:
    var re = new RegExp(‘ab+c’);
    General syntax is :
    var pattern = new RegExp(pattern, attributes)
                  ​​​​​​
Syntax and Rules
Regular expressions can contain letters, digits, and various special characters that represent matching rules. By default, JavaScript regular expressions are case sensitive and only search for the first match in any given string. Here we will learn about all symbols and special characters used for creating pattern and their meaning.

regular expressions (regex) support pattern modifiers, also known as flags, which modify the behavior of the regex pattern. Modifiers frequently used are :

  3. Quantifiers In regular expressions are used to specify how many times a particular element in the regex pattern can occur. They allow you to define repetition in your regex patterns. The characters ?, +, * ,{} are used as quantifiers in the regular expression.
    QuantifierSymbolMeaningExamples
    Zero or more*Matches zero or more occurrences of the preceding element.const regex = /a*/;
    console.log(regex.test(''));  // true

    console.log(regex.test('b')); // false

    console.log(regex.test(''));  // false

    console.log(regex.test('b')); // false

    console.log(regex.test('aa')); // false
    console.log(regex.test('b')); // false
    Specific quantity{n}Matches exactly n occurrences of the preceding element.const regex = /a{3}/;
    console.log(regex.test('aaa'));  // true
    console.log(regex.test('aa')); // false
    console.log(regex.test('aaaa')); // false
    console.log(regex.test('b')); // false
    Range of quantities{n ,m}Matches at least n and at most m occurrences of the preceding elementconst regex = /a{2,4}/;
    console.log(regex.test('aa'));    // true
    console.log(regex.test('aaa'));   // true
    console.log(regex.test('aaaa'));  // true
    console.log(regex.test('aaaaa')); // false

Examples of regular expressions for very frequent data validations
PurposePatternDescription
Validating name
 /^[a-z]{2,}$/
This pattern allows only lower case letters from length 2 onwards
Validating full name
/^[A-Z][a-z]{1,}\s[A-Z][a-z]{1,}$/
This pattern will allow full name to be written with space in between and first letter will be capital
Validating phone number
/^\(\d\d\d\) \d\d\d\-\d\d\d\d$/
For phone number of format (333) 333-3333
\d indicates any digit from 0 to 9
\( indicates presence of ( symbol
\) indicates presence of ) symbol
Validating email id
/^\w{6,}\@\w{4,}\.\w{2,}$/
\w indicates word character
{6,} indicates minimum 6 occurrences, no limit for maximum
\@ indicates presence of @ symbol
\. Indicates presence of . symbol 
Validating password
/(?=.*[A-Z])(?=.*\d)(?=.*[~!@#$%^&*])[A-Za-z0-9~!@#$%^&*()]{8,}/
(?=.*[A-Z]) indicates at least one occurrence of capital letter
(?=.*\d) indicates at least one occurrence of digit
(?=.*[~!@#$%^&*]) indicates at least one occurrence of special character
{8,} indicates minimum length as 8
