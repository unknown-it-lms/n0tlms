Introduction to AJAX
Now at this stage, we are familiar with client side technologies like HTML, CSS, javascript, jquery and some server side technologies like Node JS. In this chapter, we will learn about how to make asynchronous requests to the server side for more responsive and richer applications.
Need of AJAX
AJAX stands for Asynchronous JavaScript and XML. It enables applications to transport data to or from a server asynchronously without refreshing the page. It means that parts of a web page are updated without reloading the entire page.
AJAX can be used anywhere in a web application where small amounts of information can be saved or retrieved from the server without posting the entire page. This technique helps create better, faster, and more interactive web applications. AJAX gained popularity when Google started to use it for its autocomplete feature. 
Synchronous requestsAsynchronous requests
Users need to wait till response comes back from server and loaded in the browser window
Users need not wait after sending the asynchronous request and can perform some other action on the web page
Entire page gets reloaded with server's response
Only part of the page gets updated by the server's response without complete refresh
It sends the request in the background and the server sends the data back to web page in background. Now, there is no need for the web page to be reloaded and we can experience the updates in the web page instantly because all the work has been done in the background as in today’s website. So, this is the function of AJAX. Asynchronous means ‘functioning in background’.
Examples
  1. Google was among the first websites to incorporate AJAX for auto suggestions to their users. As you type a search query in Google, you will notice that some suggestions will appear automatically and you can choose between those by navigating through up and down keys. 
  2. While getting information from the user, we can ask the user to select the country from drop down. When country is selected, client can send asynchronous request to the server for list of states belonging to the selected country.  State drop down will get populated by response sent from the server.
  3. Google Maps and Yahoo Maps use AJAX to make the navigation process easier for the user. Users can simply drag the map without the need to click on a button.
Technologies
AJAX is a set of interactive and interrelated technologies that makes multitasking easier than conventional technologies. AJAX technologies include -
  • JavaScript
    The text-based programming language of the web, JavaScript is the glue that brings together all other elements in AJAX. When an event occurs in a website, a JavaScript function is executed.
  • HTML/XHTML and CSS
    These technologies are responsible for the presentation of the web content such as its style, font, etc.
  • DOM
    DOM is an API that is used for accessing the existing content and updating content after receiving response.
  • XMLHttpRequest
    It is used to establish asynchronous communication with the server. 
  • XML or JSON
    XML is used for communicating to and from the server. It is being replaced by JSON or Javascript Object Notation these days. JSON is lightweight and faster than XML.

Note :
  • Ajax is client side technology that is independent of server side technology.
  • Ajax is not a programming language but it is set of technologies that work to exchange data asynchronously between client and server

Advantages of AJAX
Improves response time
The very important advantage of AJAX is to improve the performance and usability of web applications. As requests are made from the client using only required amount of data, traffic between client and server reduces. It increases speed of response.  As a result, web page’s visitors will never have to see a white window and wait for pages to refresh with Ajax implementation.

Enabled asynchronous calls
As AJAX requests are being sent and processed in the background, users can continue their interaction with the web application without any waiting time.

Enhanced User Experience
AJAX allows to have uninterrupted user interactions by updating only part of the web page. This results in a more responsive web page. This gives richer experience to the end user like desktop applications.

Reduced server load
One more advantage of Ajax comes from the bandwidth usage. This action is effective in improving web performance and load speed as well.
Ajax makes the best use of the server’s bandwidth by fetching only required amount of data instead of transmitting the entire page’s content. This is especially required when web page needs frequent updates.

Form validation
Without Ajax, the validity of data in the form is not checked until the form is submitted. With Ajax, the data added to the form can be dynamically validated as the data is added to form fields using business logic in a server application. e.g. Checking userid entered by the user can be validated on server wheher it is already used by any other user.
Disadvantages
  • AJAX is highly dependent on JavaScript to send requests to the server. So, if any customer has disabled JavaScript on their browsers will not be able to experience the dynamic features of AJAX like faster loading and enhanced user experience.
  • Implementing AJAX functionality in the web page can make it more complex to debug, modify and maintain in future.
  • The pages with successive Ajax requests are unable to register with the browser’s history. So when use clicks the back button on the browser, it may not reurn to previous state of the page and may return to entore previous page.
  • As AJAX-driven web pages do not always update the URL when content changes, users may not be in a position to booklmark the page in the browser's settings.
  • Search engines may not be able to index AJAX content properly, which can negatively impact your website's search engine rankings.
  • Web pages with AJAX implementation may be exposed to security vulnaribility like cross site scripting
Using AJAX in Javascript

​​
Basic steps 
  1. Some event occurs which triggers all further steps to be carried for sending aysnchronous request to the server.
  2. Creating object which represents AJAX object holding information about aynchronous request and response cycle
  3. Initilize the request by specifying request URL and method
  4. Send the request from client side
  5. Client should check whether response is received from server side by using onreadystatechange property
  6. Update the web page using HTML DOM functions when entire response is received from server side.
Example implementing all the steps
HTML Page
<body>
    <form name="f1">
        Enter empid : <input type="number" name="empid" /> <br/>
        <!-- 1. catching the click event of the button which gives call to makeRequest() function -->
        <input type="button" value="Welcome" onclick="makeRequest()" />
    </form>
     <!-- response received from server will be displayed in following div element -- >
    <div id="msg">_______________</div>
</body>
Javascript code
<script>
        function makeRequest() {
            //2. creating ajax object
            ajax = createAjaxObject();   //readyState = 0
            // 5. Call function on every ready state change - response received
            ajax.onreadystatechange = updatePage;        
            //3. Initializing the request
            var url = "http://localhost:9000/greetemp?empid=" + document.f1.empid.value;
            ajax.open("GET", url, true); //readyState = 1
            //4. send the request
            ajax.send("");   //readyState = 2   
        }
        function updatePage() {
             if (ajax.readyState == 4) {
                alert(ajax.responseText);
                //6. update the page using DOM
                document.getElementById("msg").innerHTML = ajax.responseText;
            }
        }
        //function which creates and returns AJAX object based on the browser used by the client
        function createAjaxObject() {
            try {
                var ajax = new XMLHttpRequest();
                return ajax;
            }
            catch (e) {
                try {
                    var ajax = new ActiveXObject("Microsoft.XMLHTTP");
                    return ajax;
                }
                catch (e) {
                    alert("ajax not supported");
                }
            }
        }
