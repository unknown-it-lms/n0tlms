Introduction to Node JS
Node.js is based on the JavaScript framework, but it is used for developing server-based applications. It is mainly devloped to address the limitation of traditional web servers like apache for supporting large number of concurrent users.
Basics of Node JS
  • Node.js was developed by Ryan Dahl in 2009
  • Node.js is an open-source, freely downloadable and cross-platform JavaScript runtime environment.
  • Node uses the V8 JavaScript engine, the one which is used by Google Chrome. Node has a wrapper over the JavaScript engine which makes the runtime engine much faster and hence the processing of requests within Node also become faster.
  • Node.js applications are written in JavaScript, and can be run within the Node.js runtime on any operating systems like Microsoft Windows, and Linux.
  • Node.js also provides a rich library of various JavaScript modules which simplifies the development of web applications
  • So basically node js is nothing but :
    Node.js = Runtime Environment + JavaScript Library
  • Node.js can be used to build different types of applications such as command line application, web application, real-time chat application, REST API server etc. But, it is mainly used to build network programs like web servers, similar to PHP, Java, or ASP.NET.

Features of Node.js
  1. Asynchronous event-driven IO helps concurrent request handling 
    This is probably the most significant selling point of Node.js. This feature basically means that if a request is received by Node for some Input/Output operation, it will execute the operation in the background and continue with processing other requests.
  2. V8 JavaScript Runtime engine
    Node uses the V8 JavaScript Runtime engine, the one which is used by Google Chrome. Node has a wrapper over the JavaScript engine which makes the runtime engine much faster and hence the processing of requests within Node also become faster.
  3. Handling of concurrent requests
    Another key functionality of Node is the ability to handle concurrent connections with a very minimal overhead on a single process.
  4. The Node.js library uses JavaScript
    This is another important aspect of development in Node.js. A major part of the development community is already well versed in javascript, and hence, development in Node.js becomes easier for a developer who knows javascript.
  5. Cross-platform framework
    It is available for Windows, MAC or Linux
  6. Lightweight framework
    It includes bare minimum modules. Other modules can be included as per the need of an application. Size of node Js installable is very small in size.
  7. Open source framework
    Node.js is an open-source framework under MIT license. (MIT license is a free software license originating at the Massachusetts Institute of Technology (MIT).)
Difference from Traditional Programming
Working of traditional web servers
​
In the traditional web server model, each request is handled by a dedicated thread from the thread pool. If no thread is available in the thread pool at any point of time then the request waits till the next available thread. Dedicated thread executes a particular request and returns only after completing the execution and returns a response. Every thread takes up system RAM so when available RAM is over, incoming requests has to wait till some thread is becoming free.
Working of NodeJS Server

​

Node JS is designed with non-blocking, event driven architecture. 
The asynchronous flow:
  • JavaScript code executes on the single thread.
  • When a non-blocking I/O operation is encountered, Node.js initiates it and registers a callback function to be executed upon completion.
  • The execution flow continues without waiting for the I/O operation to finish.
  • The I/O operation is handled in the background by the operating system's kernel.
  • When the I/O operation completes, the kernel pushes the associated callback function onto the event queue.
  • The event loop continuously checks if the call stack is empty.
  • If the call stack is empty, the event loop takes the first callback function from the event queue and pushes it onto the call stack for execution.
  • This process repeats, allowing Node.js to handle many concurrent I/O operations efficiently without blocking the main thread.
Different components involved in NodeJS architecture:
  1. Single Thread: Node.js primarily runs JavaScript code on a single thread. This means that at any given moment, only one JavaScript statement is being executed.
  2. Event Loop: This is the heart of Node.js's non-blocking I/O model. The event loop continuously monitors the call stack (where JavaScript code executes) and the event queue (where completed asynchronous operations are placed).
  3. Non-Blocking I/O: When Node.js needs to perform an I/O operation (like reading a file, making a network request, or querying a database), it doesn't wait for that operation to complete. Instead, it delegates the task to the operating system's kernel (which can handle these operations in a non-blocking way) and immediately moves on to execute other JavaScript code.
  4. Event Queue: When an asynchronous I/O operation completes, the kernel notifies Node.js, and a corresponding callback function is placed in the event queue.

In summary, Node.js runs in a single process and the application code runs in a single thread. So it needs less resources than other platforms. All the user requests for the web application will be handled by a single thread
Node.js uses worker threads are used for performing CPU-intensive tasks. Some common tasks include image processing, data processing, encryption and decryption, numerical calculations. But these tasks run parallel without blocking event loop. So, this single thread doesn't have to wait for the request to complete and is free to handle the next request. When asynchronous I/O work completes then it processes the request further and sends the response.

Scenarios for using Node JS
Node.js is best for usage in following types of applications

Node JS is should not be used in following types of applications

Node Setup
Node.js development environment can be setup in Windows, Mac, Linux and Solaris. The following tools/SDK are required for developing a Node.js application on any platform.
  • Node.js
  • Node Package Manager (NPM)
  • IDE (Integrated Development Environment) or TextEditor
NPM (Node Package Manager) is included in Node.js installation since Node version 0.6.0., so there is no need to install it separately.
Steps to follow for Node JS installation
Step 1: Download the Installer
Download the Windows Installer from NodeJs official website. Make sure you have downloaded the latest version of NodeJS. It includes the NPM package manager.
The LTS (Long-term Support) version is highly recommended for you. After the download of the installer package, install it with a double-click on it.
Now .msi file will be downloaded to your browser. Choose the desired location for that.

Step 2: Install Node.js 
Double-click to install .msi binary files to initiate the installation process. Then give access to run the application.
  • You will get a welcome message on your screen and click the “Next” button. The installation process will start.
  • Choose the desired path where you want to install Node.js. NPM
  • You will get a custom page setup on the screen. Make sure you choose npm package manager , not the default of Node.js runtime . This way, we can install Node and NPM simultaneously.
You should have 143MB of space to install Node.js and npm features.
The following features will be installed by default:
  • Node.js runtime
  • Npm package manager
  • Online documentation shortcuts
  • Modification of Path

Step 3: Verify installation
To verify installation, open command prompt widow and type following commands :
To confirm Node installation, type node -v command.
To confirm NPM installation, type npm -v command.

REPL terminal
The REPL (Read-Eval-Print Loop) terminal in Node.js is a built-in interactive environment. It is used for testing JavaScript code, execute statements, so that result can be seen immediately.
To start the Node.js REPL terminal,
Type node command in the terminal and press Enter. This will start the Node.js REPL terminal, and the prompt gets changed to '>'.
Type JS statements and press enter, result will be shown immediately
