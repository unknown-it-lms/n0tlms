Node Modules
Node application represents a complete JavaScript program or script executed using Node.js, and a Node module is a smaller unit of reusable code that can be imported and used within a Node application. We will learn about the different modules available in Node JS for developing applications.
Introduction to Node Modules
  • Module in Node.js is a simple or complex functionality organized in single or multiple JavaScript files which can be reused throughout the Node.js application.
  • Each module in Node.js has its own context, so it cannot interfere with other modules.  It will have it's own set of variables, functions and objects etc.
  • Each module can be placed in a separate .js file under a separate folder.
  • Node modules helps to promote code reusability, maintainability, and modularity in Node.js applications.
  • Node JS module can expose their functionality through the use of exports(or module.exports) object. Whichever variable, function or object that is exported by a module can be used in the application if the respective module is required in the application.
  • exports is a global object available to all the modules. Basically concept is similar like whatever is stuffed in exports will be available by using the module in the application. 
  • Node modules can be imported into Node applications using the require() function, which loads and executes the module's code, making its exports available for use within the application.
Node.js includes three types of modules:
  1. Core Modules
  2. Local Modules
  3. Third Party Modules

User Defined Modules
User defined or custom modules are created by the developer locally in the Node.js application. These modules are included in node application using require function.
Creating a User-defined module
Create a .js file which contains the Custom module:
customModule.js
// Returns addition of two numbers
exports.add = function (a, b) {
    return a+b;
}; 
// Returns difference of two numbers
exports.subtract = function (a, b) {
    return a-b;
}; 
Note that the functions we add to the Custom Module must be defined with "exports" or "module.exports" in front of the function name. 
Using the User-Defined (Custom) Module
nodeApp.js
var cm = require('./customModule.js');
var a=100, b=10;
console.log("Addition : "+cm.add(a,b));
console.log("Subtraction : "+cm.subtract(a,b));
console.log("My Application has been finished !");
Points to remember

  • A custom module is loaded using the syntax as for a regular module: "var cm = require('./customModule.js');".
  • In the require command we need to put the name of the file which keeps the module functions. In some cases, module name can be used in place of file path. 
  • Usage of the module in the node application will be decided by what is exposed by the module.
Core Modules
Set of built in modules of that are part of nodejs runtime installation are called core modules. These modules are defaultly available for any node application.
Node.js is a light weight framework. The core modules include bare minimum functionalities of Node.js. These core modules are compiled into its binary distribution(as they are developed in C/C++) and load automatically when Node.js process starts. But, core module needs to be impoerted to use in the application.
Examples of core modules

Loading Core Modules
In order to use Node.js core modules, it needs to be imported using require() function as shown below.
var module = require('module_name');
As per above syntax, specify the module name in the require() function. The require() function will return an object, function, property or any other JavaScript type, depending on what the specified module returns.
Using http module
The http module in Node.js is a core module that provides functionality for creating HTTP servers and clients. It allows to handle incoming HTTP requests, send HTTP responses.
Creating http server​​​​​​
myserver.jsDescription
var http = require('http');
var server = http.createServer(function(req, res){
  //write code here for processing client's requests
});
server.listen(5000, function() {
    console.log("Server is running at http://localhost:5000");
}); 		createServer() method takes a request listener callback function as an argument, which is called every time the server receives an HTTP request.

listen() method is used to start an HTTP server and make it listen for incoming connections on a specified port
Note : execute above file using the command node myserver.js. Message will be seen on the console as "Server is running at http://localhost:5000"
Handling HTTP requests
myserver.jsDescription
var http = require('http');
var server = http.createServer(function(req, res){
        res.writeHead(200, {'Content-Type': 'text/html'});
        res.write("<p> Home Page </p>");
        res.end();
});
server.listen(5000, function() {
    console.log("Server is running at http://localhost:5000");
}); 		1. Open the browser
2. Type the URL : "http://localhost:5000"
3. When a server receives the request, callback function of createServer gets executed which returns the response as "<p> Home Page </p>" 4. This response is visible on the client's browser. 

In the above example, require() function returns an object because http module returns its functionality as an object, you can then use its properties and methods using dot notation e.g. http.createServer(). This indicates server is listening on port no 5000. Clients can raise request using this port no and machin's IP address on the network. It is used for processing requests received from different clients.
Using url module
The url module in Node.js provides functions for URL parsing.  It allows to parse URLs into their different parts such as protocol, hostname, pathname, query parameters, etc. It has even functions for formatting URL also.
myserver.jsDescription
var http = require('http');
var u = require('url');
var myserv = http.createServer(function(req,res){
    var url_obj = u.parse(req.url, true); //first decode(sp symbols - special charaters) and then parse
    var nm = url_obj.query.name;
    res.writeHead(200,{'content-type':'text/html'});
    res.write("<h1 style='color:green'> Welcome "+nm+"</h1>");
    res.end();
});
myserv.listen(9000,function() {
    console.log("server started at 9000")
})		req.url is a string used by client for making the request
This string can be parsed to get the object having different parts of URL as keys
These different parts of URL can be accessed using appropriate key
To access query parameter "name", we can use url_obj.query.name and use it in the response

Third-party Modules
Third-party modules in Node.js refer to modules or packages that are not the part of core installation. But these modules are created and maintained by NodeJS community.  These modules can be installed via npm (Node Package Manager). Examples of third party modules are express, mongoose, etc.
Node Package Manager (NPM)
  • It is a command line tool that installs, updates or uninstalls Node.js packages in the application. It is also an online repository for open-source Node.js packages. The node community around the world creates useful modules and publishes them as packages in this repository.
  • NPM is included with Node.js installation.
  • NPM performs the operation in two modes: global and local. In the global mode, NPM performs operations which affect all the Node.js applications on the computer whereas in the local mode, NPM performs operations for the particular local directory which affects an application in that directory only.
Install Package Locally
Use the following command to install any third party module in your local Node.js project folder.
npm install <package name>
For example, the following command will install ExpressJS into MyNodeProj folder.
C:\MyNodeProj> npm install express
All the modules installed using NPM are installed under node_modules folder. The above command will create ExpressJS folder under node_modules folder in the root folder of your project and install Express.js there.
Add Dependency into package.json
Use --save at the end of the install command to add dependency entry into package.json of your application.
C:\MyNodeProj> npm install express --save
Install Package Globally
NPM can also install packages globally so that all the node.js application on that computer can import and use the installed packages. NPM installs global packages into /<User>/local/lib/node_modules folder.
Apply -g in the install command to install package globally. For example, the following command will install ExpressJS globally.
C:\MyNodeProj> npm install -g express
Update Package
To update the package installed locally in your Node.js project, navigate the command prompt or terminal window path to the project folder and write the following update command.
C:\MyNodeProj> npm update <package name>
The following command will update the existing ExpressJS module to the latest version.
C:\MyNodeProj> npm update express
Uninstall Packages
Use the following command to remove a local package from your project.
C:\>npm uninstall <package name>
The following command will uninstall ExpressJS from the application.
C:\MyNodeProj> npm uninstall express
