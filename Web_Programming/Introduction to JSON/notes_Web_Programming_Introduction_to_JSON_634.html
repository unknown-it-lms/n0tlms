Introduction to JSON
JSON is a new standard that is being followed in the web applications for exchanging data between client and server. Prior to JSON, XML was used for this purpose but we have now lightweight format available in the form of JSON. In this chapter we will learn about syntax and JSON functionality supported by java script.
What is JSON
JSON, short for JavaScript Object Notation, is a format for sharing data. As its name suggests, JSON is derived from the JavaScript programming language, but it’s available for use by many languages including Python, Ruby, PHP, and Java. JSON is usually pronounced like the name “Jason.”
  • JSON is a text format for storing and transporting data
  • JSON is "self-describing" and easy to understand
  • JSON is also readable, lightweight, offers a good alternative to XML, and requires much less formatting.
  • JSON being independent of a platform is one of the major choices of format for transfer of data between computers that exchange tons of data each day.
  • An alternative to JSON is XML (extensible markup language), but JSON is better in many ways. While both are human-readable and machine-readable, JSON is much easier to read and is also faster for computers to process.
  • Furthermore, JSON is processed (or parsed) with a JavaScript parser (which is built-into most web-browsers) while XML requires a separate XML parser.
  • JSON is hierarchical in nature i.e. values within values

JSON Syntax
JSON (JavaScript Object Notation) is a lightweight data-interchange format. It is easy for humans to read and write. It is easy for machines to parse and generate. It is based on a subset of the JavaScript Programming Language Standard. JSON is a text format that is completely language independent but uses conventions that are familiar to programmers. These properties make JSON an ideal data-interchange language.
A JSON data can be considered as set of key-value pairs where values can be string in double quotes, or a number, or true or false or null, or object or array.
Data types supported in JSON
  1. Strings
    Enclosed within double quotes "" and represent sequences of characters.
  2. Numbers
    Integer or floating-point values.
  3. Booleans
    Represented by true or false.
  4. Null
    Represents the absence of a value.
  5. Arrays
    Ordered lists of values enclosed within square brackets []
  6. Objects
    Unordered collections of key-value pairs enclosed within curly braces {}.
Note:
JSON syntax does not support date type of data. Date values should be written as strings. When these date values to be used as dates, these values need to be parsed.
JSON syntax does not support undefined value
JSON syntax does not support even comments
Delimiters used in JSON syntax
  1. Key and value separated by colon(:)
  2. Objects are enclosed within curly braces {}.
  3. Arrays are enclosed within square brackets [].
  4. Strings are enclosed within double quotes "".
  5. Key-value pairs within objects are separated by commas ,. 
Basic syntax
The syntax for a key-value pair is as follows:
"key": value
The keys must be strings and are followed by a colon : to separate them from their corresponding values.
Multiple key-value pairs are separated by commas.
Objects can contain arrays, and arrays can contain objects or other arrays. Means it can be nested within one another.

JSON Parsing
Javascript provides some default objects that represent and interact with structured data buffers and data coded using JavaScript Object Notation (JSON). Such one of the very important object is JSON. It is supported by all the modern browsers. All properties and methods of JSON are static (just like the Math object). It provides 2 important methods to deal with JSON data :
  • Parsing JSON string
  • Converting object into JSON
Parsing JSON string
The JSON.parse() is a static method which parses a JSON string according to the JSON syntax,  then evaluates the string as if it's a JavaScript expression. It constructs the JavaScript object described by the string.
An optional reviver function can be passed as a second argument. This function is used to transform key-value pairs of a generated object. 
This is generally used in the scenario when web page received the data from the web server in the form of json.
If the given string is not valid JSON, it will throw a syntax error.
Javascript code
// Store JSON data in a JS variable
var json = '{"name": "Sachin", "age": 22, "country": "India"}';
// Converting JSON-encoded string to JS object
var obj = JSON.parse(json);
// Accessing individual value from JS object
alert(obj.name); // Outputs: Sachin
alert(obj.age); // Outputs: 22
alert(obj.country); // Outputs: India
// str contains JSON data as in the form of string
var str = '[{"empid":1001,"ename":"Amit","salary":10000},{"empid":1001,"ename":"Rahul","salary":10000},{"empid":1006,"ename":"Milind","salary":14000}]';
//after parsing - array of object
 var emps = JSON.parse(str);
 var data = "<table border=1>";
// iterate thr the array created
 for(i = 0;i< emps.length;i++) {
        data+="<tr>";
        data+="<td>"+emps[i].empid+"</td>";
        data+="<td>"+emps[i].ename+"</td>";
        data+="<td>"+emps[i].salary+"</td>";
        data+="</tr>";       
 }
 data+="</table>";
//display data as HTML table on the web page
 document.getElementById("emptable").innerHTML=data

Converting object into JSON
The JSON.stringify() is a static method which converts a JavaScript object to a JSON string. This function may accept second argument as a replacer function. If a replacer function is specified it can modify the process of converting  object into string.
Javascript code
// Sample JS object
var obj = {name: "Sachin", age: 22, country: "India"};
// Converting JS object to JSON string
var json = JSON.stringify(obj);
alert(json);
//outputs : {"name":"Sachin","age":22,"country":"India"}

Note :
  • Keys in javascript object not are not quoted but keys in json are quoted
  • Generally while sending the data, JSON is sent as a string using stringify function
  • When JSON data is received, it is generally in the string format which will be parsed using JSON.parse() method to retrieve data from json.
