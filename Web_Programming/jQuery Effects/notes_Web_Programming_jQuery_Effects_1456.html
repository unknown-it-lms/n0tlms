jQuery Effects
jQuery effects enhances the interactivity of the web page. jQuery provides a very simple ways for adding various kind of amazing effects like show, hide, fade-in, fade-out, slide-up, slide-down, toggle etc. All jquery effects are similar in nature and almost all accept the similar arguments. 
Hiding
In jQuery,  hide(), show(), and toggle() methods are used to control the visibility of elements on a web page. These methods allow you to hide or show elements, or toggle between hiding and showing them based on their current state.
Required parameters:
  • All these functions accept first parameter as speed and second parameter as callback function.
  • Both the parameters are optional so function can be called without passing any data.
  • First parameter specifies the speed of the hiding/showing which allows values like "slow", "fast" or no of milliseconds
  • The optional callback parameter is a function to be executed after the effect is completely executed.
Examples
CodeDescription
$("button").click(function(){
  $("p").hide();
});		Selected paragraph is hidden when the selected button is clicked. Speed and callback parameters are not specified
$("button").click(function(){
  $("p").hide("slow");
});		Selected paragraph is hidden with slow speed
$("button").click(function(){
  $("p").show(3000);
});		Paragraph will be shown in time limit of 3000 ms.
$("button").click(function(){
  $("p").show("fast", function() {
     console.log("Paragraph is shown");
  });
});		Paragraph will be shown fast and when paragraph is completely shown, msg will appear on console.

jQuery toggle()
It is also possible to toggle between hiding and showing an element with the toggle() method. 
Shown elements are hidden and hidden elements are shown. Function syntax and parameter specification is similar like hide and show.
$(selector).toggle(speed,callback);
Sliding
In jQuery, you can create sliding effects to hide or show elements with a smooth animation. The slideUp(), slideDown(), and slideToggle() methods are commonly used to achieve sliding effects.
Required parameters
Parameters are exactly similar like hide method
slideUp() and slideDown()
The jQuery slideUp() and slideDown() methods is used to hide or show the HTML elements by gradually decreasing or increasing their height (i.e. by sliding them up or down). This effect is similar like raising or lowering the curtain.
jQuery slideUp() example
jQuery slideDown() example
$(document).ready(function(){
    // Display alert message after sliding up paragraphs
    $(".up-btn").click(function(){
        $("p").slideUp("slow", function(){
            // Code to be executed
            alert("The slide-up effect is completed.");
        });
    });
});
$(document).ready(function(){
// Display alert message after sliding down paragraphs
    $(".down-btn").click(function(){
        $("p").slideDown("slow", function(){
            // Code to be executed
            alert("The slide-down effect is completed.");
        });
    });
});
jQuery slideToggle() Method
The jQuery slideToggle() method show or hide the selected elements by animating their height. If the element is initially displayed, it will slide up; if hidden, it will slide down i.e. toggling between the slideUp() and slideDown() methods. Parameters are exactly similar.
Fading
In jQuery, fading effects is used to hide or show elements with a smooth transition between visible and hidden states is possible. jQuery provides several methods to achieve fading effects: fadeIn(), fadeOut(), fadeToggle(), and fadeTo(). This effect changes opacity of element over time.
jQuery fadeIn() and fadeOut() Methods
Parameters are exactly similar like hide method (i.e. speed and callback).  jQuery fadeIn() and fadeOut() methods to display or hide the HTML elements by gradually increasing or decreasing their opacity. This effect is different than sudden hiding or showing of the elements.
jQuery fadeIn() examplejQuery fadeOut() example

    $(".in-btn").click(function(){

            // Code to be executed
            alert("The fade-in effect is completed.");
        });
    });
});  		$(document).ready(function(){
    // Display alert message after fading out paragraphs
    $(".out-btn").click(function(){
        $("p").fadeOut("slow", function(){
            // Code to be executed
            alert("The fade-out effect is completed.");
        });
    });
 });   
jQuery fadeToggle() Method
The jQuery fadeToggle() method display or hide the selected elements by animating their opacity. If the element is initially displayed, it will be fade out; if hidden, it will be fade in (i.e. toggles the fading effect). Both the parameters are exactly same i.e. speed and callback
jQuery fadeToggle() example
$(document).ready(function(){
    // Display alert message after fade toggling paragraphs
    $(".toggle-btn").click(function(){
        $("p").fadeToggle(1000, function(){
            // Code to be executed
            alert("The fade-toggle effect is completed.");
        });
    });
});
//combination of fadeIn and fadeOut
jQuery fadeTo() Method
The jQuery fadeTo() method is similar to the fadeIn() method, but it allows to fade in the elements to a certain opacity level. Basic syntax is :
$(selector).fadeTo(speed, opacity, callback);
The required additional opacity parameter specifies the final opacity that can be a number between 0 and 1. The duration or speed parameter is also required for this method that specifies the duration of the fade to animation.​​​​​​​
jQuery fadeTo() example
$(document).ready(function(){
    // Fade to paragraphs with different opacity
    $(".to-btn").click(function(){
        $("p.none").fadeTo("fast", 0);
        $("p.partial").fadeTo("slow", 0.5);
        $("p.complete").fadeTo(2000, 1);
    });
});

The effect of fadeIn()/fadeOut() method looks similar to show()/hide(), but unlike show()/hide() method the fadeIn()/fadeOut() method only animates the opacity of the target elements and does not animates their dimensions.
Animation
jQuery animate() Method
Animation effects in jQuery allow you to create dynamic and attractive transitions or movements on the web page. The animate() method is typically used to animate numeric CSS properties, for example, width, height, margin, padding, opacity, top, left, etc. but the non-numeric properties such as color or background-color cannot be animated using the basic jQuery functionality.
Not all CSS properties are animatable. In general, any CSS property that accepts values that are numbers, lengths, percentages, or colors is animatable. To manipulate and animate the color need to use the additional jQuery library file.
The basic syntax of the jQuery animate() method can be given with:
$(selector).animate({ properties }, duration, callback);
The parameters of the animate() method have the following meanings:
  • The required properties parameter defines the CSS properties to be animated.
  • The optional duration parameter specifies how long the animation will run. Durations can be specified either using one of the predefined string 'slow' or 'fast', or in a number of milliseconds; higher values indicate slower animations.
  • The optional callback parameter is a function to call once the animation is complete.
Simple example
$(document).ready(function(){
    $("button").click(function(){
        $("img").animate({
            left: "300px"
        });
    });
});          //this changes the left position of the selected element to 300 px
Animate Multiple Properties At Once
It is possible to animate multiple properties of an element together at the same time using the animate() method. All the properties animated simultaneously without any delay.
Example
 $(document).ready(function(){
    $("button").click(function(){
        $(".box").animate({
            width: "300px",
            height: "300px",
            marginLeft: "150px",
            borderWidth: "10px",
            opacity: 0.5
        });
    });
});
Note:
The CSS properties names must be camel-cased when using with the animate() method, e.g. if you want to animate the font size you need to write 'fontSize' rather than 'font-size'. Similarly, write 'marginLeft' instead of 'margin-left', 'borderWidth' instead of 'border-width', and so on.
Queued Animations
It is also possible to animate the multiple properties of an element one by one individually in a queue using the jQuery's chaining feature.
Example
 $(document).ready(function(){
    $("button").click(function(){
        $(".box")
            .animate({width: "300px"})
            .animate({height: "300px"})
            .animate({marginLeft: "150px"})
            .animate({borderWidth: "10px"})
            .animate({opacity: 0.5});
    });
});
Animate Properties with Relative Values
Even relative values can be specified for the animated properties. If a value is specified with a leading += or -= prefix, then the target value is calculated by adding or subtracting the given number from the current value of the property.
Example
$(document).ready(function(){
    $("button").click(function(){
        $(".box").animate({            
            top: "+=50px",
            left: "+=50px",
            width: "+=50px",
            height: "+=50px"
        });
    });
});

Stopping animation
In jQuery, an ongoing animation can be stopped using the stop() method. This method is useful when you want to interrupt an animation and immediately move the element to its end state or stop it from continuing further.
Basic syntax is 
$(selector).stop(); 
This method accepts 2 optional parameters where both are set to false by default :
clearQueue:  If set to true, all remaining queued animations for the selected elements will be removed. 
jumpToEnd:  If set to true, the current animation will jump to its end state.
