Arrays in Javascript
As we know, arrays can be used to store multiple values. Javascript makes use of arrays very frequently for client side scripting. In this chapter we will learn about basics of array like creating array, accessing elements from array and different array functionality. Some array functions use callback functions as arguments.
JS Objects
  • JavaScript object is a non-primitive data-type that allows you to store multiple collections of data.
  • JavaScript objects are a bit different. You do not need to create classes in order to create objects. But ES6 introduced class syntax for creating objects.
  • Objects are mutable, meaning their properties can be changed after creation
  • JavaScript objects are dynamic, allowing you to add or remove properties and methods at runtime
  • ​​​​​​​Objects can be nested within other objects to create complex data structures.
Creating objects
The general syntax to declare an object using object literal syntax:
const object_name = {
   key1: value1,
   key2: value2
}
Javascript codeExplanation
// object creation
const person = { 
    name: 'John',
    age: 20
};
console.log(typeof person); // object		Here, an object person is defined. Each member of an object is a key: value pair separated by commas and enclosed in curly braces {}.
typeof person will be displayed as object.
In the above example, name and age are keys, and John and 20 are values respectively.
In JavaScript, "key: value" pairs are called properties. For example,
let person = { 
    name: 'John',
    age: 20
};		Here, name: 'John' and age: 20 are properties.
const and let both can be used for creating objects. if const is used, it cannot be reassigned to another object. let will allow to reassign the variable reference to another object.
Accessing Object Properties
You can access the value of a property by using its key.
For example,
const person = { 
    name: 'John', 
    age: 20, 
};
  1. Using dot Notation
    Here's the syntax of the dot notation.
    objectName.key
    // accessing property
    console.log(person.name); // John
  2. Using bracket Notation
    Here is the syntax of the bracket notation.
    objectName["propertyName"]
    // accessing property
    console.log(person["name"]); // John
Nested objects
An object can also contain another object. e.g.
const student = { 
    name: 'John', 
    age: 20,
    marks: {
        science: 70,
        math: 75
    }
}
// accessing property of student object
console.log(student.marks); // {science: 70, math: 75}
// accessing property of marks object
console.log(student.marks.science); // 70
Object containing functions
In JavaScript, an object can also contain a function. For example,
const person = {
    name: 'Sam',
    age: 30,
    // using function as a value
    greet: function() { console.log('hello') }
}
person.greet(); // hello
JS built in objects - array
​​​​​​​In JavaScript, an array is an ordered list of values. Each value is called an element specified by an index:

​

A JavaScript array has the following characteristics:
  • First, an array can hold values of mixed types. For example, you can have an array that stores elements with the types number, string, boolean, and null.
  • Second, the size of an array is dynamic and auto-growing. In other words, you don’t need to specify the array size up front.

Accessing JavaScript array elements
JavaScript arrays are zero-based indexed. In other words, the first element of an array starts at index 0, the second element starts at index 1, and so on. 
To access an element in an array, you specify an index in the square brackets []:
arrayName[index]
The following shows how to access the elements of the mountains array:
let mountains = ['Everest', 'Fuji', 'Sahyadri'];
console.log(mountains[0]); // 'Everest'
console.log(mountains[1]); // 'Fuji'
Modify existing element
To change the value of an element, you assign that value to the element like this:
let mountains = ['Everest', 'Fuji', 'Sahyadri'];
mountains[2] = 'K2';
console.log(mountains);
Output:
[ 'Everest', 'Fuji', 'K2' ]
Getting the array size
Typically, the length property of an array returns the number of elements. The following example shows how to use the length property:
let mountains = ['Everest', 'Fuji', 'Sahyadri];
console.log(mountains.length); // 3

Adding and removing from any position

Advanced array functionality
Arrays in javascript support some functionality which needs another function as a argument like forEach, map, filter, reduce, every etc. Function which needs to be passed as argument to these functions can be defined separately or can be passed as anonymous function or can be passed as arrow function.
Callback function
A function is a block of code that performs a certain task when called. In JavaScript, a function can be passed as an argument to a function. This function that is passed as an argument inside of another function is called a callback function. For example,
CodeExplanation
function callMe() {
    console.log('I am callback function');
}		callback function definition. 
function greet(name, callback) {
    console.log('Hi' + ' ' + name);
    callback();
}		function which needs function as a argument
second argument is a function
greet('Peter', callMe);passing function as an argument

Sorting an array
The sort() method sorts the elements of an array in place and returns the reference to the same array which is now sorted. The default sort order is ascending, built upon converting the elements into strings, then comparing.
The time and space complexity of the sort cannot be guaranteed as it depends on the implementation.
CodeExplanation
const months = ['March', 'Jan', 'Feb', 'Dec'];
months.sort();
console.log(months);		Sorted based on natural sorting (using ascii values)
Expected output: Dec, Feb, Jan, March
const array1 = [1, 30, 4, 21, 100000];
array1.sort();
console.log(array1);		Sorted based on natural sorting (using ascii values)
Expected output: 1, 100000, 21, 30, 4
This function accepts optional argument in the form of callback function which accepts 2 arguments and returns difference between them
CodeExplanation
const points = [40, 100, 1, 5, 25, 10];
points.sort(function(a, b){return a - b});
console.log(points);		Sorted based on numeric values
Expected output: 1, 5, 10, 25, 40, 100
The argument to sort() function can be passed as :
  1. sort(compareFn) // Compare function
  2. sort(function compareFn(firstEl, secondEl) { ... }) // Inline anonymous compare function
  3. sort((firstEl, secondEl) => { ... } ) // Arrow function

Transforming an array
The map() method creates a new array populated with the results of calling a provided function on every element in the calling array. In short every element in the array gets transformed into some different value as defined by the callback function.
CodeExplanation
const array1 = [1, 4, 9, 16];
// Pass a function to map
const map1 = array1.map(x => x * 2);
console.log(map1);		In this example every element gets converted into element multiplied by 2. Here callback function is passed as an arrow function.
Expected output: 2, 8, 18, 32
Converting to single value
The reduce() method executes a given callback function on each element of the array. Every time callback function carries previous calculated value referred as accumulator. The final result of running the reducer across all elements of the array is a single value. Accumulator value can be specified if required
CodeExplanation
const array1 = [1, 2, 3, 4];
const initialValue = 0;
const sumWithInitial = array1.reduce(
  (accumulator, currentValue) => accumulator + currentValue,
  initialValue
);
console.log(sumWithInitial);		In this example reduce function is called by passing 2 arguments : arrow function and initial value. For every iteration arrow function gets called by carrying previous sum calculated. Final sum will be calculated like this:
0+1
1+2
3+3
6+4
Expected output: 10
Filtering an array
The filter() method returns an array of only those elements from the array which pass the condition. This condition is implemented in the given callback function.
CodeExplanation
const words = ['spray', 'limit', 'elite', 'exuberant', 'destruction', 'present'];
const result = words.filter(word => word.length > 6);
console.log(result);		Every element is tested with the condition whether the length of the string is above 6. If elements passes this test, then only it will be part of the filtered array in the outcome.
Expected output: Array ["exuberant", "destruction", "present"]
Testing array elements for given condition
The every() method tests whether all elements in the array pass the test implemented by the provided function. It returns a Boolean value.
CodeExplanation
var alleven = arr.every(v => v % 2 == 0);
document.write("all even : "+alleven);		This code checks whether every element is even. When all the array elements are even, then only every function will return true otherwise false.
The some() method tests whether at least one element in the array passes the test implemented by the given function. It returns true if, in the array, it finds an element for which the provided function returns true; otherwise it returns false. It returns a Boolean value.
CodeExplanation
var someeven = arr.some(v => v % 2 == 0);
document.write("some even : " + someeven);		This code checks whether at least one element is even.
Using spread operator with arrays
  • The spread operator, denoted by three consecutive dots (...)
  • It allows you to expand an iterable (e.g., an array, string, or object) into individual elements
  • It allows for compact syntax when working with arrays, and allows operations like concatenation, copying, and passing array elements to function performed very easily.
  • Use cases of spread operator
Copying arrayconst arr1 = [1, 2, 3];
const arr2 = [...arr1]; // Creates a shallow copy of arr1
Concatenating Arraysconst arr1 = [1, 2];
const arr2 = [3, 4];
const concatenatedArr = [...arr1, ...arr2]; // [1, 2, 3, 4]
Adding Elements to Arraysconst arr1 = [1, 2, 3];
const arr2 = [...arr1, 4, 5]; // [1, 2, 3, 4, 5]
Passing Array Elements as Argumentsconst numbers = [1, 2, 3];
const sum = (a, b, c) => a + b + c;
console.log(sum(...numbers)); // 6
Unpack the value of the array into separate variablesconst array = [1, 2, 3];
const [a, b, c] = [...array];
Array destructuring
  • Array destructuring in JavaScript is a syntax that allows to unpack the array elements into separate(distinct) varibales.
  • It's a simple way to extract specific elements or the entire array into individual variables.
  • Basic syntax
    var arr = [4, 5, 6, 7]
    const [first, second, third] = arr;
    This destructures the array [1, 2, 3] and assigns the values 1, 2, and 3 to the variables first, second, and third,        respectively.
const [a, b, ...rest] = [1, 2, 3, 4, 5];This destructures the array [1, 2, 3, 4, 5]. a will be 1, b will be 2, and rest will be an array containing [3, 4, 5] (the rest of the elements). 
const myArray = [1, 2, 3, 4, 5, 6];
const [first,,third,...rest] = myArray;		This destructures the array [1, 2, 3, 4, 5,6]. first will be 1, third will be 3 and rest array containing [4,5,6].
Note element 2 will be skipped.
