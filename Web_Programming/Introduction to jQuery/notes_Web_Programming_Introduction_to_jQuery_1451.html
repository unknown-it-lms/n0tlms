Introduction to jQuery
jQuery is a fast, small, and feature-rich JavaScript library. It makes java script coding very easy. Complicated tasks like HTML document traversal and manipulation, event handling, animation, and Ajax can be much simpler with JQuery functionality that works across a multitude of browsers. 
Need of jQuery
Introduction and features
  • jQuery is a JavaScript Library.
  • jQuery greatly simplifies JavaScript programming. It is always considered as write less and do more. It means for a particular task if we need 8-10 lines in javascript, it can be replaced by 3-4 lines in jQuery.
  • jQuery provides lot of functions needed for accessing and modifying HTML elements
  • jQuery simplifies a lot of frequently required complicated tasks from JavaScript, like AJAX calls and DOM manipulation.
  • jQuery is easy to learn with basic knowledge of HTML, CSS and Javascript.
Tasks which become easy using jQuery
The jQuery library contains functionality for the following tasks:
  • jQuery provides functions which allows to easily traverse the DOM tree,
  • Functions  for modifying HTML content
  • Allows to add, remove and toggle styles of HTML elements
  • Handling events
  • Applying hiding, sliding effects and using animations on HTML elements
  • AJAX calls
History 
jQuery was first released in January 2006 by John Resig at BarCamp NYC. It is currently headed by Timmy Wilson and maintained by a team of developers.
Nowadays, jQuery is widely used technology. Big companies like Google, Microsoft and IBM are using the jQuery for their applications.
Current most stable version of jQuery is 3.7.1 released in August 2023
Advantages of jQuery
There are several advantages why one should opt for jQuery:
  1. Easy to learn 
    jQuery is easy to learn because it supports same JavaScript style coding. Anybody with the basic working knowledge of HTML, CSS and JavaScript can start development with jQuery.
  2. Save lots of time
    You can save lots of time and efforts by using the jQuery inbuilt functions for traversing HTML, modifying HTML and applying different effects on HTML elements on occurrence of event.
  3. Simplify common JavaScript tasks 
    jQuery considerably simplifies the common JavaScript tasks. It will be very easy to create feature rich and interactive web pages with fewer lines of codes, a typical example is implementing Ajax to update the content of a page without refreshing it. 
  4. Cross-browser support 
    jQuery is created with modern browsers in mind and it is compatible with all major modern browsers such as Chrome, Firefox, Safari, Internet Explorer, etc.
  5. Absolutely Free
    jQuery library is completely free to download and use.
  6. Performance 
    jQuery is lightweight and efficient which minimizes page load times.

jQuery Events
Events are often triggered by the user's interaction with the web page, such as when a link or button is clicked, text is entered into an input box or textarea, selection is made in a select box, key is pressed on the keyboard, the mouse pointer is moved etc. In some cases, the Browser itself can trigger the events, such as the page load and unload events.
jQuery provides a comprehensive set of event handling methods to interact with user actions and DOM changes.
jQuery has simplified the event-handling mechanisms by providing the event functions to all the events. For example, to execute some JavaScript code when the DOM is ready, jQuery ready() function can be used. 
In jQuery, events can be categorized into several groups based on their occurrence or nature. Following are the main categories of events in jQuery.
Document loading events
These events are triggered during different stages of the document loading process, such as when the DOM is ready or when all resources (including images and scripts) have finished loading.
EventEvent functionMeaning
ready$(document).ready(callback)When DOM (Document Object Model) is fully loaded and ready to be manipulated.
load$(window).load(callback)When entire page is fully loaded including external resources like images, styles etc
Mouse events
These events are triggered by mouse interactions, such as moving the mouse pointer over elements, clicking on elements
EventEvent functionMeaning
click$("#img1").click(callback)When the selected element with id is clicked
mouseenter$("div.content").mouseenter(callback)When mouse pointer is within the selected element 
mouseleave$("div.content").mouseleave(callback)When mouse pointer is removed from the selected element 
mousedown$("p").mousedown(callback)When mouse button is clicked but not released
mouseup$("p").mouseup(callback)When clicked mouse button is released
Keyboard events
These events are triggered by keyboard interactions, such as pressing keys on the keyboard. 
EventEvent functionMeaning
keydown$("textarea").keydown(callback)When the key is pressed but not released 
keyup$("#name").keyup(callback)When mouse pointer is within the selected element 
keypress$("div.content").keypress(callback)When mouse pointer is removed from the selected element 
Form events
These events are triggered by interactions with HTML form elements, such as submitting a form, changing input values, etc.
EventEvent functionMeaning
focus$(".input").focus(callback)When selected form element gains focus
blur$(".input").blur(callback)When selected form element looses focus
change$(".input").change(callback)When selected form element changes the text
submit$("form").submit(callback)When the selected form is submitted using submit button or function call
Adding jQuery Functionlity to HTML
To use jQuery from HTML page, jQuery library needs to be made available to the HTML page. There are two methods to include jQuery to your HTML.
  • You can download and include the jQuery file
  • You can include the jQuery by CDN.
Download and include jQuery file
In this method, you have to download the jQuery js file and include it using a simple <script > tag within the HTML code. If you want to include the jQuery to your HTML page by downloading the jQuery file, simply follow the steps given below. 
Step 1: You have to download the jquery js file from the official site of jQuery.
https://jquery.com/download/
There are two versions of jQuery available for downloading:
  • Production version - this is for your live website because it has been minified and compressed
  • Development version - this is for testing and development (uncompressed and readable code) 
Both versions can be downloaded from jQuery.com. 
The jQuery library is a single JavaScript file.
Step 2:  After downloading the file, specify the jquery path in HTML file. In your HTML file, use the <script> tag, which specifies the src attribute for adding the jQuery file in the head tag just as shown below:
<script type="text/javascript" src="jquery-3.7.1.min.js"> </script> 
Including the jQuery by CDN. 
Another method to include your jQuery to HTML is including the jQuery by CDN(Content Delivery Network). Use CDN path for src attribute of <script> tag which should be added in the <head> tag
<script type="text/javascript" src="http://ajax.googleapis.com/ajax/libs/jquery/3.7.1/jquery.min.js"> </script>

Advantage of using the hosted jQuery from Google
Many users already have downloaded jQuery from Google when visiting another site. As a result, it will be loaded from cache when they visit your site, which leads to faster loading time. 
document.ready Event
When working with JavaScript and the Document Object Model (DOM), script should run only when the DOM has loaded completely. Following are some examples of actions that can fail if functions run before the document is fully loaded:
  • Trying to hide an element that is not created yet
  • Trying to get the size of an image that is not loaded yet
Document's ready event will prevent any jQuery code from running before the document is finished loading (is ready). It is good practice to wait for the document to be fully loaded and ready before working with it.
For example, we want to write "Hello World!" to div tag in our web page. The first step is to check when the DOM is loaded fully so that we can find the div element and write "Hello World" to it. If we try to write it before DOM loads, jQuery may not find the div element because it might not be constructed at that time
ready() method
jQuery has built-in function ready(). This function acts as a event handler that is used to execute java script code once the DOM(Document Object Model) is fully loaded. 
This function takes a callback function as a parameter. This callback function will be called once document is ready.
$(document).ready(function() {
            // DOM is loaded by now...       
            // Write jQuery code here...
});
It is possible to use shorthand method for above code. It is more concise way to achieve the same result. It's functionally equivalent to the traditional method  
$(function() {
            // DOM is loaded by now...       
            // Write jQuery code here...
});
Difference between window's onload event and document's ready event
The $(document).ready() function determines when the full DOM hierarchy is loaded whereas window.onload event is raised when entire window is loaded including DOM, images, css and other required resources. The DOM loads before entire window loads. The onload event is a standard event in the DOM, while the ready event is specific to jQuery. 
Summary : We can write all your jQuery code inside the $(document).ready() method. This way, your code will wait for the DOM to be loaded before running.
