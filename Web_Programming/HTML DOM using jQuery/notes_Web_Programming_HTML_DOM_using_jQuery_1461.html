HTML DOM using jQuery
jQuery provides a number of methods to manipulate DOM in efficient way. You do not need to write big and complex code to set or get the content, style of any HTML element.
Here are some basic operations which you can perform on DOM elements with the help of jQuery standard library methods :
  • Extract the content of an element
  • Change the content of an element
  • Adding a child element under an existing element
  • Adding a parent element above an existing element
  • Adding an element before or after an existing element
  • Replace an existing element with another element
  • Delete an existing element
  • Wrapping content with-in an element
Get or Set Contents or Values
​​​​​​​Some jQuery methods can be used to either assign or read some value of a selected element. A few of these methods are text(), html(), attr(), and val().
When these methods are called with no argument, it is referred to as a getters, because it gets (or reads) the value of the element. When these methods are called with a value as an argument, it's referred to as a setter because it sets (or assigns) that value.
jQuery text() Method 
The jQuery text() method is either used to get the combined text contents of the selected elements, including their descendants, or set the text contents of the selected elements.
Get contents with text() 
Set Contents with text()
// Get combined text contents of all paragraphs
    $(".btn-one").click(function(){
        var str = $("p").text();
        alert(str);
    });    
    // Get text contents of the first paragraph
    $(".btn-two").click(function(){
       var str = $("p:first").text();
       alert(str);
    });
// Set text contents of all paragraphs
    $(".btn-one").click(function(){
        $("p").text("This is demo text.");
    });    
    // Set text contents of the first paragraph
    $(".btn-two").click(function(){
        $("p:first").text("This is another demo text.");
    });
Note: The jQuery text() retrieves the values of all the selected elements (i.e. combined text)
jQuery html() Method
The jQuery html() method is used to get or set the HTML contents of the selected elements. This function is similar to manipualting innerHTML property.
Get HTML Contents
Set HTML Contents
// Get HTML contents of first selected paragraph
    $(".btn-one").click(function(){
        var str = $("p").html();
        alert(str);
    });    
    // Get HTML contents of an element with ID container
    $(".btn-two").click(function(){
        var str = $("#container").html();
        alert(str);
    });
// Set HTML contents for document's body
    $("button").click(function(){
        $("body").html("<p>Hello World!</p>");
    });
Note: If multiple elements are selected, the html() method only returns the HTML contents of the first element from the set of matched elements.

Set Attributes

​​​​​​​jQuery val() Method
The jQuery val() method is mainly used to get or set the current value of the HTML form elements such as <input>, <select> and <textarea>.
Get the Values of Form Fields
Set the Values of Form Fields
   // Get value of a text input with ID name
    $("button.get-name").click(function(){
        var name = $('input[type="text"]#name').val();
        alert(name);
    });    
    // Get value of a textarea with ID comment
    $("button.get-comment").click(function(){
        var comment = $("textarea#comment").val();
        alert(comment);
    });    
    // Get value of a select box with ID city
    $("button.get-city").click(function(){
        var city = $("select#city").val();
        alert(city);
    });
// Set value of all the text inputs
    $("button").click(function(){
        var text = $(this).text();
        $('input[type="text"]').val(text);
    });
Note: If multiple form elements are selected, the val() method only returns the value of the first element from the set of matched elements.
Add and Remove Elements
​​​​​jQuery provides several methods, like append(), prepend(), html(), text(), before(), after(), wrap() etc. that allows us to insert new content inside an existing element. 
Inserting content at the beginning and end
The jQuery append() method is used to insert content to the end of the selected elements. So the appended element becomes last child of the selected element. The prepend() method is used to insert content to the beginning of the selected elements. Element that is inserted becomes the first child of the selected element.
At the beginningAt the end
// Append all paragraphs
    $("p").append(' <a href="#">read more...</a>');    
    // Append an element with ID container
    $("button").click(function(){
       $("#container").append("This is demo text.");
    });
// Prepend all paragraphs
    $("p").prepend("<strong>Note:</strong> ");
    
    // Prepend an element with ID container
    $("button").click(function(){
       $("#container").prepend("This is demo text.");
    });
The jQuery append() and prepend() also supports passing in multiple arguments as input.
Adding multiple elements
var newHeading = "<h1>Important Note:</h1>";
var newParagraph = document.createElement("p");
newParagraph.innerHTML = "<em>Lorem Ipsum is dummy text...</em>";
var newImage = $('<img src="images/smiley.png" alt="Symbol">');
$("body").append(newHeading, newParagraph, newImage);
Adding content adjacent to the selected element
The jQuery before() and after() method is used to insert content before the selected elements. So the newly added element and selected element become siblings of each other
The jQuery before()
The jQuery after()
// Add content before an element with ID container
    $("#container").before("<p>&mdash; The Beginning &mdash;</p>");    
    // Add content before headings
    $("button").click(function(){
        $("h1").before('<img src="images/marker-left.gif" alt="Symbol">');
    });
// Add content after an element with ID container
    $("#container").after("<p>&mdash; The End &mdash;</p>");     
    // Add content after headings
    $("button").click(function(){
        $("h1").after('<img src="images/marker-right.gif" alt="Symbol">');
    });
newly added element becomes previous sibling of selected element
newly added element becomes next sibling of selected element
The jQuery before() and after() also supports passing in multiple arguments as input.
Adding parent to the selected element
The jQuery wrap() method is used to wrap an HTML structure around the selected elements. 
The jQuery code in the following example will wrap the container elements with a <div> element with the class .wrapper. So the selected element becomes child of the wrapped element
Example
// Wrap elements with class container with HTML
$(".container").wrap('<div class="wrapper"></div>');    
Removing elements or contents
jQuery provides various methods, such as empty(), remove(), unwrap() etc. to remove existing HTML elements or contents from the document.
MethodDescription
// Removes paragraphs with class "hint" from DOM
    $("button").click(function(){
       $("p.hint").remove();
    });
remove() method removes the selected elements from the DOM as well as everything inside it. In addition to the elements themselves, all bound events and jQuery data associated with the elements are removed.
// Removes paragraphs with class "hint" from DOM
    $("button").click(function(){
       $("p").remove(".hint");
    });
remove() method can also include a selector as an optional parameter, that allows you to filter the elements to be removed.
// Empty container element
    $("button").click(function(){
       $(".container").empty();
    });
jQuery empty() method removes all child elements as well as other descendant elements and the text content within the selected elements from the DOM but the selected element exists
// Removes the paragraph's parent element
    $("button").click(function(){
       $("p").unwrap();
    });
jQuery unwrap() method removes the parent elements of the selected elements from the DOM.
Removing attributes
The jQuery removeAttr() method removes an attribute from the selected elements.
Example
// Removes the hyperlink's href attribute
    $("button").click(function(){
       $("a").removeAttr("href");
    });
Modifying CSS
​​​​​​​The jQuery library includes various methods to manipulate style properties and CSS class of DOM element(s).
jQuery provides css() method to manipulate CSS properties of the matched elements and addClass(), removeClass() and toggleClass() methods to manipulate with CSS classes applied to respective element.
Getting or setting the CSS properties
css() method is used to get and set CSS properties on DOM elements.
Following is the syntax of the css() method for reading CSS properties of selected element
$(selector).css(propertyName);
Following is the syntax of the css() method for setting the value of one or more CSS properties of selected element.
$(selector).css(propertyName, value);
Getting propertiesSetting properties
//returns the background color of the first matched <div>.
      $("button").click(function(){
         alert("Background color = " + $("div").css("background-color"));
      });
 //color of the first matched <div> used to change the text color of all <p>      
​​​​​​​     $("button").click(function(){
         var color = $("div").css("background-color");
         $("p").css("color", color);
      });
Setting Multiple CSS Properties
You can apply multiple CSS properties on the matched elements using a single jQuery method css(). You can apply as many properties as you like in a single call.
Syntax
$(selector).css({propertyName1:value1, propertyName2:value2,...});
Example
$("button").click(function(){
         $("div").css({"background-color":"red", "font-size": "25px"});
 });
Adding and removing CSS classes
jQuery provides addClass() method to add a CSS class to the matched HTML element(s). Following is the syntax of the addClass() method:
$(selector).addClass("Class1 Class2");
Multiple classes can be added to the elements at a time. Just specify the space separated list of classes within the addClass() method.
Similarly, you can remove the classes from the elements using the jQuery removeClass() method. The removeClass() method can remove a single class, multiple classes, or all classes at once from the selected elements. When the removeClass() method is called without an argument it will remove all the classes from the selected elements.

Toggling CSS classes
The jQuery toggleClass() add or remove one or more classes from the selected elements in such a way that if the selected element already has the class, then it is removed; if an element does not have the class, then it is added i.e. toggle classes

Traversing Nodes
jQuery provides powerful methods for traversing the DOM (Document Object Model) to select and manipulate elements based on their relationship to other elements. Traversing allows you to move up, down, and sideways through the DOM tree to find and interact with specific elements. DOM traversing is one of the prominent features of the jQuery. The methods used for traversing are categorized into 
  1. Traversing down the tree
  2. Traversing up the tree
  3. Traversing sideways in the tree
Traversing down the tree
In logical relationships a descendant is a child, grandchild, great-grandchild, and so on.
jQuery provides the useful methods such as children() and find() which are used to traverse down in the DOM tree either single or multiple levels to easily find or get the child or other descendants of an element in the hierarchy.
MethodExampleDescription
children()<script>
$(document).ready(function(){
    $("ul").children().addClass("highlight");
});
</script>
This method is used to get the direct children of the selected element.
find()<script>
$(document).ready(function(){
    $("div").find("li").addClass("frame");
});
</script>
This method is used to get the descendant elements of the selected element.
Note : The find() and children() methods are similar, except that the find() method search through multiple levels down the DOM tree to the last descendant, whereas the children() method only search a single level down the DOM tree.
Traversing up the tree
In logical relationships an ancestor is a parent, grandparent, great-grandparent, and so on.
jQuery provides the useful methods such as parent(), parents() and parentsUntil() that you can use to traverse up in the DOM tree either single or multiple levels to easily get the parent or other ancestors of an element in the hierarchy.

Traversing sideways in the tree
In logical relationships siblings are those elements that share the same parent.
jQuery provides several methods such as siblings(), next(), nextAll(), nextUntil(), prev(), prevAll() and prevUntil() that you can use to traverse sideways in the DOM tree.
MethodExampleDescription
siblings() //adds highlight class for all siblings of p element
$("p").siblings().addClass("highlight");
This method is used to get the sibling elements of the selected element.
next()//fades out immediate next sibling of element with myimg id

This method is used to get the immediately following sibling i.e. the next sibling element
nextAll()//fades out immediate all next sibling of element with myimg id
$("#myimg").nextAll().fadeOut();
This method is used to get all following(next) siblings of the selected element.
nextUntil()//fades out immediate all next sibling up to p element of element with myimg id

This method is used to get all the following siblings up to but not including the element matched by the selector.

This method is used to get the immediately preceding sibling i.e. the previous sibling element of the selected element.
