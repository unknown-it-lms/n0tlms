DOM Manipulation
DOM manipulation in javascript is an important factor while creating a web application using HTML and JavaScript. It is the process of interacting with the DOM API to change or modify an HTML document that will be displayed in a web browser. This HTML document can be changed to add or remove elements, update existing elements, rearrange existing elements, etc.

By using textContent property
The textContent property is widely used for accessing and modifying the text content of HTML elements in JavaScript. It's especially useful when you want to work with the raw text content of elements without any styling. Value of textContent property will be a string or null. 
textContent returns full text of all elements, including <script> and <style> elements. In contrast, innerText only returns visible text of HTML element nodes only. innerText property does not include text that is hidden with CSS styles.

By using firstChild.nodeValue property
The firstChild property in JavaScript returns the first child node of the specified parent node. Nodes can be of various types, including elements, text nodes, comments, etc. The nodeValue property, when used on a text node, returns the textual content of that node.
HTMLGetting the firstChild.nodeValueOutput
<div id="parentElement">
    First child text node
    <p>Second child element</p>
</div>		const parent = document.getElementById('parentElement');
const firstChildNode = parent.firstChild;
const textContent = firstChildNode.nodeValue;
console.log(textContent);		Output:
First child text node
When using firstChild, understand that it returns the first child node of the parent, which may not necessarily be a text node. It could be an element node, comment node, etc. Always check the type of the node before accessing its nodeValue property to avoid errors.
Modifying Style
HTML element's style can be modified using one of the following ways :
  1. Using style property
  2. Using CSS classes
Using style property
To modify the style of an HTML element using JavaScript, element's style property is used. Style property which is an object representing the inline CSS styles of the element. You can then set individual style properties using CSS attribute.
Changing the style of element
HTMLJavascript
<div id="example">
    <p>This is a paragraph.</p>
</div		const element = document.getElementById('example');
element.style.color = 'red';
element.style.fontSize = '16px';
element.style.backgroundColor = 'yellow';
//output : paragraph will be displayed with the specified style
Note : When setting style properties using JavaScript, you should use camelCase for property names, instead of hyphen separated CSS property names. e.g. CSS attribute background-color will be used as backgroundColor
Removing style of an element
A specific style property can be removed by setting it to an empty string. Example :
element.style.color = '';
Using CSS classes
To modify styles using classes in JavaScript, you need to add, remove, or toggle classes on HTML elements. First, define CSS classes in the style sheet with the required styles and then use javascript's add, remove and  toggle function on the classList property. The classList property returns the CSS classnames of an element. Toggle a class on an element means if the class is present, it will be removed; if it's not present, it will be added.
Defining classAdding class
.highlight {
    color: red;
    font-size: 16px;
    background-color: yellow;
}		const element = document.getElementById('example');
element.classList.add('highlight');
Removing class
const element = document.getElementById('example');
​​​​​​​element.classList.remove('highlight');
Toggling class
const element = document.getElementById('example');
element.classList.toggle('highlight');
Advantage using classes:
  • Classes can be defined for complex styles and can be reused across multiple elements.
  • Classes can be easily toggled based on different events.
  • Classes allow to separate style of the content from actual content

Handling Browser Objects
Browser object is not an official term but its a group of objects which are used for managing various browser related information and actions.
For example, when an HTML document is opened in a browser window, the browser interprets the document as a collection of hierarchical objects(HTML tags) and accordingly displays the data contained in these objects(HTML page rendering). The browser parses the document and creates a collection of objects, which defines the documents and its details. Following are various objects that are available which allows to access different parts of browser :

​
Browser Objects:
The objects listed below are called browser objects.
  1. Window
  2. Navigator
  3. Screen
  4. History
  5. Location
Window Object
It generally represents a tab in browser window, but some actions like window's width and height will affect the complete browser window. It is the top-level object in the browser's JavaScript hierarchy. In web browsers, the window object serves as the global object for JavaScript code running in the browser. It provides :
  • Access to many properties and methods related to the browser environment.
  • Some common properties include location, navigator, document, history, screen, etc.
  • Several global functions are part of the window object, such as setTimeout(), setInterval(), alert(), confirm(), prompt(), etc.
  • Allows to use events for various browser events, such as load, resize, scroll, etc.
  • The window.open() method in JavaScript is used to open a new window or tab in a web browser. It takes several optional arguments that allow you to customize the behavior of the new window.        window.open(url, windowName, windowFeatures, replace)
    E.g.
    Window with specific URL
    window.open("https://www.example.com", "_blank"); //"_blank" is the default target for a new window
    Window with specific dimension
    window.open("https://www.example.com", "_blank", "width=400,height=300,scrollbars=yes");

The history object represents the user's navigation history for the current window. It allows to navigate forward and backward through visited URLs.
CodeOutput

history.forward();Navigates to the next visited URL in history
