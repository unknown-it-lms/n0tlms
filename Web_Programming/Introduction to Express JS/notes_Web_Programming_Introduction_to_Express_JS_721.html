Introduction to Express JS
Express JS makes web application development on the server side very easy. In this chapter we will understand  about it's installation and how to write different routes for handling client requests more easily than using http module of nodejs.
Express JS - need, features
Express JS reduces development time and also reduces the efforts required to build web application with it's different features. Official web site of express JS describes it as  "Express is a fast, unopinionated, minimalist web framework for Node.js". The meaning of this statement is that Express JS will allow the programmer to develop server side programs very quickly as compared to Node JS and does not force a particular structure of the program to be followed.
Express.js is a web application framework for Node.js. It provides various features that make web application development fast and easy which otherwise takes more time using only Node.js. 
Features of Express JS
Faster server side development
Many commonly used features of Node.js are provided by Express.js in the form of functions that can be readily used in the program. This saves time and efforts.
Routing
Expressjs provides routing mechanism in the form of different functions which are executed on receiving specific URL.
Middleware
Middleware is that functions that can be associated with multiple requests. So common tasks required in multiple request handling like logging can be defined in middleware.
Serving static content
Easy to serve static files and resources of your application. Built in middleware static is available in Express to include resources like images, styles or scripts.
Templating
ExpressJS provides templating engines that allow the developers to build dynamic content on the web pages by building HTML templates on the server side.
Debugging
Express JS provides debugging mechanism the has the ability to pinpoint the exact part of the web application which has bugs
Building REST server
Allows you to create REST API server. Server which sends the response to it's clients in the form of JSON.
Communicate with databases
Easy to connect with databases such as MongoDB, Redis, MySQL. So it is possible to connect structured as well as unstructured databases
Advantages of Using Express With Node.js
  • Express is Unopinionated, and we can customize it.
  • For request handling, we can use Middleware.
  • A single language is used for frontend and backend development.
  • Express is fast to link it with databases like MySQL, MongoDB, etc.
  • ​​Express allows dynamic rendering of HTML Pages based on passing arguments to templates.
Limitations of Express JS
  • Sometimes, there is no structural way to organize things, and the code becomes non-understandable.
  • There are some issues with callbacks. Express JS is totally based on use of callbacks.
  • The error messages that will come are challenging to understand.
Installation of Express.js
Express.js can be installed using npm. The following command will install latest version of express.js globally on your machine so that every Node.js application on your machine can use it.
npm install -g express
The following command will install latest version of express.js local to your project folder.
D:\MyNodeJSApp> npm install express --save
As you know, --save will update the package.json file by specifying express.js dependency.
Handling Requests
A web server will wait for the HTTP requests from client. Once request is received from client, server will choose the corrosponding route handler and delegate the responsibility of generating response to the specific route. A route handler is a function that will be executed every time the server receives a particular request, defined by HTTP method.
Syntax of Request Handler
app.method('requset url', callback){
...
})
The method can be get, post, put, delete, all. It accepts the request url in the first argument and callback function in the second argument. The callback function is a request handler. The request handler processes the request and write to the response object. This is similar to the callback in the core Node.js http.createServer() method.
Example of basic route
CodeDescription
const express = require('express')
const app = express();
app.get('/', function(req, res) {
  res.send('hello world')
});
app.listen(9000, function() {
   console.log("server started on port 9000");
});
  • This will run the web server at port no 9000.
  • Route handler is written for handling the request as "http://localhost:9000/"
  • When request is received with URL "http://localhost:9000/", "hello world" response is sent back to the client
//Above code can be written using arrow functions
const express = require('express')
const app = express();
app.get('/', (req, res)=> {
  res.send('hello world')
});
app.listen(9000, () => {
   console.log("server started on port 9000");
});
Route paths
Route paths, in combination with a request method, define the endpoints at which requests can be made. Endpoints will describe the end of communication channel on the sever side. This mainly include the route URL and http method that will be used by the client for makign requests. Route paths can be strings, string patterns, or regular expressions.
Route paths on strings 
CodeDescription
app.get('/', (req, res) => {
  res.send('root')
})		This route path will match requests to the root route, /.
app.get('/about', (req, res) => {
  res.send('about')
})		This route path will match requests to /about.
app.get('/random.text', (req, res) => {
  res.send('random.text')
})		This route path will match requests to /random.text.
Route paths based on string patterns
CodeDescription
app.get('/ab?cd', (req, res) => {
  res.send('ab?cd')
})		This route path will match /acd and /abcd. ? is applied for character 'b' which indicates zero or one occurrence of 'b'
app.get('/ab+cd', (req, res) => {
  res.send('ab+cd')
})		This route path will match /abcd, /abbcd, /abbbcd, and so on. '+' symbol indicates one or more occurrence of 'b'
app.get('/ab*cd', (req, res) => {
  res.send('ab*cd')
})		This route path will match /abcd, /abxcd, /abRANDOMcd, /ab123cd, and so on. '*' symbol indicates zero or more occurrence of 'b'
app.get('/ab(cd)?e', (req, res) => {
  res.send('ab(cd)?e')
})		This route path will match /abe and /abcde.
Route paths based on regular expressions
CodeDescription
app.get(/a/, (req, res) => {
  res.send('/a/')
})		This route path will match anything with an “a” in it.
General route
A route handler which can handle any request url can be considered as general route. This general route should be written at the end of all routes. If none of the route matches, then this general route will get executes. We will be writing '*' in place of route path which means any url.
CodeDescription
app.get('*', (req, res) => {
  res.send("Sorry, please check url");
})		This route path will match any string as route path.
Routing Parameters
Route parameters can be used in route url to create dynamic routes based on user input. Users can add a specific variable(s) to the request URL. This input can be extracted by Express.js and return response based on the value of the variable/parameter.
We can use : symbol in request url for specifying route parameter in request url. Route handler function can use req.params object for reading(capturing) the request parameter. req.params is a object containing key-value pairs where key is name of the route parameter specified in the path and value is the data given in the url by the client.
CodeDescription
app.get('/api/users/:id', (req, res) => {
  const userID = parseInt(req.params.id)
  //This userID can be used in for finding required data
  //send the data in the response.
})
  • This route path includes id parameter like /api/users/1.
  • This value 1 will be extracted using req.params in the function
app.get('/users/:userId/books/:bookId', (req, res) => {
  res.send(req.params)
}).
for the request URL: http://localhost:3000/users/34/books/8989
req.params object will be populated as
{ "userId": "34", "bookId": "8989" }
