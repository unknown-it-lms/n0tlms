Dynamic HTML
Java script is mainly used for generating dynamic HTML based on user's input. Generating new content or seletively displaying some part of existing content based on some condition can be easily done by event handling in java script. In this chapter, we will learn about this dynamic HTML.
Events
An event is an action that occurs as per the user's instruction as input . Different types of events get generated when user performs some action like mouse clicks, button presses, press tab and text box change.
Here’s a list of the most useful DOM events, just to take a look at:
Mouse events:
EventDescription
click
when the mouse right-clicks on an element.
contextmenu
when the mouse cursor comes over / leaves an element.
mouseover / mouseout
when the mouse button is pressed / released over an element.
mousemove
when the mouse is moved.
Keyboard events:
EventDescription
keydownwhen the key is pressed.
keyupwhen the key is released.
keypresswhen the key is pressed and released over an element.
Form events:
EventDescription
submit when the visitor submits a <form>
focuswhen the visitor focuses on an element, e.g. on an <input>.
Window events:
EventDescription
loadwhen the borwser finishes loading the page
unloadwhen the visitor leaves the current webpage.

Event handlers
JavaScript implements event handler that helps you to perform certain actions to the events. An event handler is a section of code that can be considered as a user-defined JavaScript function that operates when a particular event fires. Event handler can be treated as an event listener that performs some actions after event occurrence and returns the result.
Event listener attributes
  • These attributes allows to attach event handlers directly to HTML elements in the web page.
  • These attributes allow to define JavaScript code that should be executed when a specific event occurs on the element, such as a click, hover, or input event.
  • Typically these attributes have names that begin with on. For example, the event handler for the click event is onclick.
  • Frquently required listener attributes :
    • onload:  When your page loads, it performs accordingly.
    • onclick: When a user clicks on a button or inputs it occurs.
    • onmouseover: When a user mouses over on the button.
    • onfocus:  Certain scenarios when a user keeps the cursor in a form field.
    • onblur: If a particular form field leaves within it.
  • Example:
    to execute some code when a button is clicked, following can be used:
    <input type="button" value="Save" onclick="alert('button clicked')"   />
    Instead of writing javascript code in onclick attribute, a function can be used as a event handler, 
    <input type="button" value="Save" onclick="sendData()"   />
    Here sendData() is a user defined java script function.
  • The code in the event handler can access the event object without explicitly defining it.
    <input type="button" value="Save" onclick="alert(event.type)"   />
  • The this value inside the event handler is equivalent to the event’s target element
    <input type="button" value="Save" onclick="alert(this.value)"   />
  • The event handler can access the element’s properties
    <input type="button" value="Save" onclick="alert(value)"   />
Attaching event handler
Each element has event handler properties like onclick. To assign an event handler, the respective property can be assigned to a function.
const button = document.getElementById("myButton");
button.onclick = function() {
   alert("Button clicked!");
};
addEventListener() function even can be used for the same purpose    
 
Generating dynamic content
Create a HTML page and decide the event to be handled on a particular element.
Example: We will create a HTML form for accepting number from the user and once user clicks on the button, generate a table for number accepted from the user and display it in the given div element
<form>
        Enter number : 
        <input type="number" name="num" />
        <br/>
        <input type="button" value="Display Table"        
</form>
<div id="table"></div>

Define javascript function that performs the required action to be executed for a given event.
In the script tag, define function which generates a HTML table and displays it in the selected div element
<script>
        function dyTable(n) {
            var str = "<table border='1' style='background-color:aqua'>";
            for(i=1;i<=10;i++) {
                str+="<tr>";
                str+="<td>";
                str+= n+" * "+i+" = "+(n*i);    
                str+="</td>";        
                str+="</tr>";    
            }    
            str+="</table>";
            console.log(str); 
            document.getElementById("table").innerHTML = str;   
        }
</script>

Use the event attribute for attaching the javascript function.
Modify the button element in the HTML form to handle it's click event by calling dyTable() function created in the above step
<input type="button" value="Display Table"
        onclick="dyTable(num.value)" />
Event attributes help in attaching event handler to a particular element and these event attributes start with "on" word.
JS Popup Boxes
JavaScript provides different built-in functions to display popup messages for different purposes e.g. to display a simple message or display a message, take user's confirmation on it or display a popup to take a user's input value. There are 3 types of popup boxes 
  1. Alert box
  2. Confirm box
  3. Prompt box
Alert Box
Use alert() function to display a popup message to the user. Examples :
alert("This is alert box!");  // display string message
alert(100); // display number
alert(true); // display boolean
Alert popup displays message and ok button. This ok button can be clicked to close the alert box.
The alert function can display message of any data type e.g. string, number, boolean etc. There is no need to convert a message to string type.
Confirm Box
Sometimes you need to take the user's confirmation to proceed. For example, you want to take user's confirmation before saving updated data or deleting existing data. In this scenario, use JavaScript built-in function confirm(). The confirm() function displays a popup message to the user with two buttons, OK and Cancel. You can check which button the user has clicked and proceed accordingly.
The following example demonstrates how to display a confirm box and then checks which button the user has clicked. confirm() will return true if user clicks ok button and false if user clicks cancel button
Example: Confirm Box
if (confirm("Do you want to save changes?") == true) {
    alert("Data saved successfully!");
} else {
    alert("Save Cancelled!");
}
Prompt Box
Sometimes you may need to take the user's input to do further actions in a web page. For example, you want to calculate EMI based on users' preferred tenure of loan. For this kind of scenario, use JavaScript built-in function prompt().
Prompt function takes two string parameters. First parameter is the message to be displayed and second parameter is the default value which will be in input text when the message is displayed.
Syntax:
prompt([string message], [string defaultValue]);
Example: prompt Box
var tenure = prompt("Please enter preferred tenure in years", "15");
if (tenure != null) {
    alert("You have entered " + tenure + " years" );
}
As you can see in the above example, we have specified a message as first parameter and default value "15" as second parameter. The prompt function returns a user entered value. If user has not entered anything then it returns null. So it is recommended to check null before proceeding.

Note:
The alert, confirm and prompt functions are global functions. So it can be called using window object like window.alert(), window.confirm() and window.prompt().

Points to Remember :
  1. Popup message can be shown using global functions - alert(), confirm() and prompt().
  2. alert() function displays popup message with 'Ok' button.
  3. confirm() function display popup message with 'Ok' and 'Cancel' buttons. Use confirm() function to take user's confirmation to proceed.
  4. prompt() function enables you to take user's input with 'Ok' and 'Cancel' buttons. prompt() function returns value entered by the user. It returns null if the user does not provide any input value.
