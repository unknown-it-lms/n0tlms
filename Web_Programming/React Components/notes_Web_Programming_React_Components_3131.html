React Components
In this chpater we will learn about basic building block of react application in the form of react components. React components are re-usable. Let us see how the components can be devloped and rendered in details.
What are components
  • Components are one of the core concepts in ReactJS.
  • Components let you split the UI into independent, reusable pieces, and think about each piece in isolation.
  • Components are independent and reusable bits of code. They are similar like JavaScript functions, but work in isolation and return HTML via a render() function.
  • A Component is considered as the core building blocks of a React application. It makes the task of building UIs much easier. Each component exists in the same space, but they work independently from one another and merge all in a parent component, which will be the final UI of your application.
  • They accept arbitary inputs (called props) and return React elements describing what should appear on the screen.
  • React components have their own structure, style or as well as logic for event handling. They can be reusable as per your need.
Types of components
Components can be defined with the required UI in the form of JSX and exported as default. In ReactJS, there are mainly two types of components.
  1. Functional Components
  2. Class Components
Functional Component 
In React, functional components are a way to write components that only contain a rendering logic and don't have their own state. They are simply JavaScript functions that may or may not receive data as parameters. We can create a function that takes props(properties) as input and returns what should be rendered(displayed in the UI). The functional component is also known as a stateless component because they do not hold or manage state.
Example 
Component definitionComponent rendering
function Greet(props) { 
  return <h1>Hello , {props.name}</h1>; 
} 
export default Greet;		const element = <Greet name="Sara" />;
ReactDOM.render(
  element,
  document.getElementById('root')
);

If written in App component, render the component like HTML element
<Greet />
Note : When creating a React component, the component's name must start with an upper case letter.
Class Component
Components can also be written using ES6 classes instead of functions. Such components are called class components.
The component has to include the extends React.Component statement, this statement creates an inheritance to React.Component, and gives your component access to React.Component's functions.
The component also requires a render() method, this method returns HTML.
Component definitionComponent rendering
import React, { Component } from 'react';
​​​​​​​class Welcome extends React.Component {
  //render function is compulsory
  render() {
    return <h2>Hello</h2>;
  }
}
export default Welcome;		ReactDOM.render(<Welcome />, document.getElementById('root'));

If written in App component, render the component like HTML element
<Welcome />
If there is a constructor() function in your class component, this function will be called when the component gets initiated. The constructor function is where component's properties are initialized. In React, component properties should be kept in an object called state. The constructor function also gives a call to super() statement, which executes the parent component's constructor function, and your component has access to all the functions of the parent component (React.Component).
Component definitionComponent rendering
class Welcome extends React.Component {
  //constructor optional to implement
  constructor(props) {
    super(props);
    this.state = {name: "Amit"};
  }
  //render compulsory to implement
  render() {
    return <h2>Hello {props.name}</h2>;
  }
}
​​​​​​​export default Welcome;		ReactDOM.render(<Welcome  name='Rahul'/>, document.getElementById('root'));

If written in App component, render the component like HTML element
<Welcome name="Rahul" />

Functional components and class components are similar in some respect and are different in some aspects.
Similarities

Nesting of Components
We can refer to components inside other components:
Example of nested component
class App extends React.Component {
   render() {
      return (
         <div>
            <Header/>
            <Content/>
         </div>
      );
   }
}
Here Header and Content are the components which are nested within App component. Header and Content could be function or class components. This gives the advantage of developing complex UI.
